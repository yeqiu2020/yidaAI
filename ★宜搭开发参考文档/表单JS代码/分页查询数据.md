## 分页查询方法说明

### 概述

宜搭API的 `pageSize` 参数有最大值限制（通常为100），当需要查询的数据超过100条时，需要通过分页查询来获取所有数据。

### 分页参数说明

| 参数名 | 描述 | 是否必填 | 示例 | 备注 |
|--------|------|----------|------|------|
| currentPage | 当前页码 | 否 | 1 | 必须大于 0，默认为 1 |
| pageSize | 每页记录数 | 否 | 10 | 必须大于 0，默认为 10，最大值通常为 100 |
| totalCount | 总记录数 | 返回值 | 250 | API返回的总记录数，用于判断是否还有更多数据 |

### 返回数据结构

```javascript
{
  "success": true,
  "result": {
    "data": [...],      // 当前页的数据列表
    "totalCount": 250,   // 总记录数（所有符合条件的记录总数）
    "currentPage": 1     // 当前页码
  }
}
```

### 分页查询实现步骤

#### 步骤1：查询第一页数据

```javascript
var requestParams = {
  formUuid: 'FORM-XXXXXXXX',
  appType: 'APP_XXXXXXXX',
  searchFieldJson: JSON.stringify(searchConditions),
  pageSize: '100',      // 设置为最大值
  currentPage: '1'       // 从第1页开始
};

this.dataSourceMap.getEmployeeSalaryData.load(requestParams).then(function(response) {
  var currentPageData = response.result.data || [];
  var totalCount = response.result.totalCount || 0;
  var allData = currentPageData;
  
  // 判断是否还有更多数据
  if (allData.length < totalCount) {
    // 继续查询下一页
  }
});
```

#### 步骤2：循环查询后续页

```javascript
function queryAllData(that, searchConditions, currentPage, accumulatedData) {
  var requestParams = {
    formUuid: 'FORM-XXXXXXXX',
    appType: 'APP_XXXXXXXX',
    searchFieldJson: JSON.stringify(searchConditions),
    pageSize: '100',
    currentPage: String(currentPage)
  };
  
  return that.dataSourceMap.getEmployeeSalaryData.load(requestParams).then(function(response) {
    var currentPageData = response.result.data || [];
    var totalCount = response.result.totalCount || 0;
    
    // 合并数据
    var allData = accumulatedData.concat(currentPageData);
    
    // 检查是否还有更多数据
    if (allData.length < totalCount) {
      // 继续查询下一页
      return queryAllData(that, searchConditions, currentPage + 1, allData);
    } else {
      // 所有数据查询完成
      return allData;
    }
  });
}
```

#### 步骤3：调用分页查询函数

```javascript
// 从第1页开始查询
queryAllData(this, searchConditions, 1, []).then(function(allData) {
  console.log('共查询到 ' + allData.length + ' 条数据');
  
  // 处理所有数据...
});
```

```javascript
export function handleSummarySalary() {
  var that = this;
  
  var searchConditions = {
    departmentSelectField_mght567h: '1035598096',
    numberField_mgzxh10r: '2026',

  };
  
  // 分页查询所有数据

    console.log('共查询到 ' + allSalaryData.length + ' 条数据');
    
    // 处理数据...
  }).catch(function(error) {
    console.error('查询失败:', error);

function queryAllSalaryData(that, searchConditions, currentPage, accumulatedData) {
  var pageSize = 100;
  
  var requestParams = {
    formUuid: 'FORM-DBB47628926C48BF80B3C49AAE3782E0E03Y',
    appType: 'APP_KY52Y6FBZU8SINHQQQBN',
    searchFieldJson: JSON.stringify(searchConditions),
    pageSize: String(pageSize),
    currentPage: String(currentPage)
  };
  
  return that.dataSourceMap.getEmployeeSalaryData.load(requestParams).then(function(response) {
    var currentPageData = [];
    var totalCount = 0;
    
    if (response && response.result && response.result.data) {
      currentPageData = response.result.data;
      totalCount = response.result.totalCount || 0;
    } else if (response && response.data) {
      currentPageData = response.data;
      totalCount = response.totalCount || 0;
    }
    
    // 合并数据
    var allData = accumulatedData.concat(currentPageData);
    
    // 检查是否还有更多数据
    if (allData.length < totalCount) {
      // 继续查询下一页
      return queryAllSalaryData(that, searchConditions, currentPage + 1, allData);
    } else {
      // 所有数据查询完成
      return allData;
    }
  });
}
```

### 分页查询流程图

```
开始查询
    ↓
查询第1页（pageSize=100, currentPage=1）
    ↓
获取当前页数据 + 总记录数
    ↓
累积数据：allData = accumulatedData + currentPageData
    ↓
判断：allData.length < totalCount？
    ↓
    ├─ 是 → 查询下一页（currentPage + 1）
    │         ↓
    │    返回步骤2（递归）
    │
    └─ 否 → 返回所有数据（allData）
              ↓
          数据处理完成
```

### 注意事项

1. **pageSize 最大值**：宜搭API的 `pageSize` 参数通常最大值为 100，不能超过此值
2. **递归查询**：使用递归方式循环查询，直到获取所有数据
3. **数据累积**：每次查询后需要将新数据合并到累积数组中
4. **判断条件**：通过比较 `已查询数据总数` 和 `总记录数` 来判断是否继续查询
5. **异步处理**：API查询是异步操作，需要使用 Promise 或回调处理

### 实际应用场景

假设数据库中有 250 条符合条件的数据：

| 查询次数 | currentPage | accumulatedData | 查询结果 | allData | 是否继续 |
|---------|-------------|----------------|------------|---------|---------|
| 第1次 | 1 | [] | 100条 | 是（100 < 250）|
| 第2次 | 2 | [100条] | 200条 | 是（200 < 250）|
| 第3次 | 3 | [200条] | 250条 | 否（250 >= 250）|

最终返回：[250条] 所有数据
