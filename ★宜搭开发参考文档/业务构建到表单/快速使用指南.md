# 宜搭表单生成器 V2 - 快速使用指南

## 📚 简介

这是一个基于Node.js的宜搭表单自动生成工具，可以通过简单的JavaScript配置文件生成100%符合宜搭规范的表单JSON。

**核心特性**：
- ✅ 支持25种宜搭标准字段类型
- ✅ 支持子表（TableField）及子表内的公式字段
- ✅ 自动计算公式字段的marks位置
- ✅ 生成的JSON可直接导入宜搭使用

## 📝 配置文件编写

### 基础示例

创建配置文件 `config/my_form.js`：

```javascript
module.exports = {
  formName: '员工信息表',
  module: '人事管理',  // 可选，用于项目级生成
  fields: [
    // 单行文本
    {
      type: 'TextField',
      label: '姓名',
      placeholder: '请输入姓名',
      required: true,
      maxLength: 50
    },
    
    // 数值字段
    {
      type: 'NumberField',
      label: '年龄',
      precision: 0
    },
    
    // 日期字段
    {
      type: 'DateField',
      label: '入职日期',
      format: 'yyyy-MM-dd'
    },
    
    // 下拉选择
    {
      type: 'SelectField',
      label: '部门',
      options: [
        { label: '技术部', value: 'tech' },
        { label: '销售部', value: 'sales' },
        { label: '行政部', value: 'admin' }
      ]
    }
  ]
};
```

### 子表示例

```javascript
module.exports = {
  formName: '采购订单表',
  fields: [
    {
      type: 'TextField',
      label: '订单编号',
      required: true
    },
    
    // 子表字段
    {
      type: 'TableField',
      label: '产品明细',
      columns: [
        {
          type: 'TextField',
          label: '产品名称'
        },
        {
          type: 'NumberField',
          label: '数量',
          precision: 0
        },
        {
          type: 'NumberField',
          label: '单价',
          precision: 2
        },
        {
          type: 'NumberField',
          label: '小计',
          valueType: 'formula',
          formulaTemplate: '{数量}*{单价}',
          precision: 2
        }
      ]
    }
  ]
};
```

### 公式字段示例

```javascript
{
  type: 'NumberField',
  label: '总金额',
  valueType: 'formula',
  formulaTemplate: '{数量}*{单价}*(1-{折扣})',
  precision: 2
}
```

**公式说明**：
- 使用 `{字段名}` 引用其他字段
- 程序会自动添加零宽空格并计算marks位置
- 子表公式只能引用同一子表内的字段

## 💡 使用技巧

### 1. 测试模式 vs 正式模式

**测试模式**（临时输出）：
```bash
node test_generator.js ./config/my_form.js --test
# 输出到: temp/temp_output.json
# 用于快速验证配置
```

**正式模式**（正式输出）：
```bash
node test_generator.js ./config/my_form.js
# 输出到: output/my_form.json
# 用于正式导入宜搭
```

### 2. 字段配置常用属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `type` | 字段类型（必填） | `'TextField'` |
| `label` | 字段标签（必填） | `'姓名'` |
| `placeholder` | 提示文本 | `'请输入姓名'` |
| `required` | 是否必填 | `true` |
| `maxLength` | 最大长度 | `100` |
| `precision` | 小数位数 | `2` |
| `options` | 选项列表 | `[{label: 'A', value: 'a'}]` |
| `format` | 日期格式 | `'yyyy-MM-dd'` |
| `multiple` | 是否多选 | `false` |
| `gridSpan` | 占据列数 | `2` |

### 3. 关联表单配置

```javascript
{
  type: 'AssociationFormField',
  label: '关联产品',
  associationFormId: 'product_form',      // 关联表单ID
  associationFormName: '产品信息表',      // 关联表单名称
  multiple: false                          // 是否多选
}
```

### 4. 子表配置要点

- 使用 `TableField` 类型
- `columns` 数组定义子表字段
- 子表字段支持所有标准字段类型
- 子表内可以使用公式字段

## 🔍 常见问题

### Q1: 生成的JSON在宜搭中导入失败？
**A**: 检查以下几点：
- 确保使用的是正式生成模式（非测试模式）
- 检查配置文件语法是否正确
- 查看控制台是否有错误提示

### Q2: 公式字段不生效？
**A**: 公式字段注意事项：
- 使用 `{字段名}` 引用字段
- 字段名必须与配置中的label完全一致
- 子表公式只能引用同一子表内的字段
- 确保 `valueType: 'formula'` 已设置

### Q3: 子表字段不显示？
**A**: 已修复！当前版本子表字段生成完全正常：
- children数组包含完整字段对象
- 支持所有字段类型
- 支持子表内的公式

### Q4: 如何查看生成的JSON？
**A**: 生成后的文件位置：
- 测试模式：`temp/temp_output.json`
- 正式模式：`output/表单名.json`
