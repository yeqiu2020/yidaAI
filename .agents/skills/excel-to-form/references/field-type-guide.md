# 字段类型指南

> 宜搭表单字段类型详细说明
> 
> **合法字段类型列表（16种）**：单行文本、多行文本、数值、日期、单选、复选、下拉单选、下拉复选、关联表单、成员、部门、附件、图片、地址、流水号
> 
> **⚠️ 极其重要**：所有字段类型必须严格来自上述列表，禁止编造任何不在列表中的类型。

## 一、可用字段类型

| 字段类型 | 说明 | 适用场景 |
|---------|------|---------|
| 单行文本 | 短文本输入 | 名称、标题、编号、地址 |
| 多行文本 | 长文本输入 | 备注、说明、描述 |
| 数值 | 数字输入 | 金额、数量、比例 |
| 日期 | 日期选择（支持到时分秒） | 开始日期、结束日期、创建时间 |
| 单选 | 单选按钮组 | 性别、是否启用等少量选项 |
| 复选 | 复选框组 | 可多选的少量选项 |
| 下拉单选 | 单选下拉框 | 状态、类型、分类等较多选项 |
| 下拉复选 | 多选下拉框 | 标签、多类别 |
| 关联表单 | 关联其他表单 | 客户、项目、产品 |
| 成员 | 人员选择 | 负责人、创建人 |
| 部门 | 部门选择 | 所属部门 |
| 附件 | 文件上传 | 文档、合同 |
| 图片 | 图片上传 | 照片、截图 |
| 地址 | 地址选择器 | 客户地址、注册地址、办公地址 |
| 流水号 | 自动编号 | 单据编号、订单号 |

## 二、字段说明格式规范

**只有以下5类字段需要填写字段说明，其他字段留空或填"-"**

| 字段类型 | 字段说明格式 | 示例 |
|---------|-------------|------|
| **流水号** | `自动生成` | 自动生成 |
| **关联表单** | `关联-->目标表单名称` | 关联-->产品信息 |
| **关联带出** | `关联-->目标表单名称，关联带出` | 关联-->产品信息，关联带出 |
| **数值** | `X位小数，单位：XXX` | 2位小数，单位：元 |
| **下拉单选/下拉复选/单选/复选** | `选项值1/选项值2/选项值3` | 启用/停用 |

## 三、字段状态

| 状态值 | 说明 | 默认值 |
|-------|------|--------|
| **普通** | 字段可编辑输入（对应宜搭NORMAL） | 大部分字段默认为普通状态 |
| **只读** | 字段不可编辑，仅用于展示（对应宜搭READONLY） | 关联带出字段、系统自动生成字段默认为只读状态 |
| **隐藏** | 字段在表单中不显示（对应宜搭HIDDEN） | 默认无隐藏字段，用户可根据需要设置 |

**字段状态自动判定规则**：
- **只读**：创建人、创建时间、关联带出字段、公式计算字段
- **普通**：流水号、其他所有字段

**⚠️ 重要**：流水号字段状态统一为"普通"（不是"只读"），便于测试时手动输入编号

**⚠️ 重要说明**：宜搭流程表单会自动记录审批相关信息（审批人、审批时间、审批意见等），**不需要在表单字段中添加审批相关字段**

## 四、是否必填

- **是**：该字段为必填项
- **否**：该字段为选填项（默认）

**默认值规则**：
- 所有字段默认**非必填**（便于前期测试数据）
- 流水号字段**永不必填**（系统自动生成）
- 创建人、创建时间等系统字段**永不必填**

## 五、表单类型标识

- 「普通表单」：基础数据维护，无审批流程
- 「流程表单」：需要审批流程的业务单据
