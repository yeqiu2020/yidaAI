# 字段类型推断规则

> 根据字段名称自动推断宜搭字段类型
> 
> **合法字段类型列表（16种）**：单行文本、多行文本、数值、日期、单选、复选、下拉单选、下拉复选、关联表单、成员、部门、附件、图片、地址、流水号
> 
> **⚠️ 极其重要**：所有推断结果必须严格来自上述列表，禁止输出任何不在列表中的类型。

## 命名特征与类型映射

| 字段命名特征 | 推断类型 | 说明 | 示例 |
|-------------|---------|------|------|
| 编号、代码、ID、单号 | 流水号/单行文本 | 唯一标识 | 订单编号、产品编码、借用单号 |
| 名称、标题、主题 | 单行文本 | 简短描述 | 产品名称、客户名称、任务标题 |
| 日期、时间 | 日期 | 宜搭日期组件支持到时分秒 | 创建日期、创建时间、借用日期 |
| 数量、个数、件数 | 数值 | 整数计数 | 借用数量、库存数量、出库数量 |
| 金额、价格、费用、成本 | 数值 | 货币金额 | 订单金额、采购价格、维修费用 |
| 比例、率、折扣 | 数值 | 百分比或比率 | 折扣率、完成率、毛利率 |
| 状态、类型、类别、等级 | 下拉单选 | 枚举值（选项较多时用下拉单选） | 订单状态、产品类型、优先级 |
| 标签、标记、属性 | 下拉复选 | 可多选 | 产品标签、关注标记 |
| 性别、是否 | 单选 | 选项极少时用单选 | 性别（男/女）、是否启用 |
| 爱好、权限、角色 | 复选 | 可多选的少量选项 | 兴趣爱好、功能权限 |
| 备注、说明、描述、原因 | 多行文本 | 长文本 | 备注、故障描述、审批意见 |
| 人、员、负责人、操作人 | 成员 | 系统用户 | 创建人、审批人、借用人 |
| 部门、单位、组织 | 部门 | 组织架构 | 所属部门、申请部门 |
| 文件、文档、合同 | 附件 | 文件上传 | 合同附件、验收报告 |
| 图片、照片、头像 | 图片 | 图片上传 | 产品图片、现场照片 |
| 手机号、电话、邮箱 | 单行文本 | 联系方式 | 联系电话、电子邮箱 |
| 地址、位置、地点 | 地址 | 地址选择器 | 客户地址、注册地址、办公地址 |
| 选择、关联、引用 | 关联表单 | 外键关联 | 选择产品、关联订单 |
| 合计、总计、小计、累计 | 公式 | 计算字段 | 合计金额、总数量、累计次数 |
| 明细、列表、记录 | 子表单 | 关联子表 | 订单明细、借用明细 |

## 特殊字段识别

### 自动编号字段
包含以下关键词的字段应设置为流水号：
- 编号、单号、代码、ID
- 且通常作为主键或唯一标识

### 计算字段
包含以下关键词的字段应设置为公式：
- 合计、总计、小计、累计、总和
- 平均、均值
- 差额、差值、差异
- 百分比、占比、比例

### 关联字段
包含以下关键词的字段应设置为关联表单：
- 选择、关联、引用、对应
- 且后面通常跟随名词（如：选择产品、关联订单）

### 状态字段
包含以下关键词的字段通常为下拉单选：
- 状态、阶段、进度、类型、类别、等级、优先级
- 常见状态值：待审批/已通过/已驳回、待处理/处理中/已完成、启用/禁用

## 数值精度规则

| 字段用途 | 小数位数 | 示例 |
|---------|---------|------|
| 数量、件数 | 0位 | 库存数量【数值：0位小数】 |
| 单价、金额(元) | 2位 | 采购价格【数值：2位小数】 |
| 折扣、比率 | 1-2位 | 折扣【数值：1位小数】 |
| 百分比 | 2位 | 完成率【数值：2位小数，单位--%】 |
| 重量、体积 | 3-4位 | 重量【数值：3位小数，单位--kg】 |

## 日期时间规则

> **宜搭只有"日期"一种组件**，日期组件本身支持选择到时分秒。字段类型统一为"日期"，不需要"日期时间"类型。

| 字段命名 | 类型 | 说明 |
|---------|------|------|
| XX日期 | 日期 | 只记录日期，如：创建日期、到期日期 |
| XX时间 | 日期 | 宜搭日期组件支持到时分秒，如：创建时间、审批时间 |
| 预计XX日期 | 日期 | 计划日期 |
| 实际XX日期 | 日期 | 实际发生日期 |

## 常见业务字段对照

### 基础信息类
- 创建人 → 【成员】
- 创建时间 → 【日期】
- 更新人 → 【成员】
- 更新时间 → 【日期】
- 所属部门 → 【部门】

### 审批流程类
- 审批状态 → 【下拉单选：待审批/审批中/已通过/已驳回】
- 审批人 → 【成员】
- 审批时间 → 【日期】
- 审批意见 → 【多行文本】

### 库存管理类
- 库存数量 → 【数值：0位小数】
- 安全库存 → 【数值：0位小数】
- 入库数量 → 【数值：0位小数】
- 出库数量 → 【数值：0位小数】
- 当前库存 → 【数值：0位小数】

### 财务类
- 单价 → 【数值：2位小数】
- 数量 → 【数值：0位小数】
- 金额 → 【数值：2位小数，单位--元】
- 税率 → 【数值：2位小数，单位--%】
- 税额 → 【数值：2位小数，单位--元】
- 合计金额 → 【公式】
