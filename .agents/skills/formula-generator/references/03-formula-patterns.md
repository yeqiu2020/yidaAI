## 一、文本处理

### 1.1 文本拼接

```
CONCATENATE(字段1, "-", 字段2)
```

### 1.2 文本截取

```
// 从左侧截取3个字符
LEFT(字段, 3)

// 从右侧截取3个字符
RIGHT(字段, 3)

// 从第2个字符开始截取3个
MID(字段, 2, 3)
```

### 1.3 文本分割

```
// 按逗号分割，取第2个
ARRAYGET(SPLIT(字段, ","), 2)
```

## 二、日期计算

### 2.1 计算年龄

```
YEAR(NOW()) - YEAR(DATE(出生日期))
```

### 2.2 计算两个日期的天数差

```
DAYS(DATE(结束日期), DATE(开始日期))
```

### 2.3 计算两个日期的小时差（精确）

```
(结束日期 - 开始日期) / 3600000
```

### 2.4 计算7天后的日期（给日期组件赋值）

```
TIMESTAMP(DATEDELTA(DATE(开始日期), 7))
```

### 2.5 计算本月第一天

```
TIMESTAMP(DATE(CONCATENATE(YEAR(NOW()), "-", MONTH(NOW()), "-01")))
```

### 2.6 判断日期是否在今天之前

```
LT(DATE(日期字段), TODAY())
```

### 2.7 计算工作日天数

```
NETWORKDAYS(DATE(开始日期), DATE(结束日期))
```

### 2.8 计算下个月同一天

```
TIMESTAMP(DATE(YEAR(DATE(提交日期)), MONTH(DATE(提交日期))+1, DAY(DATE(提交日期))))
```

## 三、逻辑判断

### 3.1 简单条件判断

```
IF(GT(成绩, 60), "及格", "不及格")
```

### 3.2 多条件判断（嵌套IF）

```
IF(GT(分数, 90), "优秀", IF(GT(分数, 60), "及格", "不及格"))
```

### 3.3 多条件组合（AND）

```
IF(AND(GT(年龄, 18), LT(年龄, 60)), "符合要求", "不符合")
```

### 3.4 多条件组合（OR）

```
IF(OR(EQ(状态, "已完成"), EQ(状态, "已取消")), "已结束", "进行中")
```

### 3.5 判断是否为空

```
IF(ISEMPTY(备注), "无备注", 备注)
```

## 四、数学计算

### 4.1 简单计算

```
// 加法
数量1 + 数量2

// 减法
入库数量 - 出库数量

// 乘法
单价 * 数量

// 除法
总金额 / 数量
```

### 4.2 汇总计算

```
// 求和
ADD(字段1, 字段2, 字段3)

// 平均值
AVERAGE(字段1, 字段2, 字段3)

// 最大值
MAX(字段1, 字段2, 字段3)

// 最小值
MIN(字段1, 字段2, 字段3)
```

### 4.3 四舍五入

```
ROUND(数值, 2)
```

## 五、子表处理

### 5.1 子表字段求和

```
SUMPRODUCT(子表.数量)
```

### 5.2 子表金额计算（数量×单价）

```
SUMPRODUCT(子表.数量, 子表.单价)
```

### 5.3 获取子表第一行的值

```
ARRAYGET(子表.字段, 1)
```

### 5.4 判断子表是否重复

```
ARRAYREPEATED(子表.字段)
```

## 七、格式化输出

### 7.1 金额格式化（千分位+2位小数）

```
CONCATENATE("¥", TEXT(金额, "#,##0.00"))
```

### 7.2 日期格式化

```
TEXT(日期字段, "yyyy年MM月dd日")
TEXT(日期字段, "yyyy-MM-dd HH:mm:ss")
```

### 7.3 百分比格式化

```

```

## 八、综合案例

### 8.1 合同编号自动生成

```
CONCATENATE("HT-", TEXT(YEAR(NOW()), "0000"), "-", 序号)
```

### 8.2 根据日期判断季度

```
IF(LE(MONTH(DATE(日期)), 3), "Q1",
  IF(LE(MONTH(DATE(日期)), 6), "Q2",
    IF(LE(MONTH(DATE(日期)), 9), "Q3", "Q4")))
```

### 8.3 库存预警

```
IF(LT(当前库存, 安全库存), "❌ 库存不足", "✅ 库存充足")
```

### 8.4 审批状态显示

```
IF(EQ(审批状态, "已通过"), "✅ 已通过",
  IF(EQ(审批状态, "已拒绝"), "❌ 已拒绝", "⏳ 审批中"))
```
