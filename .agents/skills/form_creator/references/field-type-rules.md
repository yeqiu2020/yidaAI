> 本文件从 SKILL.md 拆分而来（渐进式披露），包含字段类型智能判断、识别规则、括号/中括号标注解析、字段清单格式与公式场景。

## AI智能判断字段类型

**重要：不再依赖程序的正则表达式猜类型！由AI人工判断每个字段的最佳类型！**

AI会根据字段含义和业务场景判断：

| 字段含义 | 推荐类型 | 示例 |
|---------|---------|------|
| 地址信息 | **AddressField** | 仓库地址、联系地址 |
| 人员选择 | **EmployeeField** | 创建人、盘点人、负责人 |
| 部门选择 | **DepartmentSelectField** | 所属部门、归属部门 |
| 关联其他表单 | **AssociationFormField** | 产品分类、盘点仓库 |
| 日期/时间 | **DateField** | 创建时间、入库时间 |
| 数字/金额 | **NumberField** | 数量、价格、库存 |
| 下拉选项 | **SelectField** | 类型、状态、品牌 |
| 长文本 | **TextareaField** | 备注、说明 |
| 短文本 | **TextField** | 名称、编码、规格 |

## 字段类型识别规则（必须遵守）

### 1. 部门字段优先识别规则

**规则**：字段名包含"部门"关键词时，必须识别为 **DepartmentSelectField**，且优先于人员字段判断。

```javascript
// 正确顺序
if (name.includes('部门')) {
  return { name, type: 'DepartmentSelectField', required: false };
}
if (name.includes('人') || name.includes('员') || name.includes('负责人') || name.includes('管理员')) {
  return { name, type: 'EmployeeField', required: false };
}
```

**示例**：
- "所属部门" → DepartmentSelectField
- "归属部门" → DepartmentSelectField
- "部门主管" → DepartmentSelectField（不是EmployeeField）

### 2. 地址字段识别规则

**规则**：字段名包含"地址"、"省市"、"省市区"时，必须识别为 **AddressField**。

**示例**：
- "仓库地址" → AddressField
- "联系地址" → AddressField
- "省市区" → AddressField

### 3. 关联表单字段名清理规则

**规则**：解析关联表单字段时，必须去掉字段名中的"（关联表单）"后缀。

```javascript
// 清理字段名
name = name.replace(/（关联表单）$/, '');
```

**示例**：
- Markdown: `选择产品（关联表单）【关联表单-->产品信息】`
- 生成的label: "选择产品"（不含"（关联表单）"）

### 4. 数值字段单位配置规则

**规则**：数值字段标注格式为 `【数值：N位小数，单位--XXX】`，单位通过 `innerAfter` 属性配置。

**示例**：
- `【数值：2位小数，单位--元】` → NumberField + innerAfter: "元"
- `【数值：1位小数】` → NumberField（无单位）

### 5. 子表格式支持规则

**规则**：必须同时支持两种子表格式：
- `2.子表#盘点明细#字段：` → 子表名称为"盘点明细"
- `2.子表1字段：` → 子表名称为"子表1"

## 字段括号说明解析（Excel来源）

Excel中的字段名可以包含括号说明，系统会自动解析并生成对应的字段类型：

### 1. 字段类型说明（括号内是类型）

| 括号内容 | 识别为 | 生成的字段类型 | 示例 |
|---------|--------|--------------|------|
| `流水号` | 类型说明 | **SerialNumberField** | 客户编号（流水号） |
| `数值`、`数字` | 类型说明 | **NumberField** (precision: 0) | 下单周期（数值） |
| `日期` | 类型说明 | **DateField** | 创建日期（日期） |
| `时间` | 类型说明 | **DateField** (showTime: true) | 入库时间（时间） |
| `金额`、`价格` | 类型说明 | **NumberField** (precision: 2) | 总金额（金额） |
| `多行` | 类型说明 | **TextareaField** | 备注（多行） |
| `附件` | 类型说明 | **AttachmentField** | 合同（附件） |
| `图片` | 类型说明 | **ImageField** | 照片（图片） |

### 2. 选项值说明（括号内是选项，用/或、分隔）

| 选项数量 | 生成的字段类型 | 示例 |
|---------|--------------|------|
| ≤ 3个选项 | **RadioField**（单选按钮） | 是否关联（是/否） |
| > 3个选项 | **SelectField**（下拉单选） | 交货状态（未交货/发货中/正常交货/逾期交货/逾期未交货） |

**选项解析示例：**
- `交易币种（人民币/美元）` → RadioField，选项：[人民币, 美元]
- `跟进结果（需求确认/交付定金）` → RadioField，选项：[需求确认, 交付定金]
- `税率批量设置（普票/13%/9%/6%/1%）` → SelectField，选项：[普票, 13%, 9%, 6%, 1%]

### 3. 解析规则总结

```
字段名（括号内容）
    ↓
括号内容包含 / 或 、 ?
    ↓ 是                    ↓ 否
选项值（用/或、分隔）    类型说明
    ↓                        ↓
选项数量 ≤ 3 ?           根据类型映射
    ↓ 是        ↓ 否       到对应字段类型
RadioField  SelectField
```

### 4. 使用建议

在Excel中编写字段时，建议：
1. **流水号字段**：添加`（流水号）`说明，如 `订单编号（流水号）`
2. **选项字段**：在括号中列出所有选项，用`/`分隔，如 `审批状态（待审批/已通过/已驳回）`
3. **数值字段**：如果是纯数字，可添加`（数值）`说明，如 `库存量（数值）`
4. **其他字段**：无需括号，系统会根据字段名智能判断

## 字段中括号标注说明（Markdown来源）

Markdown中的字段名可以包含中括号标注，系统会自动解析：

| 标注格式 | 识别为 | 生成的字段类型 | 示例 |
|---------|--------|--------------|------|
| `【流水号】` | 流水号 | **SerialNumberField** | 客户编号【流水号】 |
| `【关联表单-->表单名】` | 关联表单 | **AssociationFormField** | 选择产品【关联表单-->产品信息】 |
| `【下拉单选：选项1/选项2】` | 下拉选项 | **SelectField** | 付款方式【下拉单选：现金/对公】 |
| `【单选：选项1/选项2】` | 单选选项 | **RadioField** | 是否关联【单选：是/否】 |
| `【数值：N位小数】` | 数值 | **NumberField** (precision: N) | 库存量【数值：0位小数】 |
| `【数值：N位小数，单位--元】` | 金额 | **NumberField** (precision: N, unit: 元) | 总金额【数值：2位小数，单位--元】 |

## 字段清单格式规范

### 前置条件

1. Markdown 文件放置在 `流程及字段梳理/项目名称/` 目录下
2. 支持两种格式：
   - **表格格式**（推荐）：字段名称、字段类型、字段说明、字段状态、是否必填
   - **列表格式**：1.主表字段：字段1、字段2...

### 表格格式字段清单（推荐，v6.1.0新增）

| 列名 | 说明 | 示例值 |
|------|------|--------|
| **字段名称** | 字段显示名称 | 采购单号、供应商 |
| **字段类型** | 宜搭字段类型 | 单行文本、数值、日期、关联表单 |
| **字段说明** | 字段详细说明 | 关联-->供应商信息、2位小数，单位：元 |
| **字段状态** | 编辑/只读/隐藏 | 编辑、只读、隐藏 |
| **是否必填** | 是/否 | 是、否 |

#### 字段状态映射

| 字段清单值 | 生成的JSON属性 |
|-----------|---------------|
| 编辑 | `"behavior": "NORMAL"` |
| 只读 | `"behavior": "DISABLED"` |
| 隐藏 | `"behavior": "HIDDEN"`, `"hidden": true` |

#### 是否必填映射

| 字段清单值 | 生成的JSON属性 |
|-----------|---------------|
| 是 | `"validation": [{"type": "required"}]` |
| 否 | `"validation": []` |

#### 表格格式示例

```markdown
### (一) 采购订单「流程表单」

| 字段名称 | 字段类型 | 字段说明 | 字段状态 | 是否必填 |
|---------|---------|---------|---------|---------|
| 采购单号 | 流水号 | 自动生成，前缀：CGDD，示例：CGDD20260702001 | 只读 | 否 |
| 采购日期 | 日期 | - | 编辑 | 是 |
| 供应商 | 关联表单 | 关联-->供应商信息 | 编辑 | 是 |
| 采购金额 | 数值 | 2位小数，单位：元，公式计算 | 只读 | 否 |
| 备注 | 多行文本 | - | 编辑 | 否 |
| 创建人 | 成员 | 系统自动生成 | 只读 | 是 |
| 创建时间 | 日期时间 | 系统自动生成 | 只读 | 是 |

**子表：采购明细**

| 字段名称 | 字段类型 | 字段说明 | 字段状态 | 是否必填 |
|---------|---------|---------|---------|---------|
| 选择产品 | 关联表单 | 关联-->产品信息；填充：产品名称=产品名称 | 编辑 | 是 |
| 产品名称 | 单行文本 | - | 只读 | 是 |
| 采购数量 | 数值 | 0位小数 | 编辑 | 是 |
| 采购单价 | 数值 | 2位小数，单位：元 | 编辑 | 是 |
| 采购金额 | 数值 | 2位小数，单位：元，公式计算 | 只读 | 是 |
```

### 列表格式（兼容旧版）

Markdown 格式要求：
- 第一行标题：`# 系统名称 - 说明`
- 模块标题：**一、模块名称**
- 表单标题：(一).表单名称
- 主表字段：1.主表字段：字段1、字段2...
- 子表字段：2.子表#子表名称#字段：字段1、字段2...

**列表格式完整示例：**

```markdown
# 出入库管理 - 表单字段清单

> 版本: 1.0.1
> 生成日期: 2026/2/28

---

**一、基础信息**

    (一).产品类别
       1.主表字段：产品分类

    (二).产品信息
       1.主表字段：产品名称、产品分类【关联表单-->产品类别】、品牌、产品规格、单位、建议零售价格【数值：1位小数，单位--元】

**二、库存管理**

    (一).库存盘点
       1.主表字段：盘点人、所属部门、盘点仓库【关联表单-->仓库信息】
       2.子表#盘点明细#字段：选择产品【关联表单-->产品信息】、产品名称、库存量【数值：0位小数】、盘点数量【数值：0位小数】
```

## 公式与关联识别

**公式计算**：
- "自动计算"、"根据...计算" → 公式字段
- 常见计算：年龄、工龄、总价、天数、金额汇总

**表关联**：
- "关联...表"、"引用..." → 关联字段
- "子表"、"明细" → 子表单

### 支持的公式场景

**日期计算**：
- 年龄：`DATEDIF({出生日期},TODAY(),"Y")`
- 工龄：`DATEDIF({入职日期},TODAY(),"Y")`
- 天数：`DATEDIF({开始日期},{结束日期},"D")+1`

**数值计算**：
- 总价：`{单价}*{数量}`
- 汇总：`SUM({字段1},{字段2},{字段3})`
- 金额大写：需要自定义函数

**身份证相关**：
- 生肖、星座、性别、出生日期：根据身份证号计算/提取

**条件判断**：
- IF语句：`IF({条件},"值1","值2")`
- AND/OR：`AND({条件1},{条件2})`、`OR({条件1},{条件2})`
