## 功能概述

本Skill是**已有宜搭项目的同步入口**，整合了多个同步技能，提供一站式同步能力：

| 整合的Skill | 同步内容 | 输出文件 |
|------------|---------|---------|
| **config-sync** | 应用ID、表单UUID、组件ID | 系统配置清单.md、组件ID清单.md |
| **get-schema** | 表单结构 Schema | 表单JSON文件、表单结构变更.md |
| **rule-sync** | 公式、联动规则、校验规则、动作代码 | 系统规则清单.md |

### 使用场景

1. **已有项目同步**：用户在宜搭平台已搭建部分功能，需要同步到本地
2. **项目迁移**：将宜搭应用完整迁移到本地开发环境
3. **定期备份**：定期同步线上配置到本地备份
4. **团队协作**：团队成员同步同一应用的最新配置

## 工作流程

```
用户提供宜搭应用ID和项目目录
    ↓
验证应用ID有效性
    ↓
步骤1: 同步应用配置（config-sync）
    - 获取应用信息
    - 获取表单列表
    - 获取组件ID
    - 生成系统配置清单
    ↓
步骤2: 同步表单结构（get-schema）
    - 获取每个表单的Schema
    - 生成JSON文件
    - 生成结构变更记录
    ↓
步骤3: 同步业务规则（rule-sync）
    - 获取表单公式
    - 获取联动规则
    - 获取校验规则
    - 获取动作代码
    - 生成系统规则清单
    ↓
完成，输出同步报告
```

## 使用方式

### 方式一：AI 对话模式（推荐）

用户只需告诉 AI 要同步哪个项目，AI 会自动从系统配置清单读取应用ID：

```
用户：同步【叶秋功能测试】项目
AI：读取 叶秋功能测试/系统配置清单.md → 获取应用ID → 执行同步
```

### 方式二：命令行调用

#### 首次同步（需要提供应用ID）

```bash
# 首次同步，指定应用ID
yida-helper run project-sync/scripts/sync_project.js \
  --appId APP_YA1204PFH4K3MRARR1E3 \
  --output ./叶秋功能测试
```

#### 更新同步（从配置清单读取应用ID）

```bash
# 更新同步，自动从配置清单读取应用ID
yida-helper run project-sync/scripts/sync_project.js \
  --output ./叶秋功能测试
```

### 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--appId` | 否 | 宜搭应用ID，如 `APP_YA1204PFH4K3MRARR1E3`。首次同步必填，后续可从配置清单读取 |
| `--output` | 是 | 项目输出目录，如 `./叶秋功能测试` |
| `--skip-schema` | 否 | 跳过表单结构同步 |
| `--skip-rules` | 否 | 跳过业务规则同步 |
| `--help` | 否 | 显示帮助信息 |

### 编程调用

```javascript
const { syncProject } = require('./scripts/sync_project');

// 同步项目
const result = await syncProject({
  appId: 'APP_YA1204PFH4K3MRARR1E3',
  outputDir: './叶秋功能测试'
});

console.log(result);
// {
//   success: true,
//   appId: 'APP_YA1204PFH4K3MRARR1E3',
//   appName: '叶秋功能测试',
//   formsCount: 5,
//   syncSteps: [...]
// }
```

## 前置依赖

- Node.js >= 16
- 已安装并配置 `api-client`（用于API调用）
- 已安装 `config-sync`（用于配置同步）
- 已安装 `get-schema`（用于结构同步）
- 已安装 `rule-sync`（用于规则同步）
- 宜搭平台登录态（首次使用需要扫码登录）

## 注意事项

1. **首次使用需要登录**：确保已运行过 api-client 的登录流程
2. **应用ID正确性**：请确保提供的应用ID正确且有访问权限
3. **网络连接**：需要能够访问宜搭平台
4. **目录权限**：确保有写入输出目录的权限
5. **增量同步**：重复同步会覆盖本地文件，但会保留变更历史

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 应用ID无效 | 提示用户检查应用ID |
| 登录态失效 | 自动触发重新登录 |
| 单个表单同步失败 | 记录错误，继续同步其他表单 |
| 网络异常 | 重试3次后报错 |
| 目录无写入权限 | 提示用户检查目录权限 |
