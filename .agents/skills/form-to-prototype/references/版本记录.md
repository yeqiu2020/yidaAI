# form-to-prototype 版本记录

> 当前版本见 [../SKILL.md](../SKILL.md)。

| 版本 | 日期 | 更新内容 |
|-----|------|---------|
| 2.17.0 | 2026/07/17 | **【关键修复】同步功能应用匹配问题**：1) `syncForm` 函数新增 `projectDir` 参数传递，从页面URL自动计算项目目录；2) 支持 HTTP 和 file 协议两种访问方式；3) 后端 `findProjectDir` 优先使用传入的 `projectDir`，避免多个应用有相同表单名时匹配错误；4) 修复后确保进销存1/2/3/5/8等任意数量应用都能正确同步各自表单 |
| 2.16.0 | 2026/07/07 | **路径兼容性修复**：1) `loadFormListFromConfig` 总是用最新分组信息覆盖 formPaths（修复旧版原型页面路径不匹配问题）；2) `loadFormConfig` fetch 失败时回退到 staticConfigData 而非返回空配置；3) 分组目录加「分组」后缀对齐 |
| 2.15.0 | 2026/07/07 | **菜单图标与折叠优化**：1) 无分组表单（含 `系统配置清单.md` 第5列 `-`/`—` 占位符）不强行分组，直接以扁平项显示带 📄 图标；2) 分组标题加 📁 文件夹图标和 ▼/▲ 上下箭头，点击可折叠/展开；3) 普通表单用 📄 图标、流程表单用 🔄 图标替代原 ▸ 绿色箭头；4) 移除 `.menu-item.process::before` CSS 规则；5) 新增 `toggleGroup()`/`getFormIcon()` 函数；6) 多层防御性归一化 `-`/`—` 占位符（`loadFormListFromConfig`/`generateStaticConfigData`/`generateFormConfigDataJs`/`renderMenu`） |
| 2.14.0 | 2026/07/07 | **菜单按分组渲染**：`renderMenu()` 按 `group` 字段聚合输出多个 `.menu-group` 块；配置数据追加 `group` 字段并回填；4 个 HTML 模板移除硬编码 `业务表单` 包裹；`renderQuickLinks` 卡片显示分组名 |
