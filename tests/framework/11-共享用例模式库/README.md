# 共享用例模式库

> **定位：** 跨应用复用的测试用例模板，每个模式含通用场景+占位符，实例化时替换为应用的实际值
> **使用方式：** AI 在执行 `05-应用适配流程.md` 第5步"用例库生成"时，从本库选取模式 → 填充占位符 → 输出到 `{应用目录}/用例库.md`
> **配套文档：** [05-应用适配流程.md](../05-应用适配流程.md) · [04-测试场景设计原则.md](../04-测试场景设计原则.md)

## 占位符说明

实例化时需替换的通用占位符：

| 占位符 | 含义 | 数据来源 |
|--------|------|---------|
| `{应用名称}` | 宜搭应用名称 | 用户输入 |
| `{应用ID}` | 宜搭应用 ID（APP_XXXXX） | 系统配置清单.md |
| `{表单名称}` | 被测表单名称 | 字段清单.md |
| `{表单UUID}` | 被测表单 UUID | 系统配置清单.md |
| `{字段名称}` | 被测字段名称 | 字段清单.md |
| `{字段ID}` | 被测字段 ID | 系统配置清单.md / 组件ID清单.md |
| `{公式表达式}` | 宜搭公式表达式 | 规则清单.md |
| `{预期值}` | 公式/计算的预期结果 | AI 根据公式推导 |
| `{目标表单}` | 关联表单字段指向的表单 | 字段清单.md |
| `{关联字段名}` | 关联表单字段名称 | 字段清单.md |
| `{测试数据}` | 提交的测试数据 JSON | AI 根据字段清单生成 |
| `{审批节点}` | 流程审批节点名称 | 流程配置 |
| `{规则类型}` | 业务规则类型（INSERT/UPDATE/DELETE/UPSERT） | 规则清单.md |

## 实例化流程

```
1. AI 读取目标应用的 字段清单.md + 规则清单.md + 系统配置清单.md
2. 根据应用能力域，从本库选取适用的模式（参考 05-应用适配流程.md 第2步）
3. 对每个模式：
   a. 替换占位符为该应用的实际值
   b. 根据字段类型补充测试数据
   c. 根据公式/规则补充预期值
4. 输出到 {应用目录}/用例库.md
5. 从用例库中选取 P0 场景，生成 Smoke 回归集
```
