# 宜搭项目创建工具


## ⚠️ 重要声明（必须遵守）

**本Skill只创建项目目录结构，绝不直接创建表单！**

- ❌ 禁止自动生成表单JSON
- ❌ 禁止自动调用form\_creator技能
- ❌ 禁止自动创建宜搭应用
- ✅ 只创建项目目录和基础文档

表单创建必须在用户明确确认后，单独调用form\_creator技能执行。

***

## 功能说明

根据用户需求，自动创建标准化的宜搭项目目录结构。

**创建的目录结构：**

```
项目名称/
├── 01需求梳理/          # 存放需求文档和字段清单
├── 系统配置清单.md       # 记录宜搭应用的配置信息（初始为空，后续同步更新）
└── README.md            # 项目说明文档
```

**特点：**

- **自动读取应用ID**：从「组织及应用信息.md」自动匹配并填入应用ID
- 统一创建系统配置清单（自动填入已知的应用ID和CorpId）
- 项目开发提示词.md 位于根目录，所有项目共用
- 后续通过 `config-sync` 技能同步宜搭应用信息
- 适合所有项目场景（新项目或已有项目）
- 支持AI智能分组（同步时自动分类表单到2-3个分组）

***

当用户输入包含以下任何一种表述时，**必须立即调用此Skill**：

| 触发关键词      | 示例               |
| ---------- | ---------------- |
| "创建一个项目"   | "创建一个项目，项目信息为【】" |
| "初始化项目"    | "初始化项目：客户管理系统"   |

**重要**：

1. 只要用户提到"创建项目"、"初始化"、"新建系统"等关键词，无论是否有字段清单，都必须先调用此Skill创建项目基础结构
2. **绝不直接创建表单** - 这是铁律
3. 创建完项目后，询问用户是否需要生成表单，而不是自动执行

## 配置同步说明

创建项目后，系统配置清单会自动填入从「组织及应用信息.md」读取的应用ID和CorpId（如果存在）。

如果应用ID未找到或需要更新，使用以下命令同步配置：

```bash
# 统一同步（推荐）- 同步应用ID、表单UUID、组件ID、表结构
node .agents/skills/config-sync/scripts/sync_all_configs.js "项目名称/01需求梳理/字段清单.md" "APP_XXX"

# 或分步同步
# 步骤1：同步系统配置清单
node .agents/skills/config-sync/scripts/sync_config.js --appId "APP_XXX" --output "项目名称"

# 步骤2：同步表单结构及组件ID
node .agents/skills/config-sync/scripts/sync_form_schemas.js "项目名称/01需求梳理/字段清单.md" "APP_XXX"
```

同步内容：

1. **应用ID** - 宜搭应用的唯一标识
2. **表单UUID** - 各个表单的UUID
3. **组件ID** - 表单字段的fieldId
4. **表结构** - 表单的完整Schema结构
