## 表单更新日志详细规范

### 文件内容结构

表单更新日志必须包含以下章节：

#### 1. 更新概览
- 总更新次数
- 当前表单总数
- 累计新增/删除/更名表单数量统计

#### 2. 详细更新记录（倒序排列）

每个版本一条记录，包含：

**头部信息**
- 版本号（与系统配置清单一致）
- 更新日期
- 同步类型（表单列表同步/表单结构同步/本地文件夹清理/应用创建）
- 操作人

**变更统计**
- 新增表单数量
- 删除表单数量
- 更名表单数量
- 保持一致的表单数量

**详细清单**
 - ➕ 新增表单：表单名称、类型、表单UUID
 - 🗑️ 删除表单：表单名称、类型、删除原因
 - 📝 更名表单：原名称 → 新名称（如有）
 - ➖ 无变化：表单名称、组件数量、子表字段（结构同步时）

#### 3. 表单变更趋势
- 时间线形式的变更趋势图
- 直观展示表单数量变化

#### 4. 相关文件链接
- 链接到系统配置清单
- 链接到表单清单

### 对话框展示要求（日志部分）

同步完成后，在对话框中必须：
1. 告知用户表单更新日志已生成/更新
2. 展示本次更新的摘要信息（新增/删除/更名数量）
3. 提供表单更新日志文件的链接

示例：
```markdown
✅ **表单更新日志已更新！**

本次同步记录已追加到表单更新日志：
- [表单更新日志.md](file:///path/to/表单更新日志.md)

**本次变更摘要**:
- 新增表单: 2 个
- 删除表单: 0 个
- 更名表单: 0 个
- 保持一致: 8 个
```
