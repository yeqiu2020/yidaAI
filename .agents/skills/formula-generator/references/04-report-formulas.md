## 一、使用场景

- 原始表单数据需要自定义处理后展示
- 统计每天填写表单的员工人数（使用 COUNT()函数计算）
- 新增自定义字段关联超链接做页面跳转

---

## 二、设置公式入口

**路径**: 新建报表 >> 报表设计页 >> 选择数据集 >> 选择显示列字段 >> FX >> 设置对应公式

## 三、重要区分

| 特性 | 表单公式 | 报表公式 |
|------|---------|---------|
| **使用场景** | 表单字段计算、校验 | 报表数据集计算、展示 |
| **函数体系** | 独立函数集 | 独立函数集（部分与表单不同）|
| **语法风格** | 函数式（Excel风格） | SQL风格（部分函数）|
| **字段引用** | 字段显示名/ID | 数据集字段名 |

**⚠️ 警告**: 表单场域和报表场域的函数**不通用**！

## 四、逻辑判断类

### 4.1 CASEWHEN 条件函数

**用法1**: `CASEWHEN(<条件>,<值>,<条件>,<值>.....)`

类同SQL中的case when语法。

示例：
```
CASEWHEN(性别="男","male",性别="女","female")
```
则该字段值为"男"的被替换为"male"，"女"替换为"female"。

**用法2**: `CASEWHEN(<条件>,<值>,<条件>,<值>.....<值>)`

类同SQL中的case when语法，最后一个值为默认值。

示例：
```
CASEWHEN(性别="男","male","female")
```
则该字段值为"男"的被替换为"male"，非"男"替换为"female"。

### 4.2 逻辑运算符

| 函数 | 含义 | 示例 |
|------|------|------|
| `AND` | 且 | `CASEWHEN(字段1="A" AND 字段2="B",1,2)` |
| `OR` | 或 | `CASEWHEN(字段1="A" OR 字段2="B",1,2)` |
| `NOT` | 非 | `CASEWHEN(NOT(字段="A"),1,2)` |

### 4.3 比较运算符

| 标识符 | 含义 | 示例 |
|--------|------|------|
| `=` | 等于 | `字段="值"` |
| `!=` | 不等于 | `字段!="值"` |
| `IS NULL` | 为空 | `字段 IS NULL` |
| `IS NOT NULL` | 不为空 | `字段 IS NOT NULL` |

| `RIGHT` | `RIGHT(<字段>,<n>)` | `RIGHT("ABCDEF",3)` | `"DEF"` |

## 六、聚合类

### 6.1 SUM

**用法**: `SUM(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>进行求和的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
部门团建费 = SUM(费用, 预算类型="团建费")
BU团建费 = SUM(费用, 预算类型="团建费", 部门)
```

### 6.2 AVG

**用法**: `AVG(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>进行求平均的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
BU平均团建费 = AVG(费用, 预算类型="团建费",部门)
所有部门平均团建费 = AVG(费用, 预算类型="团建费",部门,BU)
```

### 6.3 MAX

**用法**: `MAX(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>求最大值的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
部门最高团建费 = MAX(费用, 预算类型="团建费")
BU最高团建费 = MAX(费用, 预算类型="团建费", 部门)
```

### 6.4 MIN

**用法**: `MIN(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>求最小值的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
部门最低团建费 = MIN(费用, 预算类型="团建费")
BU最低团建费 = MIN(费用, 预算类型="团建费", 部门)
```

### 6.5 COUNT

**用法**: `COUNT(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>进行计数的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
部门预算条数 = COUNT(部门, 费用>0,预算类型)
```

### 6.6 COUNTDISTINCT

**用法**: `COUNTDISTINCT(<度量字段>,[条件],[排除字段])`

**说明**: 返回合乎[条件]下, 对<字段>进行去重计数的结果, [排除字段] 不参与求和的交叉计算。

**注意**: 目前报表类聚合函数暂不支持进行逻辑运算。

示例：
```
BU部门数量 = COUNTDISTINCT(部门, 费用>0,预算类型)
```

### 6.7 SUMPRODUCTX

**用法**: 
```
SUMPRODUCTX(<数组字段1>, <数组字段2>)
```

**说明**: 对两个数组进行乘积求和。

示例：
```
SUMPRODUCTX(子表.数量, 子表.单价)
```

### 6.8 MAPX

**用法**: 
```
MAPX(映射表, 查找值, 返回字段)
```

**说明**: 根据映射表进行数据映射转换。

## 七、时间处理类

| 函数 | 用法 | 示例 | 说明 |
|------|------|------|------|
| `NOW` | `NOW()` | - | 获取当前时间，精确到秒 |
| `STRINGTODATE` | `STRINGTODATE(<字段>,<格式>)` | `STRINGTODATE("1989-09-27","yyyy-MM")` | 字符串转时间 |
| `DATEADD` | `DATEADD(<时间字段>,<偏移量>,<时间粒度>)` | `DATEADD(日期,10,"DAY")` | 日期加减 |
| `DATEDIFF` | `DATEDIFF(<时间字段1>,<时间字段2>,<时间粒度>)` | `DATEDIFF(日期1,日期2,"DAY")` | 日期差 |
| `DATEFORMAT` | `DATEFORMAT(<日期字段>,<时间格式>)` | `DATEFORMAT(日期,"yyyy-MM-dd")` | 格式化日期 |

## 十、与表单公式的差异

| 功能 | 表单公式 | 报表公式 |
|------|---------|---------|
| 条件判断 | `IF(条件,真值,假值)` | `CASEWHEN(条件,值,...)` |
| 文本拼接 | `CONCATENATE(文本1,文本2)` | `CONCAT(字段1,字段2)` |
| 数组获取 | `ARRAYGET(数组,位置)` | 无直接对应 |

## 十一、常见问题

### 1. 公式解析异常：AST语法异常

**问题**: 报错提示"SQL翻译时遇到未支持的数据库类型：11"

**原因**: 使用了文档以外的函数公式

**解决**: 只能使用本文档中列出的函数，不能使用表单场域的函数

### 2. CASEWHEN函数判断为空不生效

**问题**: `数据=""` 的写法不生效

**解决**: 使用 `数据 IS NULL` 的写法
