## 🐛 问题描述

### 现象
生成的宜搭表单中，子表（TableField）宽度超出页面范围，未正常显示横向滚动条。

### 对比
- **正常情况**（宜搭直接创建的子表）：子表宽度适应页面，字段多时出现横向滚动条
- **异常情况**（生成器生成的子表）：子表超出页面右侧边界，整体布局错乱

## 🔍 根本原因分析

### 第一轮修复（不完整）
**修改**: `tableLayout: "auto"` → `tableLayout: "fixed"`
**结果**: 部分改善，但问题依然存在

### 深入分析
通过对比宜搭标准格式 `含子表字段格式.json`，发现关键差异：

```javascript
// ❌ 错误配置（我们的代码）
{
  "__gridSpan": 2,      // 子表占据2列宽度
  "tableLayout": "auto" // 自动调整宽度
}

// ✅ 标准配置（宜搭格式）
{
  "__gridSpan": 1,      // 子表只占1列
  "tableLayout": "fixed" // 固定列宽
}
```

### 问题根源
1. **`__gridSpan` 设置错误**：
   - 设置为 `2` 导致子表占据2倍列宽
   - 在标准页面布局中，单列已经是全宽
   - 占据2列会导致宽度超出页面

2. **`tableLayout` 设置错误**：
   - `"auto"` 会根据内容自动调整列宽
   - 当字段多或内容长时，会无限扩展
   - 应该使用 `"fixed"` 固定列宽

## ✅ 修复方案

### 修复1: tableLayout 设置
**文件**: `yida_field_templates.js`
**位置**: 第614行
**修改**:
```javascript
// ❌ 修改前
tableLayout: 'auto',

// ✅ 修改后
tableLayout: 'fixed',
```

### 修复2: __gridSpan 设置
**文件**: `yida_field_templates.js`
**位置**: 第592行
**修改**:
```javascript
// ❌ 修改前
__gridSpan: config.gridSpan || 2, // 子表默认占2列

// ✅ 修改后
__gridSpan: config.gridSpan || 1, // 子表默认占1列（标准格式）
```
