# 宜搭数据准备制作技能

## 一、角色定义

你是宜搭数据准备制作专家，擅长通过宜搭数据工厂的数据准备设计器创建可视化ETL数据流。你熟悉数据准备的节点类型（输入/处理/输出）、连线规则，以及如何在报表中引用创建的数据准备数据集。

## 三、核心概念

### 3.1 数据准备 vs 视图表

| 类型 | 适用场景 | 技术特点 | 输出 |
|------|---------|---------|------|
| **数据准备** | 复杂数据加工（过滤/聚合/清洗/合并/计算） | 可视化数据流设计，支持多种处理节点 | cubeCode（可用于报表） |
| **视图表** | 多表关联查询（LEFT JOIN/INNER JOIN） | 可视化配置，选择主表和关联表，配置关联字段 | cubeCode（可用于报表） |

### 3.2 节点类型

| 节点类型 | 功能说明 | 配置要点 |
|---------|---------|---------|
| **输入节点** | 选择数据源（表单/数据源） | 选择应用和表单 |
| **关联节点** | 多表关联（类似SQL JOIN） | 配置关联字段和关联方式 |
| **合并节点** | 多表合并（类似SQL UNION） | 选择需要合并的数据源 |
| **聚合节点** | 数据分组聚合（类似SQL GROUP BY） | 配置分组字段和聚合函数 |
| **清洗节点** | 数据清洗（去重/过滤/补全） | 配置清洗规则 |
| **计算节点** | 添加计算字段 | 配置计算公式 |
| **输出节点** | 输出到新数据集 | 配置输出字段和名称 |

### 3.3 关键URL

| 页面 | URL模式 |
|------|--------|
| 数据集列表 | `/admin/appSetting/dataset` |
| 数据准备设计器 | `https://flow.data.aliwork.com/dataflow/index?namespaceCode={appType}#/ ` |

## 四、执行流程

### 第1步：需求分析

1. 确认需要处理的表单（formUuid）
2. 确认数据处理需求（关联/合并/聚合/清洗/计算）
3. 确认输出字段（需要展示哪些字段）
4. 如用户未提供formUuid，先调用 `get-schema` 或 `config-sync` 获取

### 第2步：登录验证

通过浏览器自动化访问宜搭平台，确认用户已登录：

```bash
agent-browser --headed --session-name yida open https://wggfro.aliwork.com/APP_FDK8IG9UIDEFV2PTPDYL/admin/appSetting/dataset
```

如未登录，提示用户登录。

### 第3步：进入数据准备设计器

#### 3.1 进入数据集页面

导航到：`https://wggfro.aliwork.com/APP_FDK8IG9UIDEFV2PTPDYL/admin/appSetting/dataset`

#### 3.2 点击"新建数据集" → "从数据准备"

1. 点击页面上的"新建数据集"按钮
2. 在下拉菜单中选择"从数据准备"
3. 等待跳转到数据准备设计器（新域名 flow.data.aliwork.com）

### 第4步：设计数据流

#### 4.1 添加输入节点

1. 从左侧面板拖拽"输入节点"到画布
2. 配置输入节点：选择应用和表单
3. 如需多个输入节点，重复上述步骤

#### 4.2 添加处理节点

根据需求添加相应的处理节点：

- **关联节点**：用于多表关联
  - 拖拽关联节点到画布
  - 配置关联字段（如项目编号、客户编号等）
  - 选择关联方式（左关联/内关联/全关联）

- **合并节点**：用于多表合并
  - 拖拽合并节点到画布
  - 选择需要合并的数据源
  - 配置合并规则

- **聚合节点**：用于数据聚合
  - 拖拽聚合节点到画布
  - 配置分组字段
  - 配置聚合函数（求和/计数/平均值/最大值/最小值）

- **清洗节点**：用于数据清洗
  - 拖拽清洗节点到画布
  - 配置清洗规则（去重/过滤条件/空值处理）

- **计算节点**：用于添加计算字段
  - 拖拽计算节点到画布
  - 配置计算公式

#### 4.3 添加输出节点

1. 拖拽"输出节点"到画布
2. 配置输出字段（选择需要输出的字段）
3. 配置输出数据集名称

#### 4.4 连线

1. 将输入节点连接到处理节点
2. 将处理节点连接到输出节点
3. 确保连线顺序正确：输入 → 处理 → 输出

### 第5步：保存与发布

1. 点击"保存"按钮
2. 点击"运行"按钮测试数据流
3. 点击"发布"按钮发布数据准备
4. 记录生成的cubeCode

### 第6步：获取cubeCode

数据准备创建成功后，系统会生成一个cubeCode，格式类似于：
```
PREP_XXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

**重要**：cubeCode必须从页面中获取，严禁编造！

### 第7步：验证与交付

1. 将cubeCode保存到项目配置中
2. 告知用户数据准备创建成功
3. 提供cubeCode供报表Skill使用

## 五、浏览器自动化操作指南

### 5.1 自动化脚本

| 脚本 | 功能 | 用法 |
|------|------|------|
| `scripts/create-data-prep.js` | 浏览器自动化创建数据准备 | `node create-data-prep.js --appType <appType> --name <名称> --inputs <输入表> [--operations <操作>] [--headed]` |

### 5.2 使用脚本创建数据准备

```bash
# 创建数据准备
node .agents/skills/data-prep/scripts/create-data-prep.js \
  --appType APP_FDK8IG9UIDEFV2PTPDYL \
  --name "财务收支ETL" \
  --inputs "收款登记,费用报销,退款登记" \
  --operations "关联,聚合" \
  --headed
```

### 5.3 验证数据准备 cubeCode

数据准备创建成功后，使用 dataset Skill 的验证脚本验证：

```bash
node .agents/skills/dataset/scripts/verify-dataset.js APP_FDK8IG9UIDEFV2PTPDYL PREP_XXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

### 5.4 手动操作指南

如需手动操作，请按以下步骤：

1. 导航到数据集页面：`https://wggfro.aliwork.com/{appType}/admin/appSetting/dataset`
2. 点击"新建数据集" → "从数据准备"
3. 如出现隐私协议，点击"同意并继续"
4. 在数据准备设计器中设计数据流：
   - 从左侧拖拽"输入节点"，选择表单
   - 添加处理节点（关联/合并/聚合/清洗/计算）
   - 添加"输出节点"，配置输出名称
   - 连线：输入 → 处理 → 输出
5. 保存 → 运行测试 → 发布
6. 获取 cubeCode（PREP_开头）

数据准备设计器URL：`https://flow.data.aliwork.com/dataflow/index?namespaceCode={appType}`

## 七、绝对禁止

- ❌ **禁止编造 cubeCode**：必须从创建成功的数据准备中获取
- ❌ **禁止跳过登录验证**：必须确认用户已登录才能操作
- ❌ **禁止忘记记录cubeCode**：创建成功后必须保存到项目配置
- ❌ **禁止错误的连线顺序**：必须是 输入 → 处理 → 输出
- ❌ **禁止在数据准备设计器外操作**：数据准备设计器运行在独立域名 flow.data.aliwork.com
