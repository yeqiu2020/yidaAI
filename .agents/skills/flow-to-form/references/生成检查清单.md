> 版本: 1.0.0

## 🚨 强制性检查（必须全部通过才能生成）

### 第一阶段：流程图分析阶段

#### ✅ 检查1-1：模块识别检查
```
□ 我已识别流程图中所有模块
□ 我已按照中文大写序号（一、二、三...）排序模块
□ 我已记录每个模块下的所有节点
□ 我已区分表单节点（带📄或▶️图标）和非表单节点
```

#### ✅ 检查1-2：表单清单建立
**要求：建立模块-表单映射表**

```markdown
示例格式：

一、基础信息
├─ 产品类别 - 📄普通表单
├─ 产品信息 - 📄普通表单
└─ 仓库信息 - 📄普通表单
（共3个表单）

二、库存管理
├─ 库存盘点 - 📄普通表单
├─ 库存调拨 - 📄普通表单
├─ 其他入库 - 📄普通表单
└─ 其他出库 - 📄普通表单
（共4个表单）

...以此类推
```

**检查项：**
```
□ 我已为每个模块建立表单清单
□ 我已标注每个表单的图标类型（📄普通/▶️流程）
□ 我已统计每个模块的表单数量
□ 我已统计流程图中的表单总数：____个
```

#### ✅ 检查1-3：图标类型确认
**要求：逐个确认每个表单的图标类型**

```markdown
表单类型识别表：

| 序号 | 表单名称 | 图标颜色 | 图标形状 | 判定类型 |
|-----|---------|---------|---------|---------|
| 1   | XXX     | 蓝色    | 文档    | 普通表单 |
| 2   | XXX     | 绿色    | 播放    | 流程表单 |
```

**检查项：**
```
□ 我已逐个查看每个表单节点的图标
□ 我已记录每个表单的图标颜色和形状
□ 我已建立表单类型识别表
□ 普通表单数量：____个
□ 流程表单数量：____个
```

## 📋 快速核对表（生成前最后检查）

在生成文件前，必须回答以下问题：

```
1. 流程图中共有多少个带📄或▶️图标的表单？
   答案：____个

2. 我识别的表单数量是多少？
   答案：____个

3. 两者数量是否一致？
   答案：是/否

4. 我是否添加了流程图中没有的表单？
   答案：是/否
   如果有，是哪些：________

5. 我是否修改了任何表单名称？
   答案：是/否
   如果有，原名称是什么：________

6. 我是否调整了任何表单归属模块？
   答案：是/否
   如果有，是哪个表单：________

7. 所有表单名称是否与流程图完全一致？
   答案：是/否

8. 所有表单是否都在正确的模块下？
   答案：是/否

9. 如果以上有任何一项为"否"，我必须重新检查流程图！
   □ 我已重新检查

10. 我现在可以生成字段清单和规则清单了吗？
    答案：是/否
```

**只有当所有问题的答案都是"是"（除了第4、5、6题应该是"否"）时，才能生成文件！**

## ⚠️ 常见错误提醒

### 错误类型1：凭经验添加表单
```
❌ 错误想法："采购管理应该有供应商评估表单"
✅ 正确做法：流程图没有，就不加
```

### 错误类型2：凭经验修改名称
```
❌ 错误想法："报价单"应该改成"销售报价"更规范
✅ 正确做法：流程图叫"报价单"，就用"报价单"
```

### 错误类型3：凭经验调整归属
```
❌ 错误想法："供应商信息"应该放在基础信息里
✅ 正确做法：流程图在采购管理里，就在采购管理里
```

### 错误类型4：图标识别错误
```
❌ 错误做法：凭业务类型判断表单类型
✅ 正确做法：只看图标颜色和形状
   - 蓝色/灰色 + 文档图标 = 普通表单
   - 绿色 + 播放/三角形图标 = 流程表单
```
