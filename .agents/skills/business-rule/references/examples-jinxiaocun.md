# 进销存实战示例集（示例2、示例3）

> 本文件由 SKILL.md 下沉而来。示例1（销售出库→扣减库存）见 [../SKILL.md](../SKILL.md) 第十三节。
> 以下示例可直接用于用户的"进销存管理"应用，目标表均为 `库存信息`，业务键为 `仓库名称 + 产品名称` 组合。

## 示例2：采购入库 → 增加库存（流程表单）

- **触发表单**：采购入库（⚠️ **流程表单**，配置入口：`流程设计 → 全局设置 → 节点提交规则 → 添加规则 → 关联操作`）
- **触发事件**：节点提交（对应普通表单的 `单据提交`）
- **逻辑**：根据入库明细增加 `库存信息` 中对应仓库+产品的库存数量

```text
UPSERT(库存信息,
  AND(EQ(库存信息.仓库名称, 仓库名称), EQ(库存信息.产品名称, 产品名称)),
  "",
  库存信息.仓库名称, 仓库名称,
  库存信息.产品名称, 产品名称,
  库存信息.库存数量, 库存信息.库存数量 + 入库数量)
```

> 🔴 **子表多行自动迭代**（v3.8.0，2026-08-01 实战确认）：公式中「产品名称」和「入库数量」是来源表（采购入库）入库明细子表的字段。当入库明细有多行时，宜搭引擎会**自动对每一行逐行迭代执行**整条公式——3 行明细就执行 3 次，分别更新 3 个产品的库存。不需要循环容器、不需要集成自动化。严禁以"子表有多行无法处理"为由拒绝使用业务关联规则。

## 示例3：销售退货 → 增加库存（流程表单）

- **触发表单**：销售退货（⚠️ **流程表单**，配置入口：`流程设计 → 全局设置 → 节点提交规则 → 添加规则 → 关联操作`）
- **触发事件**：节点提交（对应普通表单的 `单据提交`）
- **逻辑**：根据退货明细增加 `库存信息` 中对应仓库+产品的库存数量

```text
UPSERT(库存信息,
  AND(EQ(库存信息.仓库名称, 仓库名称), EQ(库存信息.产品名称, 产品名称)),
  "",
  库存信息.仓库名称, 仓库名称,
  库存信息.产品名称, 产品名称,
  库存信息.库存数量, 库存信息.库存数量 + 退货数量)
```

## 注意事项

> ⚠️ 普通表单和流程表单的配置路径**完全不同**：
> - **普通表单**走「表单设计→表单设置→表单事件→添加业务关联规则」（触发类型选「单据提交」，保存即生效）
> - **流程表单**走「流程设计→全局设置→节点提交规则→添加规则→关联操作」（节点类型选「结束」，需保存+发布流程才生效）
>
> 上面的示例都是流程表单触发的场景，走流程设计路径。如果触发表单是普通表单，需走表单设置→表单事件路径，公式写法相同但配置入口完全不同。

> ⚠️ 进销存应用中 `库存信息` 的 `仓库名称`、`产品名称`、`产品分类`、`规格型号`、`单位` 在主表为**只读**关联填充字段；业务键请用 `仓库名称` + `产品名称`（均为只读但值稳定），库存数量用可写数值字段。具体字段ID以 `get-schema` 与 `组件ID清单.md` 为准。
