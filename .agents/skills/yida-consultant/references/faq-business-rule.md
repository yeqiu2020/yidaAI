## 普通表单和流程表单的配置路径不同

### 症状

业务规则配置后不生效，或找不到配置入口。

### 根因

普通表单和流程表单的业务规则配置路径完全不同：
- 普通表单：表单设计 → 表单设置 → 表单事件 → 添加业务关联规则
- 流程表单：流程设计 → 创建新流程 → 全局设置 → 节点提交规则 → 添加规则

### 修复方案

确认表单类型后走正确路径：

**普通表单**：表单设计 → 表单设置 → 表单事件 → 添加业务关联规则（触发类型：单据提交/删除/编辑）→ 保存即生效

**流程表单**：流程设计 → 创建新流程 → 全局设置 → 节点提交规则 → 添加规则（节点类型选"结束"，节点动作勾选"同意"）→ 保存 → **发布流程**（仅保存不发布不会生效）

### 验证方式

调 rule-sync 同步当前规则配置，确认规则已正确写入。

## UPSERT 函数匹配条件不生效

### 症状

UPSERT 函数执行后，未匹配到已有数据时没有新增，或匹配到数据但未更新。

### 根因

1. 匹配条件中的字段 ID 错误
2. 匹配条件中的值类型不匹配（字符串 vs 数字）
3. 来源表和目标表的字段类型不一致

### 修复方案

1. 检查 UPSERT 函数的匹配条件参数，确认字段 ID 正确
2. 确认匹配值与目标表字段类型一致
3. 如需诊断，调 rule-sync 同步当前规则配置查看实际配置

### 验证方式

调 rule-sync 同步规则配置，检查 UPSERT 函数的匹配条件。

### 参考来源

`.agents/skills/business-rule/references/business-rule-functions.md`

## 流程表单业务规则节点类型未选"结束"

### 症状

流程表单的业务规则配置后不生效，提交审批后规则未执行。

### 根因

流程表单的节点提交规则中，节点类型默认是"开始"，必须改为"结束"。节点动作需勾选"同意"（流程正常结束对应"同意"动作）。

### 修复方案

在流程设计 → 全局设置 → 节点提交规则中：
1. 节点类型改为"结束"（不是"开始"）
2. 节点动作勾选"同意"
3. 保存后点击"发布流程"

### 验证方式

调 rule-sync 同步规则配置，确认节点类型为"结束"。

`.agents/skills/business-rule/references/manual-config-steps.md`（流程表单步骤5）
