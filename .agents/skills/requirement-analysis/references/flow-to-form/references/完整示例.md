## 三、业务规则

### 1. 借用审批通过

- **触发条件**: 借用申请.审批状态 = "已通过"
- **执行动作**: 
  1. 更新仪表库存状态为"借出"
  2. 生成出库记录
  3. 发送消息通知借用人
- **影响范围**: 仪表信息、借用申请

### 2. 借用出库确认

- **触发条件**: 借用申请.出库时间不为空
- **执行动作**: 
  1. 更新借用明细中实际出库数量
  2. 更新仪表状态为"借出"
  3. 减少柜子已用容量
- **影响范围**: 借用申请、仪表信息、柜子信息

### 3. 归还入库完成

- **触发条件**: 归还登记.入库时间不为空
- **执行动作**: 
  1. 更新仪表库存状态为"在库"
  2. 更新借用申请状态为"已归还"
  3. 如仪表状态为"损坏"，自动生成维修申请
  4. 增加柜子已用容量
- **影响范围**: 仪表信息、借用申请、维修申请、柜子信息

### 4. 检定完成更新

- **触发条件**: 检定记录.检定结果不为空
- **执行动作**: 
  1. 更新仪表信息.检定日期 = 检定记录.检定日期
  2. 更新仪表信息.到期日期 = 检定记录.下次检定日期
  3. 如检定结果 = "不合格"，更新仪表状态为"故障"
- **影响范围**: 仪表信息、检定记录

### 5. 维修完成更新

- **触发条件**: 维修记录.验收结果 = "合格"
- **执行动作**: 
  1. 更新仪表信息.仪表状态 = "正常"
  2. 更新维修申请.维修状态 = "已完成"
- **影响范围**: 仪表信息、维修申请

### 6. 报废审批通过

- **触发条件**: 报废申请.审批状态 = "已通过"
- **执行动作**: 
  1. 更新仪表信息.仪表状态 = "报废"
  2. 减少柜子已用容量
  3. 更新报废申请.报废状态 = "已处理"
- **影响范围**: 仪表信息、报废申请、柜子信息

### 7. 入柜完成更新

- **触发条件**: 入柜登记.提交
- **执行动作**: 
  1. 更新仪表信息.所属柜子 = 目标柜子
  2. 更新仪表信息.存放位置 = 柜子位置
  3. 更新柜子信息.已用容量 = 已用容量 + 入柜数量
- **影响范围**: 仪表信息、柜子信息

## 四、自动化规则

### 1. 检定到期提醒

- **触发器**: 定时触发，每天检查
- **执行动作**: 查找到期日期 <= 今天+7天 且 状态 != "已报废" 的仪表
- **执行时机**: 每天早上 9:00

### 2. 检定超期预警

- **触发器**: 定时触发，每天检查
- **执行动作**: 查找到期日期 < 今天 且 状态 = "正常" 的仪表，生成库存预警记录
- **执行时机**: 每天早上 9:00

### 3. 借用超期提醒

- **触发器**: 定时触发，每天检查
- **执行动作**: 查找预计归还日期 < 今天 且 出库状态 = "已出库" 的借用单
- **执行时机**: 每天早上 9:00

### 4. 库存预警

- **触发器**: 数据变更触发
- **执行动作**: 备件信息.库存数量 < 安全库存时，生成库存预警记录
- **执行时机**: 立即

### 5. 柜子容量预警

- **触发器**: 数据变更触发
- **执行动作**: 柜子信息.剩余容量 < 5 时，发送消息给柜子负责人
- **执行时机**: 立即

## 九、审批流程规则

### 1. 仪表借用审批

- **发起条件**: 提交借用申请
- **审批节点**: 
  - 节点1: 部门主管 - 或签
  - 节点2: 仪表管理员 - 会签（如借用数量 > 5）
- **流转条件**: 
  - 借用金额 > 10000：需增加财务审批节点
  - 紧急程度 = "紧急"：跳过部门主管，直接到仪表管理员
- **抄送规则**: 审批完成后抄送仓库管理员

### 2. 仪表归还确认

- **发起条件**: 提交归还登记
- **审批节点**: 
  - 节点1: 仓库管理员 - 或签（确认入库）
- **流转条件**: 无
- **抄送规则**: 入库完成后抄送借用人

### 3. 仪表送检审批

- **发起条件**: 提交送检申请
- **审批节点**: 
  - 节点1: 部门主管 - 或签
  - 节点2: 仪表管理员 - 或签
- **流转条件**: 
  - 送检费用 > 5000：需增加财务审批节点
- **抄送规则**: 审批完成后抄送检定单位联系人

### 4. 仪表维修审批

- **发起条件**: 提交维修申请
- **审批节点**: 
  - 节点1: 部门主管 - 或签
  - 节点2: 仪表管理员 - 或签
- **流转条件**: 
  - 预估维修费用 > 3000：需增加财务审批节点
  - 故障类型 = "人为损坏"：需增加责任人确认节点
- **抄送规则**: 审批完成后抄送维修人员

### 5. 仪表报废审批

- **发起条件**: 提交报废申请
- **审批节点**: 
  - 节点1: 部门主管 - 或签
  - 节点2: 仪表管理员 - 或签
  - 节点3: 财务部门 - 或签（核实账面价值）
  - 节点4: 总经理 - 或签（如账面价值 > 10000）
- **流转条件**: 
  - 报废数量 > 10：需增加资产管理部门审批
- **抄送规则**: 审批完成后抄送财务部门备案
