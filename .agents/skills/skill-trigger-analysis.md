## 三、触发词设计规范

### 好的触发词特征：
1. **动词+对象** 结构清晰
2. **3-5个关键词** 覆盖主要场景
3. **避免过于宽泛** 的词（如"代码"、"数据"）
4. **放在description最前面**，用"当用户...时触发"句式

### 示例模板：
```yaml
---
name: skill-name
description: 当用户说"关键词1"、"关键词2"、"关键词3"时触发此skill。具体功能说明...
---
```

## 五、触发词设计最佳实践

### ✅ 推荐格式
```yaml
---
name: skill-name
description: 当用户说"关键词1"、"关键词2"、"关键词3"时触发此skill。具体功能描述...
---
```

### ✅ 设计原则
1. **动词+对象** 结构（如"同步配置"、"删除表单"）
2. **3-5个关键词** 覆盖主要场景
3. **放在description最前面**
4. **避免过于宽泛** 的词
5. **区分相似skill**（如"JS代码"vs"宜搭公式"）
