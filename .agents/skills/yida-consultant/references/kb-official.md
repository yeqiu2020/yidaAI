## 一、表单业务关联规则（业务规则）

### 1.1 什么是业务规则

- 用于处理**表单与表单之间**的关系：一张表单数据变化时，同步影响另一张表单的数据（增加/更新/删除）。
- **操作表**：当前操作的表单，也是触发事件的表单。触发事件包括新增、编辑、删除。
- **目标表**：当前表单提交/删除数据后，对另一个表单进行插入/更新/删除。
- **配置路径**：表单编辑页面 → 点击表单空白处 → 右侧「表单事件」→ 添加业务关联规则。
- **典型场景**：物品入库 → 库存表对应商品库存量增加；物品领用或入库单被删除 → 库存量减少。

### 1.2 流程与非流程表单业务规则区别【重要判断依据】

以**目标表单**判断：
- 目标表单是**普通表单** → 才能使用业务规则。
- 目标表单是**流程表单** → 无法使用业务规则，规则书写框内无法选择流程表单（**这种情况必须用集成&自动化**）。

以**当前操作表单**判断配置入口：
- 普通表单：表单设计 → 表单设置 → 表单事件 → 添加业务关联规则。
- 流程表单：流程设计 → 全局设置 → 节点提交规则 → 添加规则。

### 1.3 表单业务规则运行日志

- 数据管理页可点击查看相应数据执行的日志。
- **未命中**：即按匹配条件没有查找到可操作的数据。

### 1.4 高级函数语法（INSERT / UPDATE / UPSERT / DELETE）

#### INSERT — 插入

```
INSERT (目标表, 目标列1, 目标值1, 目标列2, 目标值2, ...)
```

- 把当前录入表的数据插入目标表。
- 数据可来自普通组件或子表单组件；若是子表单组件，会把明细拆成**多条**插入目标表，但**最多只能用一个子表单组件**。

#### UPDATE — 更新

```
UPDATE (目标表, 主条件, 子条件, 目标列1, 目标值1, 目标列2, 目标值2, ...)
```

- 更新目标表中**符合条件**的数据（如出货时从存货表扣除对应商品的存货量）。
- **主条件**：定位目标表要更新的数据，由逻辑函数构成。如 `EQ(存货表.商品名, "铅笔")`；多条件用 `AND` 组合，如 `AND(EQ(存货表.商品名, "铅笔"), GT(存货表.存货量, 10))`。
- **子条件**：更新目标表下子表单的数据时，用子条件定位要更新的子表单数据。

#### UPSERT — 插入或更新

```
UPSERT (目标表, 主条件, 子条件, 目标列1, 目标值1, 目标列2, 目标值2, ...)
```

- 往目标表单**插入或更新**数据：商品不存在则新增，已存在则按条件更新（如在原存货量基础上累加本次进货量）。
- 主条件/子条件用法与 UPDATE 相同。

#### DELETE — 删除

```
DELETE (目标表, 主条件, 子条件)
```

- 支持两种删除：直接删除某条表单数据；删除某条表单数据中子表单组件下的部分子表单数据（主数据保留）。
- **⚠️ 业务关联公式暂不支持在条件中与字符串做直接判断**，需先用 `IF()` 判断再执行：
  ```
  IF(EQ(当前表单.商品名, "铅笔"), DELETE(), "")
  ```
  注意其中的 `EQ(当前表单.商品名, ...)` 用的是**当前表单**字段，不能用目标表单的商品名字段判断。
- 多条件用 `AND` 组合：`AND(EQ(当前表单.商品名, "铅笔"), GT(当前表单.存货量, 10))`。

### 2.3 常见问题

#### 自动化左侧无法选中目标表单字段

- **原因**：目标表单的该字段被设置为**只读**状态。
- **解决**：改成普通状态（可编辑状态）即可。

#### 自动化右侧无法找到对应字段

- **原因**：左侧选中的字段类型与右侧表单字段类型不匹配。例如左侧是**地址组件**，右侧表单内没有地址字段（做成文本字段），就选不到。
- **解决**：把两边字段类型统一（要么都是地址字段，要么都是文本字段）。

#### 自动化早于和晚于

- **晚于**：前面的时间在后面的时间之前（即 A 晚于 B = A 在 B 之后）。
- **早于**：反之（A 早于 B = A 在 B 之前）。

## 三、常见问题处理（FAQ 沉淀）

| 问题 | 根因/结论 |
|------|-----------|
| 数值计算错误 | 显示的数值与背后的真实值不一致（显示的是旧值/格式化值）。需核实字段背后的真实值。 |
| 子表内公式失效 | 子表的高级设置可能设置了"触发公式"；删除该公式再试。 |
| 选项设置失效 | 组件里曾有代码触发（后被注销），产生执行错误，影响了选项设置功能执行。清理残留代码。 |
| 已完成流程表单无法关联 | 只有**审批通过**的数据才能被关联；自动结束（无人审批）的流程数据无法被关联选择。 |
| 带参数跳转 I/I 不分 | 跳转参数中易混淆 I 与 l（大写 i / 小写 L），检查参数拼写。 |
| 权限管理 | 关联/选择不到数据时，检查权限组配置。 |
| 流水号用于更新 | 流水号字段有特殊限制，更新场景注意其特性。 |
| 控件默认值无法修改 | 默认值被锁定（可能因公式/联动/只读配置）。 |
| 审批人不允许为空 | 审批节点必须配置审批人，不能为空。 |
| 隐藏数据不见了 | 隐藏字段的数据仍存在，检查可见性与权限配置。 |

## 四、诊断使用指引

- 用户问题涉及**跨表增删改不生效**时，优先核对：①目标表单是否为流程表单（是 → 转集成&自动化，非 → 业务规则）；②高级函数主条件是否用了目标表字段做字符串判断（DELETE 必须用 IF 包裹且用当前表单字段）；③子表单拆行是否超过一个明细。
- 用户问题涉及**集成自动化不执行/失败**时：①先查集成自动化管理后台日志看异常节点；②核对字段只读状态；③核对字段类型一致性。
- 用户问题涉及**数据关联不上**时：核对目标数据是否经过审批（自动结束的流程数据不可关联）。
