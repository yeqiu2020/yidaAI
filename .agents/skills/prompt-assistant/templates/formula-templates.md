## 四、字段类型与公式函数对照表

| 字段类型 | 常用函数                          | 示例                         |
| ---- | ----------------------------- | -------------------------- |
| 日期   | DATEDIF, TIMESTAMP, TODAY     | DATEDIF(开始日期, 结束日期, "D")   |
| 数值   | SUM, AVG, MAX, MIN, ROUND     | ROUND(数值, 2)               |
| 文本   | CONCATENATE, LEFT, RIGHT, MID | CONCATENATE(字段1, "-", 字段2) |
| 子表   | SUMPRODUCTX, MAPX, FILTERX    | SUMPRODUCTX(子表.数量, 子表.单价)  |
| 条件   | IF, IFS, SWITCH               | IF(条件, 值1, 值2)             |
| 查找   | LOOKUP, VLOOKUP               | LOOKUP(查找值, 查找范围, 返回范围)    |

## 五、常见公式模式

### 5.1 日期差值计算

```
ROUND((TIMESTAMP(结束日期) - TIMESTAMP(开始日期)) / 3600000, 1)
```

### 5.2 子表金额合计

```
SUMPRODUCTX(子表.数量, 子表.单价)
```

### 5.3 条件判断赋值

```
IF(数量 > 100, "大量", IF(数量 > 10, "中量", "小量"))
```

### 5.4 文本拼接

```
CONCATENATE("订单号：", 订单编号, "-", 客户名称)
```

### 5.5 子表查找

```
MAPX(子表, 排名 = 1, 投标单位名称)
```
