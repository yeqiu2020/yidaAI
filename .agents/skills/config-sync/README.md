# 宜搭配置同步 Skill

> 版本: 1.0.6
> 更新日期: 2026-03-11

## 功能概述

本 Skill 提供两个核心功能：

1. **创建时同步**：在创建宜搭应用和表单后，自动获取应用ID、表单UUID、组件ID
2. **更新同步**：在宜搭平台修改表单（增删改组件）后，重新同步所有ID信息

## 使用场景

### 场景一：创建新应用（自动执行）

当您使用 `form_creator` skill 创建应用时，会自动调用本 skill 同步配置：

```bash
# 调用 form_creator skill
# 会自动执行以下流程：
# 1. 生成表单JSON配置
# 2. 创建宜搭应用和表单
# 3. 自动同步配置（调用 sync_config.js）
# 4. 生成系统配置清单和组件ID清单
```

**生成的文件：**
- `系统配置清单.md` - 包含应用ID、表单UUID列表
- `各表单目录/组件ID清单.md` - 每个表单的所有组件ID

### 场景二：更新现有应用（手动执行）

当您在宜搭平台修改了表单（添加/删除/修改组件）后，需要手动同步：

```bash
cd .agents/skills/config-sync/scripts
node sync_config.js --appId APP_XXX --output "项目根目录路径" --update
```

**示例：**
```bash
node sync_config.js --appId APP_F71XYFDFGSR7M6QPMH1Z --output "d:\宜搭AI编程\宜搭AI助手V1.3\进销存管理" --update
```

**参数说明：**
- `--appId`：宜搭应用ID（从系统配置清单中获取）
- `--output`：项目根目录路径（包含系统配置清单.md的目录）
- `--update`：强制更新模式，从API获取最新数据

## 工作原理

### 创建时同步流程

```
create_from_markdown.js
    ↓
创建应用和表单
    ↓
写入 .temp_forms.json（临时文件）
    ↓
调用 sync_config.js
    ↓
读取临时文件获取表单列表（最可靠）
    ↓
调用 getFormSchema API 获取组件ID
    ↓
生成系统配置清单和组件ID清单
    ↓
删除临时文件
```

### 更新同步流程

```
用户手动运行 sync_config.js --update
    ↓
调用 getFormList API 获取最新表单列表
    ↓
对比本地系统配置清单
    ↓
调用 getFormSchema API 获取每个表单的最新组件ID
    ↓
更新系统配置清单（新增/删除的表单）
    ↓
更新各表单的组件ID清单（新增/删除/修改的组件）
```

## 文件说明

### 系统配置清单.md

位置：`项目根目录/系统配置清单.md`

内容：
- 应用基本信息（名称、ID、URL）
- 表单UUID清单（序号、名称、类型、UUID）
- 统计信息（表单总数、普通表单数、流程表单数）
- 快速访问链接

### 组件ID清单.md

位置：`各表单目录/组件ID清单.md`

内容：
- 组件列表（序号、类型、字段名称、组件ID）
- 统计信息（组件总数）
- 使用说明

## 注意事项

1. **创建时自动同步**：无需手动干预，由 `form_creator` skill 自动完成
2. **更新时需要 --update 参数**：确保从API获取最新数据，而不是使用本地缓存
3. **应用ID获取**：从 `系统配置清单.md` 中的"应用ID"字段获取
4. **登录态**：脚本会自动管理登录态，无需手动登录

## 常见问题

### Q: 为什么更新时需要 --update 参数？

A: 不加 --update 时，脚本会优先使用本地缓存（系统配置清单），适合刚创建应用时使用。加 --update 时，脚本会强制从API获取最新数据，适合在宜搭平台修改表单后使用。

### Q: 如果忘记了应用ID怎么办？

A: 查看 `系统配置清单.md` 文件，里面有"应用ID"字段。

### Q: 同步失败怎么办？

A: 检查以下几点：
1. 确保已登录宜搭平台（运行 login_manager.py）
2. 确保应用ID正确
3. 确保输出目录路径正确
4. 查看错误信息，根据提示排查
