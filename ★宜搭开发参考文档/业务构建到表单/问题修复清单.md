## 📋 发现的问题汇总

### 问题1：子表 children 数组为空 ⭐⭐⭐

**问题描述**：
- 生成的子表JSON中 `children` 数组为空
- 导致子表字段无法在宜搭中显示

**根本原因**：
- 旧代码使用简化的字段配置 `columns`
- 没有调用完整的字段模板函数生成子字段

**修复方案**：
```javascript
// ❌ 错误方式
const columns = (config.columns || []).map(processSubField);
field.props.columns = columns;

// ✅ 正确方式
const children = (config.columns || []).map((col) => {
  const templateFn = FieldTemplates[col.type];
  const childField = templateFn(col);
  childField.props.isCustomStore = true;
  return childField;
});
field.children = children;
```

**修复文件**：
- `yida_field_templates.js` - TableField 模板函数

**验证状态**：✅ 已修复并验证

### 问题2：子表公式字段未处理 ⭐⭐⭐

**问题描述**：
- 子表内的公式字段 marks 位置未计算
- 公式类型未正确设置

**根本原因**：
- `form_generator_v2.js` 只处理了主表公式
- 没有递归处理子表内的公式字段

**修复方案**：
```javascript
// 在 processFormula 方法中添加子表公式处理
if (fieldConfig.type === 'TableField' && field.children) {
  for (let i = 0; i < field.children.length; i++) {
    const childField = field.children[i];
    const childConfig = fieldConfig.columns[i];
    
    if (childConfig.valueType === 'formula' && childConfig.formulaTemplate) {
      // 子表公式只能引用同一子表内的字段
      const subFields = this.generatedFields.filter(f => f.parentLabel === fieldConfig.label);
      const formulaText = replaceFormulaPlaceholders(childConfig.formulaTemplate, subFields);
      const marks = calculateFormulaMarks(formulaText, subFields);
      
      // 设置公式和marks
      childField.props.complexValue.complexType = 'formula';
      childField.props.complexValue.formula = formulaText;
      childField.props.complexValue.marks = marks;
      childField.props.complexValue.isCmData = true;
      childField.props.formula = formulaText;
      childField.props.valueType = 'formula';
    }
  }
}
```

**修复文件**：
- `form_generator_v2.js` - processFormula 方法

**验证状态**：✅ 已修复并验证

### 问题3：子表超出页面宽度 ⭐⭐

**问题描述**：
- 子表列数较多时，整体超出页面宽度
- 未出现横向滚动条

**根本原因**：
- `tableLayout` 设置为 `"auto"`
- 导致根据内容自动调整宽度

**修复方案**：
```javascript
// ❌ 错误设置
tableLayout: 'auto'

// ✅ 正确设置
tableLayout: 'fixed'
```

**修复文件**：
- `yida_field_templates.js` - TableField 模板，第613行

**验证状态**：✅ 已修复并验证

### 问题4：子字段信息未收集 ⭐

**问题描述**：
- 生成器未收集子表字段信息
- 导致主表公式无法引用子表字段（虽然场景较少）

**根本原因**：
- `generateField` 方法只保存主表字段信息

**修复方案**：
```javascript
// 在 generateField 方法中添加子字段信息收集
if (fieldConfig.type === 'TableField' && field.children) {
  for (const childField of field.children) {
    this.generatedFields.push({
      label: childField.props.label.zh_CN,
      fieldId: childField.props.fieldId,
      type: childField.componentName,
      isSubField: true,
      parentLabel: fieldConfig.label
    });
  }
}
```

**修复文件**：
- `form_generator_v2.js` - generateField 方法

**验证状态**：✅ 已修复并验证
