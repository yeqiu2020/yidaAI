·# 跨表操作宜搭内操作步骤模板

> 本模板用于跨表单数据查询操作的宜搭配置说明
> 使用时根据实际场景替换占位符内容

## 模板变量说明

| 占位符 | 说明 | 示例 |
|-------|------|------|
| `{DATA_SOURCE_NAME}` | 数据源名称 | crossFormQuery |
| `{APP_TYPE}` | 应用ID | APP_G7F1UGDPF7GIEW0UCUBY |
| `{API_ENDPOINT}` | API接口地址 | /v1/form/searchFormDatas.json |
| `{BUTTON_NAME}` | 按钮名称 | 获取成员工资数据 |
| `{FUNCTION_NAME}` | 绑定的函数名 | getEmployeeSalaryData |
| `{REQUIRED_FIELDS}` | 必填项说明 | 部门、年份、月份 |
| `{SPECIAL_NOTES}` | 特殊注意事项 | 子表原有数据会被覆盖 |

---

## 标准操作步骤

```javascript
/**
 * ===== 宜搭内操作步骤 =====
 * 
 * 【步骤1：配置远程数据源】（关键步骤，必须先完成）
 * 1. 进入宜搭应用后台，点击左侧菜单【数据源】
 * 2. 点击【添加】-->【新建远程API】，填写以下信息：
 *    - 名称：{DATA_SOURCE_NAME}（必须与代码中的名称一致）
 *    - 请求地址：/dingtalk/web/{APP_TYPE}/{API_ENDPOINT}
 *      （已根据代码中的应用ID自动组装，直接复制使用）
 *    - 请求方式：GET
 *    - 参数配置：在UI界面不配置任何Query参数，所有参数由JS代码动态传入
 * 3. 点击【保存】完成数据源配置
 * 
 * 【步骤2：配置JS代码】
 * 1. 在宜搭表单设计器中，点击右上角【JS面板】
 * 2. 将本代码完整复制粘贴到JS编辑区域
 * 3. 点击【保存】
 * 
 * 【步骤3：配置按钮事件】
 * 1. 创建一个按钮组件，命名为"{BUTTON_NAME}"
 * 2. 选中按钮，在右侧【动作】面板中找到【onClick】事件
 * 3. 选择绑定函数：{FUNCTION_NAME}
 * 4. 点击【保存】
 * 
 * 【步骤4：测试验证】
 * 1. 预览或发布表单
 * 2. 填写{REQUIRED_FIELDS}（均为必填项）
 * 3. 点击"{BUTTON_NAME}"按钮
 * 4. 查看执行结果是否符合预期
 * 
 * ===== 注意事项 =====
 * - 必须先配置远程数据源，否则代码无法调用跨应用查询
 * - 请求地址中的AppKey必须是当前应用的AppKey
 * - {REQUIRED_FIELDS}为必填项，否则无法查询
 * {SPECIAL_NOTES}
 * - 如需查询超过100条数据，需要实现分页查询逻辑
 * 
 * 代码版本号: {VERSION}
 */
```

## API接口地址对照表

| 接口功能 | API端点 | 说明 |
|---------|---------|------|
| 查询表单实例详情列表 | /v1/form/searchFormDatas.json | 返回完整表单数据 |
