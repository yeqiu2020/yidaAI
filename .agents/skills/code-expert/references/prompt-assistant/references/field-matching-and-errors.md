## 字段匹配规则

使用模糊匹配算法，按语义关键词匹配组件ID清单中的字段。

### 日期字段匹配

```javascript
const datePatterns = {
  '开始日期': ['开始', '起始', 'start', 'begin', '从'],
  '结束日期': ['结束', '截止', '终止', 'end', '到'],
  '创建日期': ['创建', '登记', '录入'],
  '更新日期': ['更新', '修改', '最后']
};
```

### 数值字段匹配

```javascript
const numberPatterns = {
  '金额': ['金额', '价格', '总价', '合计', '金额'],
  '数量': ['数量', '个数', '件数', ' count', 'quantity'],
  '单价': ['单价', '价格', 'unit'],
  '库存': ['库存', '存量', '剩余']
};
```

### 文本字段匹配

```javascript
const textPatterns = {
  '名称': ['名称', '名字', 'name', '标题'],
  '编号': ['编号', '编码', 'code', 'no'],
  '备注': ['备注', '说明', '描述', 'memo']
};
```

## 错误处理

### 常见错误及处理

1. **找不到表单**

   - 提示："未找到名为'XXX'的表单，请确认表单名称是否正确"
   - 建议：列出所有可用表单供用户选择

2. **找不到字段**

   - 提示："未找到名为'XXX'的字段，可能匹配的字段有：..."
   - 建议：展示相似字段供用户确认

3. **字段类型不匹配**

   - 提示："字段'XXX'是日期类型，但公式需要数值类型"
   - 建议：提示用户检查需求描述

4. **缺少必要信息**

   - 提示："需要关联表单信息，请提供关联表单名称"
   - 建议：询问用户补充信息
