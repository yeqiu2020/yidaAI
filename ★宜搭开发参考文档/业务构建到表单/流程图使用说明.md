## 一、图例说明

### 1.1 颜色含义

| 颜色 | 图形 | 含义 | 说明 |
|------|------|------|------|
| **浅绿色 (#E6FFCC)** | 长条矩形 | **系统表单** | 可直接转化为宜搭的表单，是流程中的执行主体 |
| **浅灰色 (#F2F2F2)** | 矩形 | **功能描述** | 描述当前表单的具体业务功能 |
| **浅紫色 (#CCCCFF)** | 椭圆 | **开始/结束** | 标识流程的起点和终点 |
| **深绿色 (#67AB9F)** | 标签 | **表单名称** | 标注下方对应的表单名称 |
| **浅青色 (#9AC7BF)** | 长条 | **主线逻辑** | 表示流程的主线走向 |
| **圆柱形** | 图标 | **静态信息表** | 基础数据表，如客户信息库、供应商信息库等 |

### 1.2 线条含义

| 线条样式 | 含义 |
|----------|------|
| **实线箭头** | 主线流程走向 |
| **虚线箭头** | 辅助操作或数据关联 |
| **菱形箭头** | 表示数据关联关系 |

## 二、关键符号详解

### 2.1 审批流程标识

在表单左侧有一个**黄色小三角形**，内部标有数字，代表：
- **该表单内部的审批流程步骤数**
- 例如：三角形内数字"3"表示此表单包含3个审批节点

```
    ▲
    3
┌─────────────┐
│  表单功能   │
│  描述文字   │
├─────────────┤
│  表单名称   │
└─────────────┘
```

### 2.2 表格标注说明

流程图中的表格用于展示表单的关键字段结构：

- **"主表字段#"** - 表示该表格展示的是主表的关键字段
- **"子表字段#XXX"** - 表示该表格展示的是子表（明细表）的字段，XXX为子表名称

#### 示例：主表字段

```
主表字段#
┌─────────┬─────────┬─────────┐
│ 字段1   │ 字段2   │ 字段3   │
├─────────┼─────────┼─────────┤
│ 数据1   │ 数据2   │ 数据3   │
└─────────┴─────────┴─────────┘
```

#### 示例：子表字段

```
子表字段#产品明细
┌──────────┬──────┬────────┐
│ 产品名称 │ 数量 │ 成本价 │
├──────────┼──────┼────────┤
│   A001   │  10  │   10   │
│   A002   │  20  │   20   │
└──────────┴──────┴────────┘
```

## 三、表单类型分类

### 3.1 执行表（业务表单）

**特征：**
- 浅绿色长条矩形
- 有审批流程（左侧有三角形数字标识）
- 可直接转化为宜搭表单

**示例：**
- 销售订单
- 收款登记表
- 发票申请
- 生产排产
- 销售发货单

### 3.2 静态信息表（基础数据表）

**特征：**
- 圆柱形图标
- 作为基础数据供其他表单引用
- 通常在流程中显示为"更新XXX信息"

**示例：**
- 客户信息库
- 供应商信息库
- 分公司信息

**关联方式：**
- 用虚线箭头与其他表单关联
- 表示数据引用或更新关系

## 四、表单结构标准

### 4.1 表单基本结构

每个表单通常包含以下部分：

```
┌─────────────────────────┐
│                         │
│    【功能描述文字】      │  ← 浅灰色矩形：说明该表单的业务功能
│    （执行人角色）        │
│                         │
├─────────────────────────┤
│      【表单名称】        │  ← 深绿色标签：表单在系统中的名称
└─────────────────────────┘
```

### 4.2 带审批流程的表单

```
    ▲
    N                    ← 黄色三角形：表示N个审批步骤
┌─────────────────────────┐
│    【功能描述文字】      │
│    （执行人角色）        │
├─────────────────────────┤
│      【表单名称】        │
└─────────────────────────┘
```

## 五、流程阅读指南

### 5.1 主线流程

跟随**实线箭头**方向阅读，表示业务的正常流转顺序：

```
开始 → 表单A → 表单B → 表单C → 结束
```

### 5.2 分支流程

当遇到判断节点（菱形）时，根据条件走向不同分支：

```
          ┌─ 是 ─→ 分支A
          │
    【判断条件】
          │
          └─ 否 ─→ 分支B
```

### 5.3 数据关联

**虚线箭头**表示表单之间的数据关联：

```
表单A ──────→ 表单B
      (虚线)
      表示表单A引用或更新表单B的数据
```

## 六、特殊标注说明

### 6.1 业务规则注释

流程图中可能包含文字注释，用于说明业务规则：

- 位于相关表单下方或旁边
- 使用较小字号
- 说明特殊业务逻辑或注意事项

### 6.2 角色标识

## 七、示例解读

### 示例1：发票申请流程

```
    🧑
   销售员
    │
    ▼
┌─────────────────────────┐
│  申请开具给甲方的发票   │  ← 功能描述：申请开票
│    （销售员执行）        │
├─────────────────────────┤
│      发票申请            │  ← 表单名称
└─────────────────────────┘
    │
    ▼ (虚线连接)
┌─────────────────────────┐
│  主表字段#              │  ← 主表字段说明
├────────┬────────┬───────┤
│ 发票金额│ 付款金额│ 付款状态│
├────────┼────────┼───────┤
│ 60000  │ 40000  │部分付款│
│ 60000  │ 60000  │付款完结│
└────────┴────────┴───────┘
```

### 示例2：静态信息表关联

```
        ┌─────────────┐
        │  圆柱形图标  │  ← 静态信息表
        │ 更新供应商信息│
        ├─────────────┤
        │  供应商信息库 │
        └─────────────┘
              ▲
              │ (虚线箭头)
              │
        【业务表单】   ← 引用或更新供应商信息
```

## 八、使用建议

1. **阅读顺序**：从左到右、从上到下，跟随实线箭头方向
2. **关注审批**：注意表单左侧的三角形数字，了解审批复杂度
3. **理解关联**：注意虚线连接，理解表单间的数据关系
4. **查看字段**：通过表格了解表单的关键字段结构
5. **注意注释**：阅读业务规则注释，理解特殊逻辑
