# 字段类型指南

合法字段类型列表：单行文本、多行文本、数值、日期、单选、复选、下拉单选、下拉复选、关联表单、成员、部门、附件、图片、地址、流水号。

## 一、可用字段类型

| 字段类型 | 说明 | 适用场景 |
|---------|------|---------|
| 单行文本 | 短文本输入 | 名称、标题、编号 |
| 多行文本 | 长文本输入 | 备注、说明、描述 |
| 数值 | 数字输入 | 金额、数量、比例 |
| 日期 | 日期选择 | 开始日期、结束日期、创建时间 |
| 单选 | 单选按钮组 | 是否类字段 |
| 复选 | 复选框组 | 可多选的少量选项 |
| 下拉单选 | 单选下拉框 | 状态、类型、分类 |
| 下拉复选 | 多选下拉框 | 标签、多类别 |
| 关联表单 | 关联其他表单 | 从另一个表单选择已有记录 |
| 成员 | 人员选择 | 负责人、创建人、审批人 |
| 部门 | 部门选择 | 所属部门 |
| 附件 | 文件上传 | 文档、附件 |
| 图片 | 图片上传 | 照片、截图 |
| 地址 | 地址选择器 | 地址、位置、地点 |
| 流水号 | 自动编号 | 业务编号、单据编号 |

## 二、字段说明格式规范

| 字段类型 | 字段说明格式 | 示例 |
|---------|-------------|------|
| 流水号 | `前缀：XXX，示例：XXXyyyyMMdd001` | 前缀：SN，示例：SN20260702001 |
| 关联表单 | `关联-->目标表单名称` | 关联-->基础资料 |
| 关联表单带填充 | `关联-->目标表单名称；填充：当前字段=源字段` | 关联-->基础资料；填充：资料名称=名称 |
| 数值 | `X位小数，单位：XXX` | 2位小数，单位：元 |
| 选项类字段 | `选项值1/选项值2/选项值3` | 启用/停用 |

被填充字段的说明列填写自身属性，不写填充来源。填充规则统一写在关联字段说明中。

## 三、字段状态

| 状态值 | 说明 |
|-------|------|
| 普通 | 字段可编辑输入 |
| 只读 | 字段不可编辑，仅展示 |
| 隐藏 | 字段在表单中不显示 |

默认规则：

- 流水号、创建人、创建时间、被填充字段、公式计算字段为只读
- 其他字段默认为普通
