# 自动化脚本开发规范

> 宜搭流程脚本节点开发规范与最佳实践

> 创建时间: 2026-02-23

## 一、脚本节点概述

宜搭流程支持在流程设计或集成自动化中添加脚本节点，通过编写JS代码实现对输入数据的加工处理，最终通过output对象输出结果。

### 使用场景
- 对上游节点返回数据进行格式化处理
- 数据转换和映射
- 复杂业务逻辑计算
- 数据清洗和过滤

### 使用方式
1. **流程设计**: 编辑流程表单 > 进入流程设计页面 > 选择开发者节点 > 脚本节点
2. **集成自动化**: 编辑应用 > 集成与自动化 > 选择具体的自动化流 > 添加脚本节点

## 二、核心规范（必须遵守）

### 2.1 语法限制

| 限制项 | 说明 | 示例 |
|--------|------|------|
| **ES5语法** | 仅支持ES5，不支持ES6+ | 使用 `var` 而非 `let/const` |
| **函数定义** | 支持在代码块里定义function | `function main() { ... }` |
| **return语句** | 禁止在function之外使用return | ❌ 错误：`if(x) return;` |
| **网络请求** | 不支持xhr、fetch | 无法发起HTTP请求 |
| **顶级对象** | 不支持window、console、print | ❌ 错误：`console.log()` |
| **内存限制** | 超过10M会触发内存超限错误 | 避免处理大量数据 |
| **CPU限制** | 超过5S会触发自动保护 | 避免死循环 |

### 2.2 输入输出规范

#### 输入参数
- **不使用 `input.xxx` 方式获取**
- **直接使用在宜搭中配置的变量名**

```javascript
// ✅ 正确 - 直接使用配置的变量名
var subTableData = subtableData || [];

// ❌ 错误 - 不支持这种写法
var subTableData = input.subtableData;
```

#### 输出参数
- **使用 `outputs.add(描述, 变量名, 值)`**
- **三个参数分别为：变量描述、变量名、代码中的变量**

```javascript
// ✅ 正确
outputs.add("表格数据", "tableData", tableData);

// 示例
outputs.add("随机延迟秒数", "randomDelaySeconds", randomDelay);
outputs.add("随机延迟毫秒", "randomDelayMilliseconds", randomDelay * 1000);
```

### 2.3 代码结构模板

```javascript
// [功能描述]
// 版本号: v1.0.0

// 主处理函数
function main() {
  // 1. 获取输入数据
  var inputData = inputVariable || [];
  
  // 2. 数据验证
  if (!inputData || inputData.length === 0) {
    outputs.add("输出描述", "outputName", null);
    return;  // return只能在函数内部使用
  }
  
  // 3. 业务逻辑处理
  var result = processData(inputData);
  
  // 4. 输出结果
  outputs.add("输出描述", "outputName", result);
}

// 辅助函数
function processData(data) {
  // 处理逻辑
  return result;
}

// 执行主函数
main();

// 代码版本号: v1.0.0
```

## 三、常见错误总结

### 错误1：在函数外部使用return

```javascript
// ❌ 错误
var data = inputData;
if (!data) {
  outputs.add("结果", "result", null);
  return;  // 错误！在函数外部使用return
}

// ✅ 正确
function main() {
  var data = inputData;
  if (!data) {
    outputs.add("结果", "result", null);
    return;  // 正确！在函数内部使用
  }
}
main();
```

### 错误2：使用input对象获取参数

```javascript
// ❌ 错误
var data = input.subtableData;

// ✅ 正确
var data = subtableData;  // 直接使用配置的变量名
```

### 错误3：使用ES6+语法

```javascript
// ❌ 错误
const data = [];
let count = 0;
var result = data.map(item => item.value);

// ✅ 正确
var data = [];
var count = 0;
var result = data.map(function(item) { return item.value; });
```

### 错误4：使用console

```javascript
// ❌ 错误
console.log("调试信息");
console.error("错误信息");

// ✅ 正确 - 不使用console，或仅在开发时使用，生产环境删除
```

### 错误5：混淆入参和出参配置

**入参配置**（在宜搭界面配置）：
- 变量描述：用于显示的名称
- 变量名：代码中直接使用的变量名
- 变量值：数据来源

**出参配置**（在宜搭界面配置）：
- 变量描述：用于显示的名称
- 变量名：下游节点引用的名称
- 代码中的变量：脚本代码中的变量名

```javascript
// 代码中使用
outputs.add("显示描述", "下游引用名", 代码中的变量);
```

## 四、最佳实践

### 4.1 数据验证

始终对输入数据进行验证：

```javascript
function main() {
  var data = inputData || [];
  
  // 类型检查
  if (typeof data === "string") {
    try {
      data = JSON.parse(data);
    } catch (e) {
      outputs.add("结果", "result", null);
      return;
    }
  }
  
  // 空值检查
  if (!data || !Array.isArray(data) || data.length === 0) {
    outputs.add("结果", "result", null);
    return;
  }
  
  // 业务逻辑...
}
```

### 4.2 错误处理

使用try-catch包裹可能出错的代码：

```javascript
function main() {
  try {
    var result = processData();
    outputs.add("结果", "result", result);
  } catch (e) {
    outputs.add("结果", "result", null);
  }
}
```

### 4.3 代码组织

- 将业务逻辑封装在函数中
- 保持main函数简洁
- 添加必要的注释
