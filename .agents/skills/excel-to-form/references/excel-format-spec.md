# Excel 格式规范

> 本文档详细说明 Excel 文件的格式要求

## 一、单表结构

Excel 文件只包含一个工作表，每行代表一个表单：

| 列名 | 说明 | 必填 | 示例 |
|-----|------|------|------|
| 表单分组 | 表单所属模块/分组 | 是 | 基础信息 |
| 表单名称 | 表单中文名 | 是 | 项目立项 |
| 表单类型 | 普通表单/流程表单 | 是 | 流程表单 |
| 主表字段 | 主表字段列表，用顿号分隔 | 是 | 立项编号（流水号）、项目名称、委托方（关联-->客户信息） |
| 子表1名称 | 第一个子表名称 | 否 | 项目组成员明细 |
| 子表1字段 | 第一个子表字段 | 否 | 评估师（关联-->评估师）、职责分工（项目负责人/现场勘查） |
| 子表2名称 | 第二个子表名称 | 否 | 付款计划 |
| 子表2字段 | 第二个子表字段 | 否 | 期次、付款比例（数值）、付款金额（金额） |

## 二、字段格式规范

字段之间用顿号（、）分隔，每个字段可包含括号说明：

```
字段名（说明1，说明2）、字段名、字段名（说明）
```

### 括号说明类型

| 说明类型 | 格式 | 示例 | 效果 |
|---------|------|------|------|
| 字段类型 | 直接写类型名 | 项目名称（单行文本） | 指定字段类型 |
| 关联表单 | 关联-->表单名 | 委托方（关联-->客户信息） | 关联表单+自动带出 |
| 下拉选项 | 选项A/选项B | 项目类型（房产评估/土地评估） | 下拉单选 |
| 数值精度 | X位小数 | 建筑面积（2位小数） | 数值字段精度 |
| 单位 | 单位：XXX | 合同金额（单位：元） | 数值字段单位 |
| 公式计算 | 公式：表达式 | 合计金额（公式：SUM(子表.金额)） | 公式字段 |
| 自动生成 | 自动生成 | 创建时间（自动生成） | 只读字段 |
| 关联带出 | 关联带出 | 委托方名称（关联带出） | 只读字段 |

## 三、字段类型自动推断

如不指定类型，系统根据字段名自动推断：

| 字段名特征 | 推断类型 | 说明 |
|-----------|---------|------|
| 编号、单号、编码 | 流水号 | 自动编号 |
| 名称、标题 | 单行文本 | 默认文本 |
| 日期、时间 | 日期 | 日期选择 |
| 金额、费用、价格 | 数值 | 2位小数，单位：元 |
| 数量、个数、人数 | 数值 | 0位小数 |
| 比例、比率 | 数值 | 2位小数，单位：% |
| 备注、说明、描述 | 多行文本 | 长文本 |
| 附件、文件 | 附件 | 文件上传 |
| 照片、图片 | 图片 | 图片上传 |
| 人员、负责人 | 成员 | 人员选择 |
| 状态 | 下拉单选 | 启用/停用 |

## 四、数值字段自动推断

| 字段名特征 | 推断精度 | 推断单位 |
|-----------|---------|---------|
| 金额、费用、价格、成本 | 2位小数 | 元 |
| 数量、个数、人数、天数 | 0位小数 | - |
| 面积、体积 | 2位小数 | 平方米/立方米 |
| 比例、比率、折扣 | 2位小数 | % |
| 重量 | 2位小数 | 千克/吨 |

## 五、日期字段自动推断

| 字段名特征 | 推断类型 |
|-----------|---------|
| 日期、时间、日 | 日期 |
| 日期时间、时间 | 日期时间 |

## 六、智能补充规则

系统自动补充以下字段（无需在Excel中填写）：

1. **所有表单自动补充**：创建人、创建时间
2. **普通表单自动补充**：状态字段（启用/停用）
3. **关联字段自动带出**：关联表单的主字段自动带出
4. **子表自动补充**：子表合计字段（如金额合计）
5. **流程表单**：审批相关字段由宜搭自动处理

## 七、关联字段自动带出

当检测到 `关联-->` 标记时，自动补充关联带出字段：

例如：
- 原字段：`委托方（关联-->客户信息）`
- 自动补充：`委托方名称（关联带出）`、`委托方联系人（关联带出）`、`委托方电话（关联带出）`

## 八、使用示例

### 示例 1：基础 Excel 导入

| 表单分组 | 表单名称 | 表单类型 | 主表字段 | 子表1名称 | 子表1字段 |
|---------|---------|---------|---------|---------|---------|
| 基础信息 | 客户信息 | 普通表单 | 客户名称、联系人、联系电话 | - | - |
| 业务管理 | 项目立项 | 流程表单 | 立项编号（流水号）、项目名称、委托方（关联-->客户信息）、预计金额（金额）、立项说明（多行） | 项目组成员明细 | 评估师（关联-->评估师）、职责分工（项目负责人/现场勘查/报告撰写/审核/其他） |

生成结果：
- 客户信息：自动补充客户编号（流水号）、创建人、创建时间、状态
- 项目立项：自动补充委托方名称（关联带出）、创建人、创建时间
- 规则：自动生成关联规则、公式规则

## 九、注意事项

1. **Excel 文件要求**
   - 必须使用 .xlsx 或 .csv 格式
   - 单表结构，一个工作表包含所有信息
   - 表头必须严格按照规范命名

2. **字段补充说明**
   - 自动补充的字段会标注 `[自动补充]`
   - 用户填写的字段保持原样
   - 如有冲突，以用户填写为准

3. **规则推导限制**
   - 自动推导的规则基于常见业务逻辑
   - 复杂规则可能需要手动调整
   - 推导的规则会标注 `[自动推导]`
