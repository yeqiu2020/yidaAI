## 功能概述

本Skill专注于同步宜搭应用中的**业务规则数据**，与 `yida-config-sync`（配置同步）形成互补：

| Skill | 同步内容 | 输出文件 |
|-------|---------|---------|
| **yida-config-sync** | 应用ID、表单UUID、组件ID | 系统配置清单.md、组件ID清单.md |
| **yida-rule-sync** | 公式、联动规则、校验规则、动作代码 | 系统规则清单.md |

> ⚠️ **注意**：yida-rule-sync 的集成自动化流程功能正在调试中，暂不可用

## 可获取的规则类型

### 1. 集成自动化流程（Automation） ⚠️ 暂不可用
宜搭"集成&自动化"模块中配置的自动化流程，包括：
- **触发器类型**: 表单事件、定时触发、Webhook、手动触发
- **执行动作**: 发送通知、更新数据、新增数据、删除数据、调用接口、发起审批
- **流程状态**: 启用/禁用

> 🔧 **状态**：该功能正在调试中，API 调用成功但返回空数据，暂时无法使用

### 2. 表单字段公式（Formula）
宜搭公式字段的计算逻辑，如：
```
{采购数量} * {采购单价}
DATEDIF({开始日期}, {结束日期}, "D")
```

### 3. 字段联动规则（Linkage）
字段间的联动关系，如：
- 选择供应商 → 自动带出联系人
- 选择产品 → 自动带出单价

### 4. 字段校验规则（Validation）
字段的校验逻辑，如：
- 必填校验
- 正则表达式校验
- 数值范围校验

### 5. 表单动作代码（Actions）
表单页面的生命周期代码，如：
- `didMount` - 页面加载时执行
- `onChange` - 字段值变化时执行
- `onSubmit` - 表单提交时执行

## 使用方式

