## 第1步话术：收集用户身份信息

**已有保存的用户信息时**：

> "📋 检测到您在 **叶秋--宜搭AI开发工作流** 的账号信息：
>
> 📎 平台网址：<https://www.yidatrain.com/>
>
> **姓名**：{sender}
> **手机号**：{phone}
>
> 是否使用此账号发送建议？
>
> - 回复 **是** - 使用此账号继续
> - 回复 **否** - 更换其他账号"

**用户选择更换账号时**：

> "⚠️ 您确定要变更账号信息吗？
>
> 当前账号：{sender} ({phone})
>
> 变更后，下次发送将使用新账号。
>
> 请输入新的账号信息：
>
> 1. **您的姓名**：
> 2. **您的手机号**："

**没有保存的用户信息时**：

> "您好！我来帮您给叶秋发送建议。
>
> ⚠️ **注意**：发送建议需要您先在 **叶秋--宜搭AI开发工作流** 注册账号。
>
> 📎 注册地址：<https://www.yidatrain.com/>
>
> 请先提供您在平台注册的个人信息：
>
> 1. **您的姓名**：
> 2. **您的手机号**：
>
> 我们将验证您在平台的注册身份，未注册用户无法发送建议。"

**读取已保存用户信息（伪代码）**：

```javascript
// 伪代码
const currentUser = readCurrentUser();
if (currentUser.sender && currentUser.phone) {
  // 使用已保存的用户信息
  sender = currentUser.sender;
  phone = currentUser.phone;
  console.log(`📋 使用已保存的用户信息：${sender} (${phone})`);
}
```

## 第1.5步话术：验证用户身份信息

**验证调用（伪代码）**：

```javascript
// 伪代码 - 调用接收端API验证用户
const validationResult = await validateUser(sender, phone);

if (!validationResult.valid) {
  // 验证失败，提示用户
  console.error(validationResult.message);
  return;
}
```

**验证请求示例**（可以复用发送接口，只验证不保存）：

```bash
curl -X POST "https://your-api.com/validate-user" \
  -H "Content-Type: application/json" \
  -d '{
    "sender": "用户姓名",
    "phone": "用户手机号"
  }'
```

**验证结果处理话术**：

✅ **验证通过**：

> "✅ 账号验证通过！
>
> 已确认您的身份：小不点 (15270209736)
>
> 接下来请确认您要发送的反馈类型..."

❌ **验证失败 - 账号不存在**：

> "❌ 账号校验不通过，无法发送。
>
> 系统中未找到您的注册信息。
>
> 📎 请先前往注册：<https://www.yidatrain.com/>
>
> 注册完成后，再回来发送您的建议。"

❌ **验证失败 - 手机号不匹配**：

> "❌ 账号校验不通过，无法发送。
>
> 您提供的姓名和手机号不匹配，请检查：
>
> - 姓名：小不点
> - 手机号：15270209736
>
> 请重新提供正确的注册信息。"

❌ **验证失败 - 其他错误**：

> "❌ 账号校验不通过，无法发送。
>
> 错误信息：\[具体错误原因]
>
> 请检查您的信息后重试，或联系技术支持。"

**保存用户信息**（仅验证通过后），保存到 `config/current-user.json`：

```json
{
  "version": "1.2.0",
  "lastUpdated": "2026-03-25T10:30:00",
  "sender": "用户提供的姓名",
  "phone": "用户提供的手机号"
}
```

**今日已发送满3条时**：

> "❌ 您今日已发送3条建议，达到每日上限。
>
> 请明天再试，或查看您已发送的建议记录。"

## 第2步话术：确认反馈类型

> "请确认您要发送的反馈类型：
>
> 1. 🐛 Bug报告（程序错误）
> 2. 💡 功能建议（新功能需求）
> 3. 📋 需求提交（想要实现的功能需求）
> 4. ❓ 使用问题（操作疑问）
> 5. ⭐ 使用评价（好评或建议）
>
> 请告诉我对应的数字或类型。"

## 第6步话术：反馈结果

**发送成功**：

> "✅ 建议发送成功！
>
> 叶秋已收到您的建议，我们会尽快处理。
>
> 📊 今日发送进度：\[已发送条数]/3 条"

**发送失败**：

> "❌ 发送失败，请稍后重试。
>
> 您的建议已自动保存到本地，可以稍后重新发送。"
