# Excel 格式规范

## 一、单表结构

Excel 文件只包含一个工作表，每行代表一个表单：

| 列名 | 说明 | 必填 | 示例 |
|-----|------|------|------|
| 表单分组 | 表单所属模块/分组 | 是 | 基础资料 |
| 表单名称 | 表单中文名 | 是 | 主数据表 |
| 表单类型 | 普通表单/流程表单 | 是 | 普通表单 |
| 主表字段 | 主表字段列表，用顿号分隔 | 是 | 资料编号（流水号）、资料名称、分类（类别1/类别2） |
| 子表1名称 | 第一个子表名称 | 否 | 明细 |
| 子表1字段 | 第一个子表字段 | 否 | 明细名称、数量（数值）、金额（金额） |
| 子表2名称 | 第二个子表名称 | 否 | 记录 |
| 子表2字段 | 第二个子表字段 | 否 | 记录时间、记录说明 |

## 二、字段格式规范

字段之间用顿号（、）分隔，每个字段可包含括号说明：

```text
字段名（说明1，说明2）、字段名、字段名（说明）
```

| 说明类型 | 格式 | 示例 | 效果 |
|---------|------|------|------|
| 字段类型 | 直接写类型名 | 资料名称（单行文本） | 指定字段类型 |
| 关联表单 | 关联-->表单名 | 选择资料（关联-->基础资料） | 关联表单 |
| 下拉选项 | 选项A/选项B | 分类（类别1/类别2） | 下拉单选 |
| 数值精度 | X位小数 | 数量（0位小数） | 数值字段精度 |
| 单位 | 单位：XXX | 金额（单位：元） | 数值字段单位 |
| 公式计算 | 公式：表达式 | 合计（公式：SUM(明细.金额)） | 公式字段 |
| 自动生成 | 自动生成 | 创建时间（自动生成） | 只读字段 |

填充规则统一写在关联字段说明中：

```text
关联-->目标表单；填充：当前字段=源字段
```

被填充字段的说明列填写自身属性，不再写旧格式 `填充-->XXX.XXX`。

## 三、字段类型自动推断

| 字段名特征 | 推断类型 |
|-----------|---------|
| 编号、单号、编码 | 流水号 |
| 名称、标题 | 单行文本 |
| 日期、时间 | 日期 |
| 金额、费用、价格、成本、余额、额度 | 数值 |
| 数量、个数、人数、天数 | 数值 |
| 比例、比率、折扣 | 数值 |
| 备注、说明、描述 | 多行文本 |
| 附件、文件 | 附件 |
| 照片、图片 | 图片 |
| 人员、负责人、申请人、审批人、审核人 | 成员 |
| 状态、类型、分类、方式 | 下拉单选 |

## 四、智能补充规则

系统只自动补充确定性字段：

1. 所有表单自动补充：创建人、创建时间
2. 普通表单自动补充：状态字段（启用/停用）
3. 流程表单：审批相关字段由宜搭自动处理

系统不自动补充业务语义字段，不自动生成被填充字段，不按行业模板推导规则。

## 五、使用示例

| 表单分组 | 表单名称 | 表单类型 | 主表字段 | 子表1名称 | 子表1字段 |
|---------|---------|---------|---------|---------|---------|
| 基础资料 | 基础资料 | 普通表单 | 资料编号（流水号）、资料名称、分类（类别1/类别2） | - | - |
| 业务处理 | 业务单据 | 流程表单 | 单据编号（流水号）、选择资料（关联-->基础资料）、数量（数值）、说明（多行） | 明细 | 明细名称、数量（数值）、金额（金额） |

生成后，AI 可根据业务语义把 `选择资料` 的字段说明扩展为：

```text
关联-->基础资料；填充：资料名称=资料名称
```

并同步添加只读被填充字段 `资料名称`。
