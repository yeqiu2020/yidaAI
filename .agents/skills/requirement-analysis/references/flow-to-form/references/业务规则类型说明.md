# 业务规则类型说明

## 一、公式规则

### 说明
用于计算字段值，支持数学运算、逻辑判断、日期计算等。

### 常见场景
1. **数值计算**
   - 合计金额 = 单价 × 数量
   - 折扣后金额 = 原价 × 折扣率
   - 差额 = 盘点数量 - 库存数量

2. **日期计算**
   - 借用天数 = 预计归还日期 - 借用日期
   - 逾期天数 = IF(归还日期 > 预计归还日期, 归还日期 - 预计归还日期, 0)
   - 剩余天数 = 到期日期 - TODAY()

3. **汇总计算**
   - 总数量 = SUM(子表.数量)
   - 平均价格 = AVERAGE(子表.单价)
   - 最大数量 = MAX(子表.数量)

4. **文本拼接**
   - 完整地址 = 省 + 市 + 区 + 详细地址
   - 显示名称 = 编号 + "-" + 名称

### 触发时机
- 字段值变更时
- 表单提交时
- 定时触发

---

## 二、关联表单规则

### 说明
建立表单之间的数据关联，支持数据填充和级联选择。

### 常见场景
1. **基础数据引用**
   - 选择产品 → 自动填充产品编码、规格、单价
   - 选择客户 → 自动填充客户地址、联系人、电话

2. **业务单据关联**
   - 归还单关联借用单 → 带出借用明细
   - 入库单关联采购单 → 带出采购明细

3. **多级级联**
   - 选择省 → 筛选市 → 筛选区
   - 选择大类 → 筛选小类 → 筛选具体项目

### 关联方式
- **单选**：一对一关联
- **多选**：一对多关联

### 数据填充
- 关联字段值
- 关联表单的其他字段值（关联属性）

---

## 三、业务规则

### 说明
根据条件自动执行业务操作，如更新字段、创建记录、发送消息等。

### 常见场景
1. **状态流转**
   - 审批通过后更新状态
   - 入库完成后更新库存
   - 归还后更新借用状态

2. **数据同步**
   - 更新关联表单数据
   - 同步库存数量
   - 更新统计信息

3. **记录创建**
   - 自动生成维修工单
   - 自动生成出库记录
   - 自动生成对账单

4. **数据校验**
   - 库存不足时阻止出库
   - 重复提交时提示警告
   - 数据异常时标记提醒

### 规则要素
- **触发条件**：什么时候执行
- **执行动作**：执行什么操作
- **影响范围**：影响哪些数据

---

## 四、自动化规则

### 说明
定时或条件触发的自动化任务，无需人工干预。

### 常见场景
1. **定时提醒**
   - 检定到期前7天提醒
   - 借用超期提醒
   - 库存预警提醒

2. **定时任务**
   - 每日库存盘点
   - 月度报表生成
   - 数据备份

3. **条件触发**
   - 库存低于安全库存时自动补货
   - 超期未归还时自动发送催还通知
   - 故障报修后自动分配维修人员

### 触发器类型
- **定时触发**：按时间周期执行
- **数据变更触发**：数据变化时执行
- **事件触发**：特定事件发生时执行

---

## 五、消息提醒规则

### 说明
在特定条件下向指定人员发送通知消息。

### 常见场景
1. **审批通知**
   - 提交申请时通知审批人
   - 审批完成时通知申请人
   - 审批驳回时通知并说明原因

2. **任务通知**
   - 分配任务时通知执行人
   - 任务即将到期时提醒
   - 任务完成时通知相关人员

3. **预警通知**
   - 库存不足时通知采购员
   - 设备故障时通知维修人员
   - 超期未处理时通知主管

4. **日报/周报**
   - 每日业务汇总推送
   - 周报表发送给管理层

### 发送渠道
- **站内信**：宜搭系统内消息
- **邮件**：电子邮件通知
- **短信**：手机短信（需配置）
- **钉钉**：钉钉工作通知

### 消息内容
支持变量替换，如：
- `{申请人}` 提交了借用申请
- 仪表 `{仪表名称}` 即将到期，请及时检定

---

## 六、聚合表规则

### 说明
对多个表单数据进行汇总统计，生成汇总表供报表使用。

### 常见场景
1. **库存统计**
   - 按产品类别统计库存数量
   - 按仓库统计库存金额
   - 按状态统计仪表数量

2. **业务统计**
   - 按部门统计借用次数
   - 按人员统计完成任务数
   - 按月统计销售额

3. **财务统计**
   - 按客户统计应收金额
   - 按项目统计成本
   - 按品类统计利润

### 聚合方式
- **求和**：数值相加
- **计数**：记录数量
- **平均值**：算术平均
- **最大值**：最大数值
- **最小值**：最小数值

### 配置要素
- **数据源**：从哪个表单取数
- **聚合字段**：对哪个字段进行计算
- **分组字段**：按什么维度分组
- **过滤条件**：筛选哪些数据

---

## 七、报表规则

### 说明
定义数据展示方式和可视化图表。

### 报表类型
1. **明细表**
   - 展示原始数据明细
   - 支持筛选、排序、导出
   - 适用于数据查询

2. **汇总表**
   - 展示聚合后的数据
   - 支持多级分组
   - 适用于统计分析

3. **图表**
   - 柱状图：对比数据大小
   - 折线图：展示趋势变化
   - 饼图：展示占比分布
   - 雷达图：多维度对比

### 配置要素
- **数据来源**：表单或聚合表
- **展示字段**：显示哪些字段
- **筛选条件**：默认过滤条件
- **排序规则**：默认排序方式
- **图表配置**：X轴、Y轴、系列等

---

## 八、数据联动规则

### 说明
一个表单的数据变化自动同步到其他表单。

### 常见场景
1. **库存联动**
   - 出库单提交 → 减少库存表数量
   - 入库单提交 → 增加库存表数量
   - 盘点差异 → 调整库存数量

2. **状态联动**
   - 借用审批通过 → 更新仪表状态为"借出"
   - 归还入库完成 → 更新仪表状态为"在库"
   - 维修完成 → 更新仪表状态为"正常"

3. **信息同步**
   - 基础信息修改 → 同步更新所有关联单据
   - 价格调整 → 更新未审批单据的价格

### 联动方向
- **单向联动**：A → B
- **双向联动**：A ↔ B

---

## 九、审批流程规则

### 说明
定义业务单据的审批流程和流转规则。

### 常见场景
1. **多级审批**
   - 员工提交 → 部门主管审批 → 总经理审批
   - 申请人 → 直接上级 → 部门负责人

2. **条件审批**
   - 金额 > 10000：需财务审批
   - 金额 > 50000：需总经理审批
   - 紧急程度 = "高"：跳过部分节点

3. **会签/或签**
   - 会签：所有审批人都通过才算通过
   - 或签：任一审批人通过即可

### 审批节点
- **审批人**：指定人员、角色、上级
- **审批方式**：会签、或签
- **审批权限**：通过、驳回、转交

### 流转条件
- **条件分支**：根据条件走不同分支
- **超时处理**：超时自动通过或提醒
- **退回规则**：可退回至指定节点

### 抄送规则
- **抄送时机**：提交时、审批完成时
- **抄送对象**：相关人员、角色
- **抄送内容**：单据链接、关键信息
