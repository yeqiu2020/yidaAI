## 一、公式类提示词模板

### 1.1 简版模板（简单计算，1-3个字段）

**适用场景**:

- 简单计算：日期差、年龄、文本拼接等
- 字段较少：1-3个字段
- 逻辑明确：无需额外解释

**模板结构**:

```
【公式类型】：表单公式

【需求】：
（一句话描述做什么计算）

【对应表单字段】：

| 序号 | 字段名称 | 字段ID | 说明 |
|------|----------|--------|------|
| 1 | XXX | xxxField_xxx | |
| 2 | XXX | xxxField_xxx | |
```

**示例**:

```
【公式类型】：表单公式

【需求】：
计算两个日期的天数差

【对应表单字段】：

| 序号 | 字段名称 | 字段ID | 说明 |
|------|----------|--------|------|
| 1 | 开始日期 | dateField_mlkrc6w6 | |
| 2 | 结束日期 | dateField_mlkrc6w8 | |
```

### 1.2 完整版模板（复杂逻辑，子表处理）

**适用场景**:

- 复杂逻辑：多条件判断、嵌套IF
- 子表处理：子表包含判断、汇总
- 字段较多：3个以上字段
- 特殊规则：需要解释业务逻辑

**模板结构**:

```
【公式类型】：表单公式 / 报表公式

【需求描述】：
（详细描述计算逻辑、判断条件、业务场景）

【公式命名】：
（给这个公式起一个清晰的名称）

【对应表单字段】：

**主表字段**

| 序号 | 字段名称 | 字段ID | 说明 |
|------|----------|--------|------|
| 1 | XXX | xxxField_xxx | |
| 2 | XXX | xxxField_xxx | |

**子表#XXX（tableField_xxx）**

| 序号 | 字段名称 | 字段ID | 说明 |
|------|----------|--------|------|
| 1 | XXX | xxxField_xxx | |
| 2 | XXX | xxxField_xxx | |
```

**示例**:

```

【需求描述】：
对产品详情子表内的产品名称进行判断，看是否包含钉钉专业版这个产品在内

【公式命名】：
产品包含判断

【对应表单字段】：

**子表#产品详情（tableField_mlx2nn1y）**

| 序号 | 字段名称 | 字段ID | 说明 |
```
