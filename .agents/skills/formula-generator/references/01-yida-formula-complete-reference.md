## 一、快速开始

### 1.1 什么是宜搭公式

宜搭公式可以提高表单填写效率、降低表单填写错误及自定义数据处理等。此外，宜搭公式还可以完成部分业务逻辑计算和流程自动化处理。

### 1.2 使用场景

- **提高填写效率**：例如分数在90以上时等级为A，否则为B。输入分数后，等级自动判断
- **减少错误**：例如当前库存=入库数量-已出库数量，自动计算避免手工出错
- **数据处理**：文本拼接、日期计算、条件判断等

### 1.3 核心概念

#### 时间戳 vs 日期对象（⚠️ 重要）

| 数据类型 | 来源 | 特点 | 使用方式 |
|---------|------|------|----------|
| **时间戳** | 日期组件字段的值 | 毫秒级数字（如1700000000000） | 必须用 `DATE()` 函数转换为日期对象 |
| **日期对象** | `NOW()`、`TODAY()` 等函数返回 | 日期类型 | **直接**使用，**不要**再用 `DATE()` 包裹 |

**记忆口诀**：
> **字段值**（时间戳）→ 需要 `DATE()` 转换  
> **NOW()/TODAY()**（日期对象）→ **不需要** `DATE()` 包裹

### 1.4 字段引用格式

- 字段名用零宽空格包裹（程序自动生成）
- 所有标点用英文格式
- 比较运算用函数：`GT()`、`GE()`、`LT()`、`LE()`、`EQ()`

### TEXT函数格式化专题

#### 数值格式化

| 格式字符串 | 输入 | 输出 | 说明 |
|-----------|------|------|------|
| `"#,##0.00"` | 1234.5 | 1,234.50 | 千分位+2位小数 |
| `"0.00"` | 1234.5 | 1234.50 | 保留2位小数 |
| `"#,##0"` | 1234.5 | 1,235 | 千分位+整数（四舍五入） |
| `"0%"` | 0.85 | 85% | 百分比 |

#### 日期格式化

| 符号 | 含义 | 示例 |
|------|------|------|
| `yyyy` | 年（4位） | 2024 |
| `MM` | 月（2位） | 03 |
| `dd` | 日（2位） | 06 |
| `HH` | 时（24小时制） | 14 |
| `mm` | 分 | 30 |
| `ss` | 秒 | 45 |
| `E` | 星期 | 星期一 |

**示例**：
```
TEXT(TODAY(), "yyyy年MM月dd日")
// 结果："2024年03月06日"

TEXT(NOW(), "yyyy-MM-dd HH:mm:ss")
// 结果："2024-03-06 14:30:45"
```

## 三、时间函数

### 3.1 获取当前时间

| 函数 | 返回值类型 | 说明 |
|------|-----------|------|
| `NOW()` | 日期对象 | 当前日期时间 |
| `TODAY()` | 日期对象 | 今天 |
| `SYSTIME()` | 日期对象 | 服务器时间 |

⚠️ **注意**：这两个函数返回的是**日期对象**，**不要**用 `DATE()` 包裹！

❌ 错误：`DATE(NOW())`  
✅ 正确：`NOW()`

### 3.2 时间戳转换

| 函数 | 作用 | 使用场景 |
|------|------|----------|
| `DATE(时间戳)` | 时间戳 → 日期对象 | 处理日期组件字段的值 |
| `DATE(年, 月, 日)` | 用年月日构造日期对象 | 构造新的日期 |
| `TIMESTAMP(日期对象)` | 日期对象 → 时间戳 | 给日期组件赋值 |
| `CASCADEDATEINTERVAL(日期区间)` | 计算日期区间的天数 | `CASCADEDATEINTERVAL(日期区间)` |
| `CASCADEDATEINTERVALV2(日期区间)` | 返回日期区间2个日期的天数 | `CASCADEDATEINTERVALV2(日期区间)` |
| `TIME(时, 分, 秒)` | 返回特定时间的十进制数字 | `TIME(14, 30, 0)` |

### 3.3 提取日期部分

| 函数 | 字段值用法 | NOW()用法 |
|------|-----------|-----------|
| `YEAR(日期对象)` | `YEAR(DATE(出生日期))` | `YEAR(NOW())` |
| `MONTH(日期对象)` | `MONTH(DATE(日期字段))` | `MONTH(NOW())` |
| `DAY(日期对象)` | `DAY(DATE(日期字段))` | `DAY(NOW())` |
| `HOUR(日期对象)` | `HOUR(DATE(日期字段))` | `HOUR(NOW())` |
| `MINUTE(日期对象)` | `MINUTE(DATE(日期字段))` | `MINUTE(NOW())` |
| `WEEKNUM(日期对象)` | `WEEKNUM(DATE(日期字段))` | `WEEKNUM(NOW())` |
| `ISOWEEKNUM(日期对象)` | `ISOWEEKNUM(DATE(日期字段))` | `ISOWEEKNUM(NOW())` |
| `SECOND(日期对象)` | `SECOND(DATE(日期字段))` | `SECOND(NOW())` |

### 3.4 日期计算

| 函数 | 作用 | 示例 |
|------|------|------|
| `DAYS(结束, 开始)` | 两个日期间的天数差 | `DAYS(DATE(结束), DATE(开始))` |
| `DATEDELTA(日期, 天数)` | 日期加减天数 | `DATEDELTA(DATE(日期), 7)` |
| `WORKDAY(开始, 工作日数)` | 计算N个工作日后的日期 | `WORKDAY(DATE(开始), 5)` |
| `NETWORKDAYS(开始, 结束)` | 两个日期间的工作日天数 | `NETWORKDAYS(DATE(开始), DATE(结束))` |
| `DAYS360(开始, 结束)` | 按360天/年计算天数差 | `DAYS360(DATE(开始), DATE(结束))` |

### 3.5 日期边界

| 函数 | 作用 | 示例 |
|------|------|------|
| `DAYBEGIN(时间戳)` | 将时分秒置零 | `DAYBEGIN(日期字段)` |
| `DAYEND(时间戳)` | 将时分秒置为最大 | `DAYEND(日期字段)` |
| `YEARBEGIN(时间戳)` | 获取年份首个日期 | `YEARBEGIN(日期字段)` |
| `YEAREND(时间戳)` | 获取年份最后日期 | `YEAREND(日期字段)` |

### 3.6 常见日期错误

| 错误用法 | 正确用法 | 说明 |
|----------|----------|------|
| `YEAR(DATE(NOW()))` | `YEAR(NOW())` | `NOW()`返回日期对象，不需要`DATE()` |
| `YEAR(日期字段)` | `YEAR(DATE(日期字段))` | 字段值是时间戳，需要`DATE()`转换 |
| `DAYS(结束日期, 开始日期)` | `DAYS(DATE(结束), DATE(开始))` | 两个参数都需要是日期对象 |
| `DAYS(DATE(结束), DATE(开始)) * 24` | `(结束日期 - 开始日期) / 3600000` | DAYS只返回整天数，精确小时用时间戳计算 |

## 四、逻辑函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `IF(条件, 真值, 假值)` | 条件判断<br>⚠️ **真值和假值都必须给值，不能留空** | `IF(GT(成绩, 60), "及格", "不及格")` |
| `EQ(值1, 值2)` | 等于 | `EQ(状态, "已完成")` |

### IF函数强制规范

**核心原则：IF函数的真值和假值都必须给明确的值，不能留空字符串！**

| 场景 | 错误示范 | 正确示范 |
|------|---------|---------|
| 校验场景 | `IF(GT(天数,30),"超过30天","")` | `IF(GT(天数,30),"❌ 超过30天","✅ 符合要求")` |
| 赋值场景 | `IF(EQ(状态,"完成"),"已完成","")` | `IF(EQ(状态,"完成"),"已完成","进行中")` |

### EMPLOYEE函数详解

**表达式**：
```
EMPLOYEE(工号数组)
```

**描述**：根据传入的工号数组，返回对应的人员信息对象数组（即人员组件底层的值）。

**⚠️ 重要：成员组件公式中只能使用特定函数**

成员组件（人员选择）的公式编辑器中，**只能使用以下12个函数**：

#### 一、人员获取函数（5个）

| 函数 | 返回值类型 | 说明 |
|------|-----------|------|
| `DirectorBuilder` | 数组 | 获取主管信息 |
| `EMPLOYEE` | 数组 | 工号数组转人员对象数组 |
| `ESIGNUSER` | 文本 | 获取签署用户信息 |
| `USER` | 数组 | 获取当前登录人 |
| `UserBuilder` | 数组 | 构建人员对象 |

#### 二、集合函数（4个）

| 函数 | 返回值类型 | 说明 |
|------|-----------|------|
| `DIFFERENCESET` | 数组 | 返回差集（在数组1但不在数组2中） |
| `INTERSECTIONSET` | 数组 | 返回交集 |
| `SUBSET` | 布尔 | 判断是否为子集 |
| `UNIONSET` | 数组 | 返回并集（去重） |

#### 三、其它函数（2个）

| 函数 | 返回值类型 | 说明 |
|------|-----------|------|
| `GetArrayItem` | 范型 | 获取数组元素（索引从1开始） |
| `GetObjectField` | 范型 | 获取对象属性 |

**不可用的函数**（在成员组件公式中会报错）：
- ❌ `IF`、`AND`、`OR` 等逻辑函数
- ❌ `ISEMPTY`、`ISNULL` 等判断函数
- ❌ `CONCATENATE` 等文本函数
- ❌ `ADD`、`SUM` 等数学函数
- ❌ `USERFIELD`、`DEPTNAME` 等（虽然属于人员函数，但在成员组件公式中不可用）

**典型应用场景**：

| 场景 | 公式 |
|------|------|
| 合并两个成员字段 | `EMPLOYEE(UNIONSET(成员1,成员2))` |
| 合并三个成员字段 | `EMPLOYEE(UNIONSET(成员1,成员2,成员3))` |
| 获取共同成员 | `EMPLOYEE(INTERSECTIONSET(成员1,成员2))` |

**示例**：
```
EMPLOYEE(UNIONSET(成员1,成员2))
// 返回: [{"label":"张三","key":"userid1"},{"label":"李四","key":"userid2"}]
// 说明：将成员1和成员2的工号数组合并，去重后转换为人员对象数组
```

### UNIONSET / INTERSECTIONSET / DIFFERENCESET 函数详解

**表达式**：
```
UNIONSET(数组1, 数组2, ...)       // 并集（去重）
INTERSECTIONSET(数组1, 数组2)     // 交集
DIFFERENCESET(数组1, 数组2)       // 差集（在数组1但不在数组2中）
```

**描述**：集合运算函数，用于处理成员字段的工号数组。

**参数说明**：
- 成员组件的值实际上是工号数组，如 `["userid1", "userid2"]`
- 这些函数直接操作工号数组，返回新的工号数组
- 需要配合 `EMPLOYEE` 函数将结果转换为人员对象数组

**示例**：
```
// 成员1 = ["user1", "user2"]
// 成员2 = ["user2", "user3"]

UNIONSET(成员1,成员2)
// 返回: ["user1", "user2", "user3"] (去重合并)

INTERSECTIONSET(成员1,成员2)
// 返回: ["user2"] (共同成员)

DIFFERENCESET(成员1,成员2)
// 返回: ["user1"] (只在成员1中)
```

#### SUBSET 函数

**表达式**：
```
SUBSET(数组1, 数组2)
```

**描述**：判断数组1是否为数组2的子集，返回布尔值。

**示例**：
```
// 成员1 = ["user1"]
// 成员2 = ["user1", "user2"]

SUBSET(成员1, 成员2)
// 返回: true (成员1是成员2的子集)

SUBSET(成员2, 成员1)
// 返回: false (成员2不是成员1的子集)
```

#### GetArrayItem 函数

**表达式**：
```
GetArrayItem(数组, 索引)
```

**描述**：从数组中获取指定索引的元素，**索引从1开始**。

**示例**：
```
// 成员 = ["userid1", "userid2", "userid3"]

GetArrayItem(成员, 1)
// 返回: "userid1" (第1个元素)

GetArrayItem(成员, 2)
// 返回: "userid2" (第2个元素)
```

---

#### GetObjectField 函数

**表达式**：
```
GetObjectField(对象, "属性名")
```

**描述**：从标准JSON对象中获取指定属性的值。

**常用属性名**：
| 属性名 | 说明 |
|--------|------|
| `"key"` | userId / 部门ID |
| `"label"` | 显示名称 |
| `"avatar"` | 头像地址 |

**示例**：
```
// 先通过 UserBuilder 获取人员对象
// 返回: [{"label":"张三","key":"userid1"}]

GetObjectField(GetArrayItem(UserBuilder(成员), 1), "label")
// 返回: "张三"

GetObjectField(GetArrayItem(UserBuilder(成员), 1), "key")
// 返回: "userid1"
```

### USERFIELD函数详解

**表达式**：
```
USERFIELD(成员字段, "属性名")
```

**描述**：直接获取成员字段的指定属性值，**无需使用构造器函数组合**，是最简洁的成员信息获取方式

**常用属性**：
| 属性名 | 说明 |
|--------|------|
| `"name"` | 姓名 |
| `"mobile"` | 手机号 |
| `"email"` | 邮箱 |
| `"title"` | 职位 |
| `"workNo"` | 工号 |
| `"deptName"` | 部门名称 |

**示例**：
```
USERFIELD(成员, "mobile")
// 返回: "13800138000"

USERFIELD(成员, "name")
// 返回: "张三"
```

**优势**：
- ✅ 语法简洁，一个函数即可获取属性
- ✅ 无需组合 `GetArrayItem` + `GetObjectField`
- ✅ 支持获取手机号等敏感信息（需有相应权限）

### 9.3 构造器函数详解

#### UserBuilder - 成员构造函数

**表达式**：

```
UserBuilder(["userid1", "userid2"] | 成员组件)
```

**描述**：用于生成指定userId列表或指定成员组件对应的人员模型集合

**返回值**：`[{人员对象}, {人员对象}]`

#### DirectorBuilder - 主管构造函数

**表达式**：
```
DirectorBuilder("" | "userid", level)
```

**描述**：用于生成当前登录人或指定某人的第 level 级主管

**表达式**：
```
DeptBuilder(无参数 | userid | 单选成员组件)
```

**描述**：根据条件获取指定部门对象模型函数

**示例**：

```
// 返回当前登录人的部门
// 返回: [{"label":"技术部","key":"dept123"}]
```

#### GetObjectField - 对象属性提取函数

**表达式**：
```
GetObjectField(标准Json对象模型, "fieldKey")
```

**描述**：用于从指定的标准json对象中获取指定key对应的value属性值

**⚠️ 注意**：不支持在子表单中使用

**常用属性名**：
| 属性名 | 说明 | 适用对象 |
|--------|------|----------|
| `"key"` | userId / 部门ID | 人员对象、部门对象 |
| `"label"` | 显示名称 | 人员对象、部门对象 |
| `"avatar"` | 头像地址 | 人员对象 |
| `"businessWorkNo"` | 工作账号 | 人员对象 |

**示例**：
```
GetObjectField(GetArrayItem(UserBuilder(成员组件), 1), "label")
// 返回: "小王(工号11)"
```

#### GetArrayItem - 数组元素获取函数

**表达式**：
```
GetArrayItem(标准JsonArray类型, n)
```

**描述**：用于从指定的标准JsonArray中获取第n个数据单元

**⚠️ 注意**：索引从1开始，n=1代表第1个

**示例**：
```

// 返回: {"label":"小王","key":"userid123"}
```

## 十一、常见错误与解决方案

### 错误1：使用了不存在的函数或大小写错误

**常见错误**：
- 使用 `SUBTRACT`、`DIVIDE`（宜搭无此函数，用 `-` `/` 运算符）
- **大小写错误**：`GETARRAYITEM` 应为 `GetArrayItem`
- 在表单场域使用 `MAPX`、`SUMPRODUCTX`（报表场域专用）

**解决方案**：
- 查阅本文档确认函数存在
- **严格按文档大小写使用函数**

### 错误2：日期函数参数类型错误

❌ **错误**：`YEAR(DATE(NOW()))`  
✅ **正确**：`YEAR(NOW())`

❌ **错误**：`YEAR(日期字段)`  
✅ **正确**：`YEAR(DATE(日期字段))`

### 错误3：IF函数真假值留空

❌ **错误**：`IF(GT(成绩,60),"及格","")`  
✅ **正确**：`IF(GT(成绩,60),"及格","不及格")`

### 错误4：混淆 ARRAYGET 和 GetArrayItem

| 函数 | 用途 | 索引起始 |
|------|------|---------|
| `ARRAYGET(数组, 位置)` | 通用数组函数，用于子表字段等 | **从1开始** |
| `GetArrayItem(数组, 索引)` | 构造器函数配套使用 | **从1开始** |

### 错误5：子表字段ID格式错误

❌ **错误**：`tableField_xxx.textField_yyy`  
✅ **正确**：直接使用 `textField_yyy`

### 错误6：在成员组件公式中使用不支持的函数

❌ **错误**：在成员组件公式中使用 `IF(ISEMPTY(成员1),成员2,成员1)`  
✅ **正确**：`EMPLOYEE(UNIONSET(成员1,成员2))`

**问题说明**：
成员组件（人员选择）的公式编辑器有严格的函数限制，只能使用：
- `EMPLOYEE`、`UNIONSET`、`INTERSECTIONSET`、`DIFFERENCESET` 等集合函数
- `USER`、`USERFIELD`、`DIRECTOR` 等人员相关函数

**不可用的函数**：
- ❌ `IF`、`AND`、`OR` 等逻辑函数
- ❌ `ISEMPTY`、`ISNULL` 等判断函数
- ❌ `CONCATENATE` 等文本函数

**解决方案**：
- 合并成员字段：`EMPLOYEE(UNIONSET(成员1,成员2))`
- 获取共同成员：`EMPLOYEE(INTERSECTIONSET(成员1,成员2))`
