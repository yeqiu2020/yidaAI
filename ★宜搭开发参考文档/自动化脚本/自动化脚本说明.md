1.简介
1.1 什么是脚本节点
宜搭流程支持用户在设计当前流程、集成自动化的过程中，添加「脚本」类型的开发者节点。
通过脚本节点，使用JavaScript的开发脚本（原Groovy节点已不推荐使用），可在业务逻辑中手动在业务流中插入一些静态变量或做基础上游节点带来的上下文数据，方便业务流程的灵活配置。
1.2 使用场景
在设计期中，添加脚本节点，通过编写JavaScript代码，可以实现对input数据的取值，以及对中间数据加工处理，最终通过output的内置对象的数据注入，实现在业务流编排中的脚本化的数据处理能力。

2.添加子流程节点
路径1：编辑流程表单 >> 进入流程设计页面 >> 在分子分支节点类型下，选择添加「JavaScript」节点。
路径2：编辑应用 >> 集成与自动化 >> 选择具体的自动化流并进入设计配置，选择添加「JavaScript」节点。




3.JavaScript节点配置
1. 新建节点
a. Step1
● 选择当前应用内的其他流程表单作为子流程的触发表单。


2. 编写代码
a. Step2
● Input对象：可以选取当前上下游的字段或静态值。所有手动设置的InputObj可以在代码块面板中进行引用及处理。
● output对象：当前节点的数据输出载体对象，可以基于object对象的方法进行数据操作。
● 代码块：这部分是脚本编写区域，可以理解为一个JavaScript代码编辑器插件，配合内置的input和output对象，可以使用代码进行逻辑拼装。


3. 测试代码
a. Step3
● 可以在inputObj中输入测试数据，点击测试按钮，可以获得测试的输出数据。



4. 消费数据
a. Step4
● 在脚本节点下方的其他节点中，当选取字段类型时，就可以看到前置的脚本节点output节点对应字段


4 其他说明：
1. 新的脚本节点，代替了原groovy节点，JavaScript具有更广泛的开发者群体。
2. JavaScript节点仅支持ES5语法，不支持ES6及以上的语法
3. 暂不支持批量更新节点的处理。
4. 请勿进行大内存场景的数据处理，超过10M(目前暂定10M，后续宜搭会根据实际情况调整)会触发内存超限错误。CPU占用超过5S会触发自动保护机制(例如写个死循环)会报错。
5. 不支持xhr、fetch网络请求，window、console、print等顶级对象和函数
6. 支持在代码块里定义function
7. 请不要在function之外添加return语句

宜搭低代码平台中JavaScript脚本编辑器的三个核心概念。
这三个概念构成了一个完整的数据处理链条：​输入（Input）→ 处理（代码块）→ 输出（Output）​​。

1. Input对象（输入对象）
核心定义：​
Input对象是当前JavaScript节点的​数据输入源​​。它是一个预先构建好的JavaScript对象（通常命名为 inputObj），其内容来源于您在配置面板中手动选择的上游数据字段或设置的静态值。
详细解释：​
● •
数据来源​：正如您在图中左侧看到的“表单事件触发”节点连接着“JavaScript”节点，这意味着“JavaScript”节点可以获取到来自“表单提交”的数据。
    ○ •
上游字段​：您可以通过下拉菜单，直接选择上游节点（如表单事件）传递过来的字段，例如图中的“楼宇名称”、“楼宇编号”。这些字段的值会被自动填入 inputObj。
    ○ •
静态值​：您也可以手动输入一个固定的值（如数字100、文本"成功"）。
● •
在代码中的使用​：在“代码块”区域编写JavaScript代码时，您可以直接引用这个 inputObj来获取所需的数据。
    ○ •
访问方式​：例如，如果您勾选了“楼宇名称”字段，在代码中就可以通过 inputObj.楼宇名称或 inputObj['楼宇名称']来获取用户提交的具体楼宇名称字符串。
简单比喻：​ Input对象就像一个​​原材料配送箱​​。上游工序（如表单提交）将各种原料（数据字段）准备好，您只需要在清单（Input对象配置区）上勾选本次加工需要哪些原料，这些原料就会被整齐地放进箱子（inputObj）里，供您（代码块）直接取用。

2. 代码块
核心定义：​
代码块是核心的​业务逻辑处理中心​​。它本质上是一个内嵌的JavaScript代码编辑器，您在此处编写标准的JavaScript代码来实现复杂的业务逻辑、计算、数据转换或调用API等。
详细解释：​
● •
功能​：它接收来自Input对象的数据，进行加工处理，然后将结果赋值给Output对象。
● •
与Input/Output的配合​：
    a. 1.
读取Input​：在代码中，您会读取 inputObj中的值进行计算或判断。例如：var buildingName = inputObj.楼宇名称;（将楼宇名称存入一个变量）。
    b. 2.
编写逻辑​：您可以进行各种操作，如if...else条件判断、for循环、字符串拼接、数学运算、甚至调用平台内置或第三方API。
    c. 3.
写入Output​：处理完成后，通过 outputs.add()方法将结果添加出去。
图片代码示例分析：​
// 从Input对象获取数据（假设inputObj已包含所需数据）
var buildingName = inputObj.楼宇名称；

// 执行逻辑：获取当前日期
var toDay = new Date();

// 将处理结果写入Output对象
outputs.add("楼宇负责人姓名", "name", "张三"); // 添加静态值
outputs.add("楼宇个数", "buildingCount", 20); // 添加数字
outputs.add("日期", "date", toDay.toString()); // 添加经过计算的日期字符串
简单比喻：​ 代码块就是​​中央厨房​​。它从配送箱（Input对象）里取出原材料，根据食谱（您写的代码逻辑）进行清洗、切割、烹饪（数据处理），最后将做好的菜肴（处理结果）装盘，准备送往下一个窗口（Output对象）。

3. Output对象（输出对象）
核心定义：​
Output对象是当前JavaScript节点的​数据输出载体​​。它负责接收代码块处理后的结果，并将其封装成一个对象（通常命名为 outputObj），传递给流程中的下一个节点使用。
详细解释：​
● •
操作方法​：通过代码块中内置的 outputs.add()方法来添加输出数据。这个方法通常接受多个参数，图中提示为 outputs.add("名称", "键", 值)。
    ○ •
名称​：变量的显示名称，用于下游节点选择时易于识别（如“楼宇负责人姓名”）。
    ○ •
键​：变量在代码中被引用的键名（如 name）。
    ○ •
值​：变量的具体值，可以来自变量、计算结果或静态值。
● •
下游使用​：当这个JavaScript节点执行完毕后，它输出的 outputObj就会成为下游节点（如图中的“新增数据”节点）的Input对象。下游节点可以直接选择“楼宇负责人姓名”、“楼宇个数”等字段作为自己的输入。
简单比喻：​ Output对象就是一个​​成品配送窗口​​。厨房（代码块）将做好的菜肴（数据结果）贴上标签（名称和键）放在窗口。下一个工序的工人（下游节点）可以直接从这个窗口取走他需要的成品（如下一个节点需要“楼宇负责人姓名”），继续进行后续操作。
总结与数据流
整个过程的逻辑非常清晰，形成了一个闭环：
1. 1.
配置Input​：在“Input对象”区域，定义这个脚本节点需要​​接收什么数据​​（来自上游或静态值）。
2. 2.
编写代码​：在“代码块”区域，编写JavaScript逻辑来​​处理这些数据​​。你可以使用 inputObj获取输入，用 outputs.add()设置输出。
3. 3.
定义Output​：通过代码中的 outputs.add()方法，明确这个脚本节点要​​输出什么数据​​给下游。
以图片场景为例，数据流是：​
表单提交事件​ （提交了楼宇信息）→ ​​JavaScript节点​​ （inputObj接收楼宇信息 → 代码块计算负责人、个数、日期 → outputObj生成结果）→ ​​新增数据节点​​ （获取 outputObj中的结果，如负责人姓名，并写入数据库）。
希望这个详细的解释能帮助您彻底理解宜搭脚本中这三个核心概念的作用与关系。
