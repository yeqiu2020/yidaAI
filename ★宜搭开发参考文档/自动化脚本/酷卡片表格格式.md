# 酷卡片表格数据格式规范

> 宜搭酷卡片组件表格数据结构标准
> 版本: v1.0.0
> 创建时间: 2026-02-23

---

## 一、概述

酷卡片是宜搭中用于展示结构化数据的组件，支持表格形式的数据展示。本文档定义了酷卡片表格数据的标准格式，用于数据转换和接口对接。

---

## 二、数据格式标准

### 2.1 完整结构

```json
{
  "data": [
    {
      "field1": "value1",
      "field2": "value2"
    }
  ],
  "meta": [
    {
      "aliasName": "显示名称",
      "alias": "字段名",
      "dataType": "STRING",
      "weight": 40
    }
  ]
}
```

### 2.2 字段说明

#### data 数组
| 属性 | 类型 | 说明 |
|------|------|------|
| 业务字段名 | any | 使用业务字段名（如menuName），非宜搭字段ID |

#### meta 数组
| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| aliasName | string | 是 | 字段显示名称，用于表头展示 |
| alias | string | 是 | 字段名，与data中的字段名对应 |
| dataType | string | 是 | 数据类型，大写：STRING/NUMBER/DATE |
| weight | number | 是 | 权重，控制列的显示顺序，从大到小排列 |

## 三、正确示例

### 3.1 标准格式示例

```json
{
  "data": [
    {
      "menuName": "红烧肉",
      "price": "¥20",
      "quantity": "2份"
    },
    {
      "menuName": "西红柿炒蛋",
      "price": "¥12",
      "quantity": "3份"
    },
    {
      "menuName": "土豆烧牛腩",
      "price": "¥35",
      "quantity": "1份"
    }
  ],
  "meta": [
    {
      "aliasName": "菜名",
      "alias": "menuName",
      "dataType": "STRING",
      "weight": 40
    },
    {
      "aliasName": "价格",
      "alias": "price",
      "dataType": "STRING",
      "weight": 30
    },
    {
      "aliasName": "份数",
      "alias": "quantity",
      "dataType": "STRING",
      "weight": 20
    }
  ]
}
```

### 3.2 关键点说明

1. **data中使用业务字段名**
   - ✅ 正确：`"menuName": "红烧肉"`
   - ❌ 错误：`"textField_ml20hmaa": "红烧肉"`

2. **dataType使用大写**
   - ✅ 正确：`"dataType": "STRING"`
   - ❌ 错误：`"dataType": "string"` 或 `"dataType": "text"`

3. **weight递减控制顺序**
   - 第一列：weight = 40
   - 第二列：weight = 30
   - 第三列：weight = 20

4. **排除系统字段**
   - 需要排除宜搭自动生成的 `rowId` 字段
   - ✅ 正确：meta中不包含rowId
   - ❌ 错误：meta中包含 `{aliasName: "rowId", alias: "rowId", ...}`

## 四、常见错误

### 错误1：使用宜搭字段ID作为data字段名

```json
// ❌ 错误 - 使用宜搭字段ID
{
  "data": [
    {
      "textField_ml20hmaa": "红烧肉",
      "numberField_ml20hmac": "20",
      "rowId": "73666981PUS23ESKNVLCOB4B4QG72IF4X02LMC14"
    }
  ]
}

// ✅ 正确 - 使用业务字段名
{
  "data": [
    {
      "menuName": "红烧肉",
      "price": "¥20"
    }
  ]
}
```

### 错误2：dataType使用小写

```json
// ❌ 错误 - 小写dataType
{
  "meta": [
    {
      "dataType": "text"
    }
  ]
}

// ✅ 正确 - 大写dataType
{
  "meta": [
    {
      "dataType": "STRING"
    }
  ]
}
```

### 错误3：包含rowId字段

```json
// ❌ 错误 - 包含rowId
{
  "data": [
    {
      "menuName": "红烧肉",
      "rowId": "xxx"
    }
  ],
  "meta": [
    { "alias": "menuName", ... },
    { "alias": "rowId", ... }  // 不应该包含
  ]
}

// ✅ 正确 - 排除rowId
{
  "data": [
    {
      "menuName": "红烧肉"
    }
  ],
  "meta": [
    { "alias": "menuName", ... }
  ]
}
```

### 错误4：字段映射不一致

```json
// ❌ 错误 - data和meta字段不对应
{
  "data": [
    { "menuName": "红烧肉" }
  ],
  "meta": [
    { "alias": "dishName", ... }  // 与data中的menuName不匹配
  ]
}

// ✅ 正确 - 字段完全对应
{
  "data": [
    { "menuName": "红烧肉" }
  ],
  "meta": [
    { "alias": "menuName", ... }
  ]
}
```

## 六、转换脚本示例

### 6.1 完整转换脚本

```javascript
// 子表数据转换为酷卡片表格数据格式
// 版本号: v1.0.0

function main() {
  // 获取子表数据
  var subTableData = subtableData || [];
  
  // 解析JSON字符串
  if (typeof subTableData === "string") {
    try {
      subTableData = JSON.parse(subTableData);
    } catch (e) {
      outputs.add("表格数据", "tableData", null);
      return;
    }
  }
  
  // 验证数据
  if (!subTableData || !Array.isArray(subTableData) || subTableData.length === 0) {
    outputs.add("表格数据", "tableData", null);
    return;
  }
  
  // 字段映射配置：宜搭字段ID -> 业务字段
  var fieldMapping = {
    'textField_ml20hmaa': { alias: 'menuName', aliasName: '菜名' },
    'numberField_ml20hmac': { alias: 'price', aliasName: '价格' },
    'numberField_ml20hmad': { alias: 'quantity', aliasName: '份数' }
  };
  
  // 构建meta
  var meta = [];
  var weight = 40;
  
  for (var fieldId in fieldMapping) {
    var mapping = fieldMapping[fieldId];
    var dataType = "STRING";
    
    if (fieldId.indexOf("numberField") === 0 || fieldId.indexOf("moneyField") === 0) {
      dataType = "NUMBER";
    } else if (fieldId.indexOf("dateField") === 0) {
      dataType = "DATE";
    }
    
    meta.push({
      aliasName: mapping.aliasName,
      alias: mapping.alias,
      dataType: dataType,
      weight: weight
    });
    
    weight = weight - 10;
  }
  
  // 构建data
  var data = [];
  for (var i = 0; i < subTableData.length; i++) {
    var row = subTableData[i];
    var newRow = {};
    
    for (var fieldId in fieldMapping) {
      var alias = fieldMapping[fieldId].alias;
      if (row.hasOwnProperty(fieldId)) {
        newRow[alias] = row[fieldId];
      }
    }
    
    data.push(newRow);
  }
  
  // 输出
  outputs.add("表格数据", "tableData", {
    data: data,
    meta: meta
  });
}

main();
```

### 6.2 关键转换逻辑

1. **字段映射**：建立宜搭字段ID到业务字段名的映射
2. **排除系统字段**：跳过 `rowId` 等系统字段
3. **类型转换**：将宜搭字段类型转换为酷卡片dataType（大写）
4. **数据重组**：根据映射关系重组data数组

## 七、验证清单

在提交数据前，请检查以下项目：

- [ ] data中的字段名是业务字段名，非宜搭字段ID
- [ ] meta中的alias与data中的字段名完全一致
- [ ] dataType使用大写（STRING/NUMBER/DATE）
- [ ] 不包含rowId等系统字段
- [ ] weight值正确设置，控制列顺序
- [ ] data和meta数组长度匹配
