# UI 交互与负面用例模式

> 能力域：UI 交互 / 校验与规则 / 流程审批 / 权限与安全
> 执行工具：js-action-tester / playwright-cli / data-tester
> 测试层级：UI E2E / 宜搭 API

---

## 正向 UI 模式

### P21：表单JS动作代码执行正确

**场景：** 表单内的 JS 动作代码（表单动作、字段联动、条件显示等）执行结果正确

| 属性 | 值 |
|------|-----|
| 优先级 | P0 |
| 测试层级 | UI E2E |
| 执行工具 | js-action-tester |
| 能力域 | UI 交互 |

**占位符：**
- `{表单名称}` — 含 JS 动作的表单
- `{JS代码类型}` — 表单动作 / 字段联动 / 条件显示 / 字段校验
- `{触发操作}` — 触发 JS 执行的操作（如选择下拉值、点击按钮）
- `{预期结果}` — JS 执行后的预期效果（如字段值变化、组件显示/隐藏）

**前置条件：**
- js-action-tester 可访问专用测试应用
- Cookie 有效

**操作步骤：**
1. 在专用测试应用中创建测试表单
2. 上传 JS 代码并绑定事件
3. 执行 {触发操作}
4. 验证 {预期结果}

**断言：**
- {预期结果} 成立（量化：DOM 属性值、字段值、元素可见性）

**产品依据：** js-action-tester SKILL.md
