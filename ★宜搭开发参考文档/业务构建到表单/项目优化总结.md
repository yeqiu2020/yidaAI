## 🔧 核心修复

### 1. 子表字段生成修复

**问题描述**：
- 生成的子表JSON中 `children` 数组为空
- 对比标准格式发现子表需要完整的字段对象，而非简化配置

**修复方案**：
修改 `yida_field_templates.js` 中的 `TableField` 模板：

```javascript
// ❌ 旧方案：使用简化的字段配置
const columns = (config.columns || []).map(processSubField);

// ✅ 新方案：使用完整的字段模板生成children
const children = (config.columns || []).map((col) => {
  const templateFn = FieldTemplates[col.type];
  const childField = templateFn(col);
  childField.props.isCustomStore = true;
  return childField;
});
field.children = children;
```

**修复效果**：
- ✅ 子表 `children` 数组包含完整的字段对象
- ✅ 每个子字段都有独立的 fieldId、props 等完整属性
- ✅ 支持所有字段类型作为子表字段
- ✅ 子表内的公式字段正确计算 marks 位置

---

### 2. 子表公式字段支持

**新增功能**：
在 `form_generator_v2.js` 中添加子表公式处理逻辑：

```javascript
// 处理子表内的公式字段
if (fieldConfig.type === 'TableField' && field.children) {
  for (let i = 0; i < field.children.length; i++) {
    const childField = field.children[i];
    const childConfig = fieldConfig.columns[i];
    
    if (childConfig.valueType === 'formula') {
      // 子表公式只能引用同一子表内的字段
      const subFields = this.generatedFields.filter(f => f.parentLabel === fieldConfig.label);
      const formulaText = replaceFormulaPlaceholders(childConfig.formulaTemplate, subFields);
      const marks = calculateFormulaMarks(formulaText, subFields);
      // ... 设置公式和marks
    }
  }
}
```

**测试验证**：
生成的 `库存盘点表.json` 中：
- ✅ "盘点差值" 字段正确设置为公式类型
- ✅ 公式内容：`​盘点数量​-​库存量​` (含零宽空格)
- ✅ marks 数组正确标记字段引用位置

## 📁 临时文件管理优化

### 新策略：固定临时文件

**旧问题**：
- 每次测试生成新的临时文件
- 需要手动删除临时文件
- 文件散落在不同目录

**新方案**：
```javascript
// 使用固定的临时输出文件
const TEMP_OUTPUT = path.join(__dirname, 'temp', 'temp_output.json');

// 测试模式和正式模式
node test_generator.js ./config/库存盘点表.js --test    # 临时测试
node test_generator.js ./config/库存盘点表.js            # 正式生成
```

**优势**：
- ✅ 临时测试始终覆盖同一文件 `temp/temp_output.json`
- ✅ 用户无感知，不需要手动清理
- ✅ 正式生成输出到 `output/` 目录
- ✅ 清晰的模式区分

- 批量生成多个表单
- 自动组织项目目录结构
- 生成项目文档

### 3. 使用编程方式

```javascript

const generator = new FormGeneratorV2();

  formName: '测试表单',
  fields: [
    { type: 'TextField', label: '姓名' },
    { type: 'NumberField', label: '年龄' }
  ]

generator.saveToFile(formJson, './output/测试表单.json');
```
