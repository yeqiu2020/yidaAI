| 代码类型 | 生成目录 |
|---------|---------|
| 所有代码类型 | 【{项目目录}/{表单目录}/代码/】 |

1. 用户指定项目路径 → 项目案例模式
2. 用户说"场景案例"/"案例库" → 场景案例模式
3. 默认根据工作目录判断
