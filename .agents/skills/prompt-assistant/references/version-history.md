# 版本历史（prompt-assistant）

> 本文件由 SKILL.md 下沉而来。当前版本见 [../SKILL.md](../SKILL.md) 底部"版本信息"。

## v2.7.0（2026-05-24，当前版本）

- **【强制】新增步骤5.3**：生成跨表单代码提示词时，应用ID和表单UUID必须从 `系统配置清单.md` 读取真实值直接填入，严禁留占位符
- **【强制】强化步骤2**：明确要求从系统配置清单读取的ID必须直接填入，并给出查找方法说明
- **根因**：此前未明确约束，导致提示词中留 `需从系统配置获取` 占位符，用户需二次提醒才填入，影响体验

## v2.6.0

- **新增保存前三条铁律**：严禁合并提示词到已有文件、严禁删除已有提示词文件、必须先扫描目录确定序号
- **澄清规则13适用范围**：规则13仅适用于同一文件内的列表排序，不适用于文件命名，每个独立文件内编号就是"提示词-1"
- **根因**：此前因未明确这些约束，导致合并文件→误删文件→序号冲突的连锁错误

## v2.5.0

- **文件存储规范重大变更**：从"集中式存储"改为"独立文件存储"
  - 每个公式/代码都有独立的提示词文件
  - 使用序号命名（如 `1.成员合并公式提示词.md`）
  - 与公式JSON文件一一对应（`1.成员合并公式.json`）
  - 便于单独管理和查找
- 更新文件保存步骤说明
- 更新文件命名规范表格
