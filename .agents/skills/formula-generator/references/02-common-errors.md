## 一、函数相关错误

### 错误1：SUMPRODUCT函数参数不足

**错误表现**：
- 报错："函数 SUMPRODUCT 的必需参数个数为 2"
- 公式无法正常保存或运行

**错误示例**：
```
SUMPRODUCT(IF(EQ(子表.产品,"苹果"),1,0))
```

**错误原因**：
- SUMPRODUCT函数在宜搭中**必须至少2个参数**
- 不能单独使用一个数组作为参数

**正确方案**：
```
// 方案1：使用SUM函数替代（推荐用于条件计数）
SUM(IF(EQ(子表.产品,"苹果"),1,0))

// 方案2：使用两个数组相乘
SUMPRODUCT(IF(EQ(子表.产品,"苹果"),1,0), 1)

// 方案3：两个子表字段相乘后求和
SUMPRODUCT(子表.单价, 子表.数量)
```

**使用建议**：
- **条件计数**（统计满足条件的行数）：使用 `SUM(IF(EQ(...),1,0))`
- **多数组乘积求和**：使用 `SUMPRODUCT(数组1, 数组2, ...)`
- SUMPRODUCT适合计算如"单价×数量"的总和场景

---

### 错误2：使用了不存在的函数或大小写错误

**错误表现**：
- 报错："未找到与 XXX 匹配的公式函数"
- 公式返回空值或异常

**常见错误**：
- 在表单场域使用 `MAPX`、`SUMPRODUCTX`（报表场域专用）
- 使用 `SUBTRACT`、`DIVIDE`（宜搭无此函数）
- **大小写错误**：`GETARRAYITEM` 应为 `GetArrayItem`
- **混淆相似函数**：`GetArrayItem` vs `ARRAYGET`

**解决方案**：
- 查阅 [01-formula-complete-reference.md](./01-formula-complete-reference.md) 确认函数存在
- **严格按文档大小写使用函数**（宜搭函数大小写敏感）
- 表单场域**不支持**`MAPX`、`SUMPRODUCTX`
- 减法用 `-` 运算符，除法用 `/` 运算符

**函数场域对照表**：

| 函数 | 表单场域 | 报表场域 | 说明 |
|------|---------|---------|------|
| SUMPRODUCT | ✅ | ❌ | 数组乘积求和 |
| MAPX | ❌ | ✅ | 报表场域专用 |
| SUMPRODUCTX | ❌ | ✅ | 报表场域专用 |
| EXIST | ❌ | ❌ | 仅校验函数可用 |

**易混淆函数对比**：

| 函数 | 用途 | 索引起始 | 示例 |
|------|------|---------|------|
| `ARRAYGET(数组, 位置)` | 获取数组元素 | **从1开始** | `ARRAYGET(子表.字段, 1)` |
| `GetArrayItem(数组, 索引)` | 构造器函数用 | **从1开始** | `GetArrayItem(部门, 1)` |

**关键区别**：
- `ARRAYGET`：通用数组函数，用于子表字段等
- `GetArrayItem`：构造器函数配套使用，用于人员/部门对象数组

## 二、日期函数参数类型错误

### 错误3：对NOW()/TODAY()使用DATE()

❌ **错误**：
```
YEAR(DATE(NOW()))
MONTH(DATE(TODAY()))
```

✅ **正确**：
```
YEAR(NOW())
MONTH(TODAY())
```

**原因**：`NOW()` 和 `TODAY()` 返回的是**日期对象**，不需要再用 `DATE()` 转换。

---

### 错误4：对字段值不使用DATE()

❌ **错误**：
```
YEAR(出生日期)
DAYS(结束日期, 开始日期)
```

✅ **正确**：
```
YEAR(DATE(出生日期))
DAYS(DATE(结束日期), DATE(开始日期))
```

**原因**：日期组件字段的值是**时间戳**（数字），必须用 `DATE()` 转换为日期对象。

---

### 错误5：计算年龄的错误方式

❌ **错误**：
```
YEAR(NOW()) - YEAR(出生日期)  // 出生日期是时间戳，不能直接用
```

✅ **正确**：
```
YEAR(NOW()) - YEAR(DATE(出生日期))
```

---

### 错误6：DAYS函数参数类型错误

❌ **错误**：
```
DAYS(结束日期, 开始日期)  // 两个都是时间戳
```

✅ **正确**：
```
DAYS(DATE(结束日期), DATE(开始日期))
```

---

### 错误7：计算小时数的错误方式

❌ **错误**：
```
DAYS(DATE(结束), DATE(开始)) * 24  // DAYS只返回整天数
```

✅ **正确**：
```
(结束日期 - 开始日期) / 3600000  // 直接用时间戳计算毫秒差，转小时
```

## 三、IF函数使用错误

### 错误8：IF函数真假值留空

❌ **错误**：
```
IF(GT(成绩,60),"及格","")
IF(EQ(状态,"完成"),"已完成","")
```

✅ **正确**：
```
IF(GT(成绩,60),"及格","不及格")
IF(EQ(状态,"完成"),"已完成","进行中")
```

**原因**：
- 用户看到空值会认为公式没有生效
- 明确的提示可以提升用户体验
- 便于调试和排查问题

**使用图标增强可读性**：
- ❌ 表示错误/不通过
- ✅ 表示正确/通过
- ⚠️ 表示警告
- ℹ️ 表示提示

## 四、字段相关错误

### 错误9：混淆 ARRAYGET 和 GetArrayItem

| 函数 | 用途 | 索引起始 |
|------|------|---------|
| `ARRAYGET(数组, 位置)` | 通用数组函数，用于子表字段等 | **从1开始** |
| `GetArrayItem(数组, 索引)` | 构造器函数配套使用 | **从1开始** |

**关键区别**：
- `ARRAYGET`：用于子表字段等普通数组
- `GetArrayItem`：用于人员/部门对象数组，配合构造器函数使用

---

### 错误10：子表字段ID格式错误

❌ **错误**：
```
tableField_xxx.textField_yyy
```

✅ **正确**：
直接使用 `textField_yyy`

**字段ID格式规则**：
- ✅ 子表字段ID与普通字段ID格式完全相同：`textField_xxx`
- ✅ 直接使用字段本身的ID，不需要任何前缀
- ❌ 不要使用 `子表ID.字段ID` 格式（这是编造的错误格式）

---

### 错误11：JSON格式错误

❌ **错误**：
```json
"text": "SPLIT(​字段​,\"\,\")"
```

✅ **正确**：
```json
"text": "SPLIT(​字段​,\",\")"
```

**JSON转义规则**：
- ✅ 双引号 `"` 需要转义为 `\"`
- ✅ 反斜杠 `\` 需要转义为 `\\`
- ❌ 逗号 `,` **不需要转义**，直接写 `","` 即可
- ❌ 括号 `(` `)` **不需要转义**，直接写即可

## 五、marks位置计算错误

### 错误12：手工计算marks位置

**绝对禁止的行为**：
- ❌ 手工计算字符位置
- ❌ 手工计算字段长度
- ❌ 估算或猜测位置
- ❌ 依赖"上次是X，这次也差不多"

**正确做法**：
- ✅ 使用Node.js程序自动计算
- ✅ 完全依赖 `formula_generator_wrapper.js` 自动计算
- ✅ 程序会自动校验 `text[from.ch:to.ch]` 是否等于字段名

**marks位置计算是公式生成的核心，必须使用Node.js程序，严禁任何其他方式！**

## 六、函数编造错误

### 错误13：使用文档中不存在的函数

**宜搭公式适合的场景**：
- ✅ 简单的数学运算（加减乘除）
- ✅ 文本拼接和截取
- ✅ 日期计算（天数差、年月日提取）
- ✅ 条件判断（IF 嵌套）
- ✅ 简单的子表汇总（SUM、AVG、COUNT）
- ✅ 字段间的基础联动

**宜搭公式无法实现的场景**（必须使用 JS）：
- ❌ **循环逻辑** - 公式不支持 for/while 循环
- ❌ **数组/列表操作** - 无法动态遍历数组元素
- ❌ **复杂字符串处理** - 正则表达式、复杂替换逻辑
- ❌ **递归计算** - 公式不支持递归调用
- ❌ **外部数据获取** - 无法调用 API 或查询外部数据源

**核心原则：只能使用【宜搭表单公式文档】中明确列出的函数，严禁编造任何函数！**

## 七、人员/部门字段处理错误

### 错误14：直接使用成员组件值

❌ **错误**：
```
成员组件  // 返回 ["userid123"]，不是对象
```

✅ **正确方式1 - USERFIELD（推荐）**：
```
USERFIELD(成员组件, "name")
USERFIELD(成员组件, "mobile")
```

✅ **正确方式2 - 构造器函数**：
```
GetObjectField(GetArrayItem(UserBuilder(成员组件), 1), "label")
```

**推荐使用 USERFIELD 函数**，语法更简洁。

在编写公式前，确认以下事项：

- [ ] SUMPRODUCT是否至少有2个参数？

- [ ] 函数名称大小写正确
- [ ] 日期字段是否用 `DATE()` 包裹？（字段值必须）
