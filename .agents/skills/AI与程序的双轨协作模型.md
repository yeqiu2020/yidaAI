# 方法论总结：AI与程序协作的工程实践

> 版本：1.0.0  
> 创建日期：2026-02-15  
> 适用场景：宜搭公式生成、自动化脚本、表单代码等

---

## 一、核心洞察

### 1.1 问题本质

在宜搭公式生成过程中，我们面临两个核心挑战：

| 挑战类型 | 具体问题 | 解决难度 |
|---------|---------|---------|
| **精确计算** | marks位置需要逐字符精确计算，不能估算 | 高（人工易错） |
| **逻辑构建** | 公式逻辑需要根据业务需求灵活构建 | 中（AI擅长） |

### 1.2 突破点

**关键发现**：将"可计算的"交给程序，将"需要判断的"交给AI

- **程序负责**：精确计算、格式转换、位置标记、验证校验
- **AI负责**：需求理解、逻辑设计、函数选择、异常处理

## 三、实施步骤（四步强制流程）

### 步骤1：AI解析需求

**输入**：用户需求描述
**输出**：结构化配置

```javascript
// AI提取的关键信息
const config = {
  formulaName: '根据身份证号计算星座',  // AI理解需求命名
  category: '身份证处理',              // AI判断分类
  fields: [                            // AI识别字段
    { displayName: '身份证号', fieldId: 'textField_mljkhwmz' }
  ],
  logic: '提取第11-14位判断星座范围'    // AI设计的逻辑
};
```

**关键动作**：
- 朗读字段名3次，确认准确性
- 明确字段类型和ID
- 设计公式逻辑流程

### 步骤2：AI构建逻辑模板

**输入**：结构化配置
**输出**：公式逻辑文本（使用占位符）

```javascript
// AI构建的公式模板（使用占位符）
const formulaTemplate = 
  'IF(EQ(LEN({身份证号}),18),' +
  'IF(AND(GE(VALUE(MID({身份证号},11,4)),321),...)' +
  '...' +
  '"身份证号格式错误")';
```

**关键动作**：
- 使用 `{字段名}` 占位符，避免直接处理零宽空格
- 确保函数名称正确（大写）
- 构建完整的逻辑判断链

### 步骤3：程序精确计算

**输入**：公式模板 + 字段配置
**输出**：完整JSON（含marks位置）

```javascript
// 程序自动完成的工作
function generateFormula(config) {
  // 1. 替换占位符为零宽空格包裹的字段名
  const text = replacePlaceholders(config.formulaTemplate, config.fields);
  
  // 2. 自动计算每个字段的位置
  const marks = calculateMarks(text, config.fields);
  
  // 3. 验证 text[from:to] == 字段名
  validateMarks(text, marks);
  
  // 4. 生成完整JSON
  return { text, marks, isCmData: true };
}
```

**关键动作**：
- 逐字符精确计算位置
- 自动处理多次引用的字段
- 验证每个mark的正确性

### 步骤4：输出生成与验证

**输入**：完整JSON
**输出**：文件 + 文档

```
宜搭公式生成记录/
├── 身份证处理/
│   ├── 根据身份证号计算星座.json   <- 程序生成
│   └── 根据身份证号计算星座.md     <- AI生成说明
```

**关键动作**：
- 程序写入JSON文件
- AI生成说明文档
- 双方共同验证结果

## 四、关键成功要素

### 4.1 必须遵守的原则

| 原则 | 说明 | 违反后果 |
|------|------|---------|
| **绝不手工计算位置** | marks位置必须由程序计算 | 位置错误，公式失效 |
| **绝不编造函数** | 只能使用官方文档列出的函数 | 公式无法运行 |
| **字段名必须确认** | 必须与表单实际字段名一致 | marks匹配失败 |
| **必须验证校验** | 程序必须验证 text[from:to] | 潜在错误无法发现 |

### 4.2 协作界面设计

**AI与程序的协作界面是：公式模板（使用占位符）**

```javascript
// AI输出（使用占位符）
'IF(EQ(LEN({身份证号}),18),"正确","错误")'

// 程序处理（替换为零宽空格包裹）
'IF(EQ(LEN(​身份证号​),18),"正确","错误")'
//           ↑零宽空格↑
```

这种设计的优势：
- AI专注于逻辑，不处理特殊字符
- 程序专注于格式，精确计算位置
- 两者解耦，独立演进

## 七、总结

### 7.1 核心思想

> **让AI做AI擅长的事，让程序做程序擅长的事**

- AI擅长：理解、设计、判断、创造
- 程序擅长：计算、转换、校验、生成

### 7.2 关键突破

1. **解耦**：通过占位符将AI逻辑与程序格式解耦
2. **精确**：程序保证位置计算的100%准确性
3. **复用**：固定配置文件，重复使用
4. **验证**：程序自动校验，避免人工疏漏

### 7.3 适用范围

本方法论适用于任何需要"精确计算 + 灵活逻辑"的场景：
- ✅ 宜搭公式生成
- ✅ 表单代码生成
- ✅ 自动化脚本
- ✅ 报表配置
- ✅ 任何需要精确位置标记的文本生成
