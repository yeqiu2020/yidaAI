## P33：Cookie 有效性验证

**场景：** 当前 Cookie 有效，可正常调用宜搭 API

| 属性 | 值 |
|------|-----|
| 优先级 | P0 |
| 测试层级 | 宜搭 API |
| 执行工具 | data-tester |
| 能力域 | 工具链 |

**占位符：**
- `{应用ID}` — 任意已存在的应用 ID

**操作步骤：**
1. 读取 `.cookies.json`
2. 调用宜搭 API（如 `searchFormDatas.json`），携带 Cookie

**断言：**
- API 返回非 401 状态码
- 返回结果非"登录过期"错误

**失败处理：**
- Cookie 过期 → 需要用户重新登录（调用 simulated-login 或 auth-plus）
- CSRF Token 过期 → 自动刷新
