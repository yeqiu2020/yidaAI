## 1. 配置 PowerShell UTF-8 编码（解决中文乱码）

**重要性**: ⭐⭐⭐ 必须首先执行，否则后续所有中文输出都会显示乱码

**问题说明**: Windows PowerShell 默认使用 GBK/ASCII 编码，而 Node.js 使用 UTF-8 编码，导致中文显示乱码（如"中文测试"显示为"娴嬭瘯涓枃"）

**检测方法**:

```powershell
# 检查当前编码
[Console]::OutputEncoding
$OutputEncoding
chcp
```

**自动配置步骤**:

1. **检测是否已配置 UTF-8**:
   - 运行 `chcp` 检查代码页
   - 如果显示 `Active code page: 65001`，说明已配置 UTF-8，显示 "✅ PowerShell UTF-8 编码已配置，跳过"
   - 如果显示 `Active code page: 936` 或其他，需要配置
2. **配置 UTF-8 编码**（需要执行一次）:
   ```powershell
   # 创建 PowerShell 配置文件（如果不存在）
   if (!(Test-Path $PROFILE)) {
       New-Item -Path $PROFILE -Type File -Force
   }

   # 检查是否已存在 UTF-8 配置
   $profileContent = Get-Content $PROFILE -Raw -ErrorAction SilentlyContinue
   if ($profileContent -notmatch "UTF-8") {
       # 添加 UTF-8 编码设置
       Add-Content -Path $PROFILE -Value "`n# 设置 UTF-8 编码，解决中文乱码问题`n`$OutputEncoding = [System.Text.Encoding]::UTF8`n[Console]::OutputEncoding = [System.Text.Encoding]::UTF8`nchcp 65001 | Out-Null"
       Write-Host "✅ PowerShell UTF-8 编码配置完成" -ForegroundColor Green
       Write-Host "💡 请关闭当前终端，重新打开新的终端窗口以使配置生效" -ForegroundColor Yellow
   } else {
       Write-Host "✅ PowerShell UTF-8 编码已配置" -ForegroundColor Green
   }
   ```
3. **验证配置**:
   - 提示用户："配置已更新，请关闭当前终端并重新打开，然后再次运行环境初始化"
   - 或者在新终端中验证：`node -e "console.log('中文测试')"` 应正确显示 "中文测试"

**配置文件位置**: `C:\Users\<用户名>\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`

## 2. 检查 Node.js

### 2.1 检测 Node.js 是否可用

```powershell
# 尝试运行 node 命令
$nodeVersion = node -v 2>$null
if ($LASTEXITCODE -eq 0) {
    Write-Host "✅ Node.js 已安装，版本: $nodeVersion" -ForegroundColor Green
} else {
    Write-Host "⚠️ Node.js 命令不可用，开始自动查找..." -ForegroundColor Yellow
    
    # 常见 Node.js 安装路径
    $possiblePaths = @(
        "$env:ProgramFiles\nodejs",
        "${env:ProgramFiles(x86)}\nodejs",
        "$env:USERPROFILE\.trae-cn\binaries\node\versions\*",
        "$env:USERPROFILE\.trae\binaries\node\versions\*",
        "$env:USERPROFILE\.cursor\binaries\node\versions\*",
        "$env:USERPROFILE\.nvm\versions\node\*",
        "$env:ProgramData\nvm",
        "$env:USERPROFILE\AppData\Roaming\nvm"
    )
    
    $foundNodePath = $null
    foreach ($pathPattern in $possiblePaths) {
        $nodeExe = Get-ChildItem -Path $pathPattern -Filter "node.exe" -Recurse -ErrorAction SilentlyContinue | Select-Object -First 1
        if ($nodeExe) {
            $foundNodePath = $nodeExe.Directory.FullName
            Write-Host "🔍 找到 Node.js: $foundNodePath" -ForegroundColor Cyan
            break
        }
    }
    
    if ($foundNodePath) {
        # 临时添加到当前会话 PATH
        $env:PATH = "$foundNodePath;$env:PATH"
        
        # 永久添加到用户环境变量
        $userPath = [Environment]::GetEnvironmentVariable("PATH", "User")
        if ($userPath -notlike "*$foundNodePath*") {
            [Environment]::SetEnvironmentVariable("PATH", "$userPath;$foundNodePath", "User")
            Write-Host "✅ Node.js 路径已永久添加到用户环境变量" -ForegroundColor Green
            Write-Host "💡 提示：新打开的终端将自动识别 Node.js" -ForegroundColor Yellow
        }
        
        # 验证
        $nodeVersion = node -v
        Write-Host "✅ Node.js 现在可用，版本: $nodeVersion" -ForegroundColor Green
    } else {
        Write-Host "❌ 未找到 Node.js，需要手动安装..." -ForegroundColor Red
        Write-Host "📥 请访问 https://nodejs.org/ 下载 LTS 版本安装" -ForegroundColor Yellow
        exit 1
    }
}
```

### 2.2 PowerShell 7 特殊处理

如果当前是 **PowerShell 7**（`$PSVersionTable.PSVersion.Major -ge 7`），且 Node.js 在 PowerShell 5/CMD 中可用但在 PowerShell 7 中不可用：

```powershell
if ($PSVersionTable.PSVersion.Major -ge 7) {
    # 从系统 PATH 中同步 Node.js 路径
    $machinePath = [Environment]::GetEnvironmentVariable("PATH", "Machine")
    $userPath = [Environment]::GetEnvironmentVariable("PATH", "User")
    $fullPath = "$machinePath;$userPath"
    
    # 查找包含 node.exe 的路径
    $nodePaths = $fullPath -split ';' | Where-Object { 
        Test-Path (Join-Path $_ "node.exe") -ErrorAction SilentlyContinue 
    }
    
    foreach ($path in $nodePaths) {
        if ($env:PATH -notlike "*$path*") {
            $env:PATH = "$path;$env:PATH"
            Write-Host "✅ 已同步 Node.js 路径到 PowerShell 7: $path" -ForegroundColor Green
        }
    }
}
```

### 5.1 检测逻辑

1. **获取当前 Playwright 版本需要的 Chromium 版本**：
   ```powershell
   $playwrightVersion = npx playwright --version
   # 根据版本确定需要的 Chromium 编号
   # 1.62.x -> chromium-1234  ← 当前项目 package.json 锁定版本（^1.62.1）
   # 1.61.x -> chromium-1228
   # 1.59.x -> chromium-1223
   ```
   **完整版本对应关系**（以项目实际 package.json 锁定版本为准）：
   
   | Playwright 版本 | Chromium 编号 | 说明 |
   |-----------------|---------------|------|
   | 1.62.x | chromium-1234 | 项目当前锁定版本 |
   | 1.61.x | chromium-1228 | |
   | 1.59.x | chromium-1223 | |
   
2. **检测对应版本的 Chromium 是否存在**：
   - 检查 `$env:USERPROFILE\AppData\Local\ms-playwright\chromium-1234\chrome-win64\chrome.exe` 是否存在
   - **注意**：必须检测**对应版本**的 chromium 文件夹，不能只看是否存在任意版本

   - 运行 `npx playwright install chromium` 安装正确版本

### 5.2 配置国内镜像加速下载（重要：解决 Chromium 下载慢的问题）

**问题说明**: Playwright 默认从 `https://cdn.playwright.dev` 下载 Chromium，国内访问速度极慢（通常 <100KB/s，下载 179MB 需要 30+ 分钟甚至超时失败），必须切换到国内镜像。

**国内镜像选项**（按速度优先级）:

| 镜像源 | 地址 | 说明 |
|--------|------|------|
| npmmirror（推荐） | `https://cdn.npmmirror.com/binaries/playwright` | 阿里云提供，速度快且稳定，通常 2-5 分钟即可下载完成 |
| cnpmjs | `https://npm.taobao.org/mirrors/playwright` | 淘宝镜像，已逐步迁移到 npmmirror |
| playwright.dev | `https://cdn.playwright.dev/builds` | 官方源，国内速度慢 |

**配置步骤**（在运行 `npx playwright install` 之前执行）:

```powershell
# 1. 设置 Playwright 下载镜像（临时 - 仅当前会话生效）
$env:PLAYWRIGHT_DOWNLOAD_HOST = "https://cdn.npmmirror.com/binaries/playwright"

# 2. 永久配置（推荐 - 写入用户环境变量，避免每次重新设置）
[Environment]::SetEnvironmentVariable("PLAYWRIGHT_DOWNLOAD_HOST", "https://cdn.npmmirror.com/binaries/playwright", "User")
Write-Host "✅ Playwright 下载镜像已永久配置为 npmmirror" -ForegroundColor Green

# 3. 同时配置 npm 镜像（加速 playwright 包本身的安装）
npm config set registry https://registry.npmmirror.com
Write-Host "✅ npm 镜像已配置为 npmmirror" -ForegroundColor Green

# 4. 验证配置
$checkHost = [Environment]::GetEnvironmentVariable("PLAYWRIGHT_DOWNLOAD_HOST", "User")
Write-Host "🔍 当前镜像配置: $checkHost" -ForegroundColor Cyan
```

### 5.3 快速检测与安装命令（已集成国内镜像）

```powershell
# 检测 chromium-1234 是否存在（对应 Playwright 1.62.x，项目当前锁定版本）
$chromiumPath = "$env:USERPROFILE\AppData\Local\ms-playwright\chromium-1234\chrome-win64\chrome.exe"
if (Test-Path $chromiumPath) {
    Write-Host "✅ Chromium 已安装 (chromium-1234)" -ForegroundColor Green
} else {
    Write-Host "⚠️ Chromium 未安装或版本不匹配，开始安装（使用国内镜像加速）..." -ForegroundColor Yellow
    
    # 配置国内镜像（如果未配置）
    $mirrorHost = [Environment]::GetEnvironmentVariable("PLAYWRIGHT_DOWNLOAD_HOST", "User")
    if (-not $mirrorHost) {
        [Environment]::SetEnvironmentVariable("PLAYWRIGHT_DOWNLOAD_HOST", "https://cdn.npmmirror.com/binaries/playwright", "User")
        $env:PLAYWRIGHT_DOWNLOAD_HOST = "https://cdn.npmmirror.com/binaries/playwright"
        Write-Host "✅ 已自动配置 npmmirror 镜像" -ForegroundColor Green
    } else {
        Write-Host "ℹ️ 已存在镜像配置: $mirrorHost" -ForegroundColor Cyan
    }
    
    # 同时确保 npm 镜像已配置
    npm config get registry | Out-Null
    if ($LASTEXITCODE -ne 0) {
        npm config set registry https://registry.npmmirror.com
    }
    
    # 使用国内镜像安装 Chromium
    npx playwright install chromium
    
    # 验证安装结果
    if (Test-Path $chromiumPath) {
        Write-Host "✅ Chromium 安装成功" -ForegroundColor Green
    } else {
        Write-Host "❌ Chromium 自动安装失败，请尝试手动下载（见下方手动安装步骤）" -ForegroundColor Red
    }
}
```

### 5.4 Chromium 推荐下载地址（手动安装备用）

**推荐国内镜像下载地址（速度快，推荐优先使用）：**

- Chromium 国内镜像：`https://cdn.npmmirror.com/binaries/playwright/builds/chromium/1234/chrome-win.zip`
- Headless Shell 国内镜像：`https://cdn.npmmirror.com/binaries/playwright/builds/chromium/1234/chrome-headless-shell.zip`

**官方源（国内访问慢，作为备用）：**

- Chromium: `https://cdn.playwright.dev/builds/cft/147.0.7727.15/win64/chrome-win64.zip`
- Headless Shell: `https://cdn.playwright.dev/builds/cft/147.0.7727.15/win64/chrome-headless-shell-win64.zip`

**手动安装步骤：**

1. 从国内镜像下载 `chrome-win.zip`（约 179MB，使用国内镜像约 2-5 分钟）
2. 解压到 `$env:USERPROFILE\AppData\Local\ms-playwright\chromium-1234\chrome-win\`
3. 确保目录下有 `chrome.exe` 文件
4. 如需 Headless 模式，同时下载并解压 `chrome-headless-shell.zip` 到 `chromium_headless_shell-1234\chrome-win\` 目录
5. 推荐安装路径：`$env:USERPROFILE\AppData\Local\ms-playwright`（即 `C:\Users\<当前用户名>\AppData\Local\ms-playwright`）

**镜像版本对应关系**:
- Playwright 1.62.x → chromium-1234 → 镜像路径包含 `1234`（项目当前锁定版本）
- Playwright 1.61.x → chromium-1228 → 镜像路径包含 `1228`
- Playwright 1.59.x → chromium-1223 → 镜像路径包含 `1223`
- 完整镜像目录：https://cdn.npmmirror.com/binaries/playwright/builds/chromium/

### 5.5 常见问题

- **问题**：已安装 Chromium 但提示 "Executable doesn't exist at ...chromium-1234..."
- **原因**：安装的 Chromium 版本与 Playwright 版本不匹配
- **解决**：删除旧的 chromium 文件夹，重新运行 `npx playwright install chromium`（已配置国内镜像）
- **问题**：安装 Chromium 时报权限错误
- **原因**：Trae 沙箱限制了直接文件操作，但 `npx` 命令不受此限制
- **解决**：确保使用 `npx playwright install chromium` 安装，不要手动复制文件到 ms-playwright 目录
- **问题**：使用镜像后仍下载失败
- **原因**：镜像源版本号与 Playwright 版本不匹配，或镜像路径变更
- **解决**：访问 https://cdn.npmmirror.com/binaries/playwright/builds/chromium/ 查看可用版本号，或回退到官方源 `https://cdn.playwright.dev`
- **问题**：下载速度仍然慢（<1MB/s）
- **原因**：网络环境异常或镜像节点访问不畅
- **解决**：尝试切换网络（如使用代理或热点重试），或下载离线包后手动解压

**注意事项：**

- **第1步（UTF-8编码配置）必须首先执行**，这是解决中文乱码的基础
- 如果第1步提示需要重启终端，请关闭当前终端并重新打开后再继续
- 每一步都必须先检测再安装，避免重复下载安装 Chromium
- **第5步（Chromium安装）必须先配置国内镜像再执行 npx playwright install chromium**，否则会从官方源下载，速度极慢甚至超时失败
- 配置完 PLAYWRIGHT_DOWNLOAD_HOST 后，需关闭当前终端重新打开（或手动设置 $env:PLAYWRIGHT_DOWNLOAD_HOST）才能在当前会话生效
- 每个步骤完成后显示相应的状态信息
- 所有步骤完成后输出汇总结果
- 手工查找playwright全局安装目录在展开后的完整路径：`$env:USERPROFILE\AppData\Local\ms-playwright\`（即 `C:\Users\<当前用户名>\AppData\Local\ms-playwright\`）
