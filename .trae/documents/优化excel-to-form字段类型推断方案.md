# 优化 excel-to-form 字段类型推断方案

## 一、目标

将 Excel 转字段清单流程从「脚本关键词匹配优先」调整为「AI 语义预推断优先 + 脚本兜底规则校验补充」，解决 `产品分类`、`单位` 等明显选项类字段被误判为「单行文本」的问题，并验证对已有进销存 Excel 的实际效果。

## 三、实施步骤

### 步骤 1：AI 语义预推断并生成覆盖文件

- 读取 Excel：`d:\宜搭AI编程\宜搭AI助手V2.0.1\进销存系统\01需求梳理\进销存管理表单清单.xlsx`
- 参照 `AI字段类型推断提示词.md`，对无显式类型标注、且脚本兜底规则可能误判的字段进行语义判断。
- 输出覆盖文件：`d:\宜搭AI编程\宜搭AI助手V2.0.1\进销存系统\01需求梳理\field-types-override.json`
- 覆盖文件仅包含有把握需要修正的字段；用户已在 Excel 括号内明确标注类型的字段不重复指定。

### 步骤 2：运行脚本重新生成字段清单和规则清单

调用命令：

```bash
node .agents/skills/excel-to-form/scripts/excel_to_form.js "进销存系统/01需求梳理/进销存管理表单清单.xlsx" "进销存系统/01需求梳理" "进销存管理" "1.0.0"
```

脚本会自动读取同目录下的 `field-types-override.json`。

### 步骤 3：AI 校验字段说明完整性

对生成的 `字段清单.md` 执行第 3.6 步校验：

1. 流水号字段：确认说明格式为「自动生成，前缀：XXX，示例：XXXyyyyMMdd001」。
2. 关联表单字段：确认说明格式为「关联-->目标表单」，并追加填充规则。
3. 数值字段：金额类补充「单位：元」，数量类补充合理单位，比例类补充「单位：%」。
4. 下拉单选/多选字段：确认字段说明包含 `/` 分隔的选项值，且符合业务场景。

### 步骤 4：运行 ai-validator 结构校验

执行：

```bash
node scripts/ai-validator.js check-after-write "进销存系统/01需求梳理/字段清单.md"
```

必须无错误、无警告。若报错，返回步骤 2 或步骤 3 修复。

### 步骤 5：验证关键字段类型

检查 `字段清单.md` 中以下字段是否已正确识别为「下拉单选」并带有选项：

- 产品信息.产品分类
- 产品信息.单位
- 其他在步骤 1 中被 AI 覆盖的字段

### 步骤 6：清理临时文件

删除本次验证过程中产生的临时目录（如 `temp-file/excel-verify`），保持工作区整洁。

## 四、回退策略

- 若 AI 覆盖文件导致字段类型非法，脚本会自动回退为「单行文本」并输出警告。
- 若脚本兜底规则与 AI 覆盖冲突，以 AI 覆盖为准（但用户显式标注优先级最高）。
- 若验证失败，保留旧版字段清单作为备份，不直接覆盖用户源文件。

## 五、验证标准

1. `field-types-override.json` 已生成且 JSON 格式合法。
2. `字段清单.md` 已重新生成，无结构缺失。
3. `check-after-write` 校验通过。
4. `产品分类`、`单位` 等目标字段类型为「下拉单选」且说明列包含选项。
5. 临时文件已清理。
