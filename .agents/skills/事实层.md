## 数据读写（2026-10-29）

- 子表读取：`formData` 只返回前 50 行；完整行用 `instValue` 或 `listTableDataByFormInstIdAndTableId.json`（分页 pageSize 上限 50，以 `totalCount` 为准） `[已固化:.agents/skills/form-data-update/scripts/fdu_lib.js assertSubRowCount]`
- 子表写入：必须整表回写，行内必须带 `rowId`；缺 rowId 的存量行先在页面编辑保存一次补标识 `[已固化:fdu_lib.js buildUpdatePayload]`
- 关联表单字段：`associationFormField_*` 必须以**对象数组** `[{instanceId,title}]` 回写；写入字符串会把关联置空 `[已固化:fdu_lib.js normalizeAssociationValue]`
- 下拉字段：优先传选项实际值（回读中带 `<field>_id` 后缀的镜像键）；传显示值会破坏选项映射 `[已固化:fdu_lib.js normalizeSelectValue]`
- 附件/图片/签名类控件：读取形态与写入形态不同构，脚本整表回写无法保真 → 非空中止 `[已固化:fdu_lib.js guardComplexFieldsOnFullRewrite]`
- 日期直写必须 13 位毫秒时间戳，严禁 `YYYY-MM-DD` 字符串 `[已固化:fdu_lib.js normalizeDateValue]`
- 公式/校验：API 直建的单据不触发页面端公式求值；公式字段只在页面提交时计算（2026-10-29）
- 服务端业务校验（如「不允许超量发货！」）：API 写入整条记录被拒，无参数可绕过（2026-10-29） `[已固化:form_data_update.js writePayload 错误透传]`
- superform（schemaType=superform）的 READONLY 行为字段：startInstance/updateInstance 写入被静默丢弃（响应成功值不入库）→ 唯一靠写后回读断言发现（2026-10-15）
- searchFormDatas 分页：pageSize 传 200 报「参数校验失败」；上限 100（2026-10-30 空手模型实测背书）
- 废弃空壳表单（getFormComponentDefinationList 返回 0 组件）：searchFormDatas / getInstanceIds / getInstances 等枚举接口全部报 `selectListException 无法找到字段: pid`，平台接口层无法枚举，属平台边界——排查数据时先排除空壳表单，勿当接口故障（2026-10-30 易能盛ERP 实测）

## 集成自动化（2026-10-15 沉淀，详证见 AGENTS.md 硬规则区）

- `saveProcess` 不校验配置完整性，**保存成功 ≠ 配置正确**；API 保存过的流 getProcess 回读 content 恒为空，修改只能 `--process-code` 整体重建
- UpdateDataNode 产生的子表行 `update` 事件不向其他逻辑流传播（`--trigger-recursively` 无效），`insert` 正常
- 更新目标子表行时 `subSourceId` 有值但 `subCondition` 为空 → 引擎按主表模式执行报错（体检不拦截）
- 依赖「中间表被更新」触发下游流的方案是死路；中间表必须逐笔 INSERT（UPSERT 键加单据编号）

## 本地服务（2026-10-25）

- `/push-form-actions` 等写接口需先 `GET /get-session-token` 取 `X-Session-Token`
- 服务死活判据只有 `ensure-service.js` 的 `YIDA_READY {"ok":true,...}` 或 node 直连 http；禁止用 curl 判活（系统代理会返回 502 造成误判）
- 工作区目录内 `.bat`/`.vbs` 经 explorer 启动会弹安全警告导致静默失败；启动器必须放工作区外
- 所有 `.bat` 必须纯 ASCII 内容 + CRLF 换行，否则 cmd.exe 静默解析失败

## 多项目与安全（2026-10-25）

- 脚本多项目隔离：`YIDA_PROJECT_ROOT` 优先，Cookie/台账必须跟随目标项目而不是脚本宿主 `[已固化:form_data_update.js PROJECT_ROOT]`
- 写操作前选择性刷新 Schema（get-schema 只同步本次涉及表单），本地清单是派生缓存不是真相源（2026-09-30）
