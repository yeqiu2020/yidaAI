# 手动配置步骤明细（普通表单 / 流程表单 UI 逐步清单）

> 本文件由 SKILL.md 第十节下沉而来。正常流程由 `push-rule.js` 自动完成这些步骤（见 SKILL.md 第九节），本清单用于手动粘贴兜底或人工核对。两条路径的核心区分与差异对比表见 [../SKILL.md](../SKILL.md) 第三节与硬规则8。

## 普通表单配置步骤（走「表单设置→表单事件」路径）

1. 打开触发表单设计器（pageDesigner URL：`/design/pageDesigner?formUuid=表单UUID值`）
2. 点击顶部「表单设计」Tab
3. 在左侧/右侧面板中找到「表单设置」入口，单击展开
4. 在「表单设置」面板中找到「表单事件」折叠面板（class `lc-field lc-accordion-field`），如折叠则单击展开
5. 在「表单事件」面板中找到「添加业务关联规则」按钮（class `next-btn next-small next-btn-normal vs-list-adder`），单击
6. 在弹出的对话框（class `next-dialog next-dialog-v2 vs-advanceRule-dialog`）中：
   - 选择**触发类型**（单据提交 / 单据删除 / 单据编辑，默认「单据提交」）
   - 输入**规则名称**，确认**规则类型**为「关联操作」（默认已选中）
   - 在**关联操作**公式输入区（TEXTAREA）中输入函数名、括号、逗号、字符串常量；目标表、目标列、来源字段通过令牌插入（对照 MD 文件中的 fieldMapping）
7. 点击「确定」保存规则
8. 点击「保存」保存表单设计（⚠️ 普通表单**不需要**「发布流程」步骤，保存即生效）

> ⚠️ 普通表单的触发类型是「单据提交/单据删除/单据编辑」三选一，**不是**节点类型（无"开始/审批节点"概念）。「表单事件」面板中还包含其他事件类型（如表单校验、字段联动等），「添加业务关联规则」是其中一种，按钮文本明确。

## 流程表单配置步骤（走「流程设计→全局设置→节点提交规则」路径）

1. 打开触发表单设计器，点击顶部「流程设计」（newDesigner URL，含 processCode 参数）
2. 如果流程已启用（显示"当前流程启用中，仅可查看，不支持编辑"），点击「创建新流程」创建新版本草稿
3. 点击「全局设置」按钮，打开全局设置面板，找到「节点提交规则」区域（显示"已配置N条"）
4. 点击「添加规则」按钮，弹出规则配置对话框，输入**规则名称**
5. 🔴 **节点类型配置**（流程表单必做，见 SKILL.md 硬规则 15）：
   - 节点类型选「结束」（默认是"开始"，必须改为"结束"，即"开始"右侧的第二个选项，未找到选项时 push-rule.js 以 exit code 4 退出）
   - 节点动作勾选「同意」（结束节点同样必填节点动作，否则提示"节点动作不能为空"；流程正常结束对应"同意"动作）
   - 触发方式保持默认「任务完成执行」（无需修改）
6. 确认**规则类型**为「关联操作」（默认已选中）
7. 在**关联操作**公式输入区（TEXTAREA）中输入函数名、括号、逗号、字符串常量；目标表、目标列、来源字段通过令牌插入（对照 MD 文件中的 fieldMapping）
8. 点击「确定」保存规则
9. 点击「保存」保存流程设计
10. 点击「发布流程」（⚠️ 仅保存不发布，规则不会生效；流程表单必须发布）

> ℹ️ 宜搭在流程表单对话框中会提示"推荐使用「集成&自动化」配置关联操作"，但「关联操作」（即高级函数）仍然可用。全局设置面板中还有复选框「运行失败时，终止后续关联操作规则」，控制某条规则失败时是否终止后续规则的执行。
